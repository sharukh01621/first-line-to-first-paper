34.1 Stage 1 — First-Principles Intuition: Why Aggregate Metrics Hide Clinical Harm

Every hospital AI horror story begins with a celebratory aggregate metric. A team trains a child-stunting or sepsis risk classifier, sees a respectable overall test ROC-AUC on a pooled evaluation split, and declares victory. Weeks after deployment, clinicians notice the tool systematically misses sick patients in one demographic while flooding clinics with false alarms in another—or silently collapses after a seasonal shock changes patient demographics.

Responsible Clinical AI rests on five non-negotiable engineering disciplines:

  • Disaggregation Before Deployment: Pooled accuracy, AUC, and Brier score are weighted averages dominated by the majority stratum. A model scoring 0.65 overall can simultaneously achieve 73% sensitivity in rural clinics while missing 100% of cases in urban clinics—or flagging 100% of poorest households while ignoring wealthier stunted children.

  • Fairness Definitions Encode Clinical Values: Three group-fairness criteria capture distinct harms:

    • Demographic Parity (\(\Delta_{\text{DP}}\)): \(\max_g P(\hat{Y}=1 \mid G=g) - \min_g P(\hat{Y}=1 \mid G=g)\). Equalizes overall referral or screening rates across groups—dangerous when true disease prevalence genuinely differs!
    • Equal Opportunity (\(\Delta_{\text{EO}}\)): \(\max_g \text{TPR}_g - \min_g \text{TPR}_g\). Ensures sick patients in every group have an equal probability of being caught and treated.
    • Equalized Odds (\(\Delta_{\text{EqOdds}}\)): \(\max(\Delta_{\text{EO}}, \Delta_{\text{FPR}})\). Equalizes both missed cases (TPR) and false-alarm burden (FPR).

  • Subgroup Calibration Matters Independently of Ranking: Even if a model’s overall ECE looks tiny (~0.03), risk scores can remain systematically miscalibrated inside vulnerable subgroups (Poorest ECE 0.1658 vs. Richer ECE 0.0077). Clinicians rely on honest probabilities to allocate scarce nutrition supplements and diagnostic tests.

  • Qualitative Error Slicing Turns Numbers into Hypotheses: Scalar metrics tell you that a model failed; inspecting the 5 most confident False Negatives (\(y=1\), lowest \(\hat{p}\)) and False Positives (\(y=0\), highest \(\hat{p}\)) reveals why—such as over-reliance on socioeconomic proxies (wealth_rank, is_urban) when clinical biomarkers are missing.

  • Post-Deployment Shift Monitoring (PSI): Clinical environments never stand still. Pandemics, droughts, supply-chain disruptions, and hospital coding changes alter input feature distributions (covariate shift) long before delayed health outcomes are measured. The Population Stability Index (PSI) quantifies distribution drift continuously so teams retrain before patients are harmed.

NoteImpossibility Theorem in Clinical Fairness (Chouldechova / Kleinberg)

When two populations have genuinely different disease prevalences (\(P(Y=1 \mid G=a) \neq P(Y=1 \mid G=b)\), such as Rural 16.2% vs. Urban 8.1% stunting in mch_survey_sample), it is mathematically impossible for any imperfect classifier to simultaneously satisfy subgroup calibration, Equal Opportunity (equal TPR), and equal FPR! You must choose the fairness criterion aligned with clinical harm—typically Equal Opportunity for life-saving screening—and document residual trade-offs transparently in a Model Card.

34.3.2 Aggregate AUC Hides Subgroup Disparities

Now let’s peel back the 0.6471 aggregate AUC by disaggregating performance across residence and wealth_quintile:

def subgroup_performance_table(y_true, y_prob, groups, threshold=0.5):
    """Disaggregate clinical classifier metrics by sorted subgroup."""
    yt = np.asarray(y_true, dtype=int)
    yp = np.asarray(y_prob, dtype=float)
    gr = np.asarray(groups)
    rows = []
    for g in sorted(pd.unique(gr)):
        m = gr == g
        yt_g, yp_g = yt[m], yp[m]
        pred_g = (yp_g >= threshold).astype(int)
        auc = (
            round(float(roc_auc_score(yt_g, yp_g)), 4)
            if len(np.unique(yt_g)) == 2
            else np.nan
        )
        tp = int(np.sum((yt_g == 1) & (pred_g == 1)))
        fn = int(np.sum((yt_g == 1) & (pred_g == 0)))
        fp = int(np.sum((yt_g == 0) & (pred_g == 1)))
        tn = int(np.sum((yt_g == 0) & (pred_g == 0)))
        tpr = tp / (tp + fn) if (tp + fn) > 0 else 0.0
        fpr = fp / (fp + tn) if (fp + tn) > 0 else 0.0
        rows.append({
            "group": g.item() if hasattr(g, "item") else g,
            "n": int(np.sum(m)),
            "prevalence": round(float(np.mean(yt_g == 1)), 4),
            "roc_auc": auc,
            "tpr": round(tpr, 4),
            "fpr": round(fpr, 4),
            "brier": round(float(brier_score_loss(yt_g, yp_g)), 4),
        })
    cols = [
        "group", "n", "prevalence", "roc_auc", "tpr", "fpr", "brier",
    ]
    return pd.DataFrame(rows, columns=cols)

34.3.3 Quantifying Fairness Gaps: DP, Equal Opportunity & Equalized Odds

Let’s turn these subgroup tables into standardized fairness-gap metrics (max - min across groups):

def compute_fairness_gaps(y_true, y_pred, sensitive_attr):
    """Compute max-min DP, Equal Opportunity, FPR, and EqOdds gaps."""
    yt = np.asarray(y_true, dtype=int)
    yp = np.asarray(y_pred, dtype=int)
    gr = np.asarray(sensitive_attr)
    if not (len(yt) == len(yp) == len(gr)):
        raise ValueError(
            "y_true, y_pred, and sensitive_attr must have equal length"
        )
    sels, tprs, fprs = [], [], []
    for g in sorted(pd.unique(gr)):
        m = gr == g
        yt_g, yp_g = yt[m], yp[m]
        sels.append(float(np.mean(yp_g == 1)))
        tp = int(np.sum((yt_g == 1) & (yp_g == 1)))
        fn = int(np.sum((yt_g == 1) & (yp_g == 0)))
        fp = int(np.sum((yt_g == 0) & (yp_g == 1)))
        tn = int(np.sum((yt_g == 0) & (yp_g == 0)))
        tprs.append(tp / (tp + fn) if (tp + fn) > 0 else 0.0)
        fprs.append(fp / (fp + tn) if (fp + tn) > 0 else 0.0)
    eo = max(tprs) - min(tprs)
    fpr_d = max(fprs) - min(fprs)
    return {
        "demographic_parity_diff": round(max(sels) - min(sels), 4),
        "equal_opportunity_diff": round(eo, 4),
        "max_fpr_diff": round(fpr_d, 4),
        "equalized_odds_diff": round(max(eo, fpr_d), 4),
    }

34.3.4 Subgroup Calibration Curves & ECE Disparity

Now let’s audit probability calibration separately within each subgroup using equal-width Expected Calibration Error on \([0, 1]\):

\[\text{ECE}_g = \sum_{b=1}^{B} \frac{n_{g,b}}{N_g} \left| \bar{y}_{g,b} - \bar{p}_{g,b} \right|\]

def subgroup_calibration_audit(y_true, y_prob, groups, n_bins=5):
    """Audit equal-width ECE and Brier score across sorted subgroups."""
    yt = np.asarray(y_true, dtype=float)
    yp = np.asarray(y_prob, dtype=float)
    gr = np.asarray(groups)
    edges = np.linspace(0.0, 1.0, n_bins + 1)
    rows, raw_eces = [], {}
    for g in sorted(pd.unique(gr)):
        m = gr == g
        yt_g, yp_g = yt[m], yp[m]
        n_g = int(np.sum(m))
        ece = 0.0
        for i in range(n_bins):
            lo, hi = edges[i], edges[i + 1]
            if i < n_bins - 1:
                bm = (yp_g >= lo) & (yp_g < hi)
            else:
                bm = (yp_g >= lo) & (yp_g <= hi)
            cnt = int(np.sum(bm))
            if cnt > 0:
                gap = abs(float(yt_g[bm].mean()) - float(yp_g[bm].mean()))
                ece += (cnt / n_g) * gap
        g_val = g.item() if hasattr(g, "item") else g
        raw_eces[str(g_val)] = ece
        rows.append({
            "group": g_val,
            "n": n_g,
            "ece": round(ece, 4),
            "brier": round(float(brier_score_loss(yt_g, yp_g)), 4),
        })
    worst = max(raw_eces, key=raw_eces.get)
    max_gap = round(max(raw_eces.values()) - min(raw_eces.values()), 4)
    return {
        "per_group": pd.DataFrame(
            rows, columns=["group", "n", "ece", "brier"]
        ),
        "worst_ece_group": worst,
        "max_ece_gap": max_gap,
    }

def slice_worst_errors(df, y_true, y_prob, top_k=5):
    """Return top-k most confident false negatives and false positives."""
    work = df.copy()
    work["y_true"] = np.asarray(y_true, dtype=int)
    work["y_prob"] = np.asarray(y_prob, dtype=float)
    fn_df = (
        work[work["y_true"] == 1]
        .sort_values("y_prob", ascending=True)
        .head(top_k)
        .reset_index(drop=True)
    )
    fp_df = (
        work[work["y_true"] == 0]
        .sort_values("y_prob", ascending=False)
        .head(top_k)
        .reset_index(drop=True)
    )
    return {
        "worst_false_negatives": fn_df,
        "worst_false_positives": fp_df,
    }

34.3.6 Post-Processing Fairness Mitigation Without Retraining

When a classifier ranks sick patients well inside each subgroup but exhibits a score offset across groups (e.g., rural maternal anemia scores sit systematically lower than urban scores under a uniform 0.50 cutoff), post-processing threshold calibration can dramatically reduce the Equal Opportunity gap without retraining a single weight:

def calibrate_group_thresholds_for_tpr(
    y_true, y_prob, groups, target_tpr=0.75
):
    """Pick highest per-group cutoff achieving TPR >= target_tpr."""
    if not (0.0 < target_tpr <= 1.0):
        raise ValueError("target_tpr must lie in (0, 1]")
    yt = np.asarray(y_true, dtype=int)
    yp = np.asarray(y_prob, dtype=float)
    gr = np.asarray(groups)
    out = {}
    for g in sorted(pd.unique(gr)):
        m = gr == g
        yt_g, yp_g = yt[m], yp[m]
        n_pos = int(np.sum(yt_g == 1))
        best_t = 0.0
        if n_pos > 0:
            for t in np.sort(np.unique(yp_g))[::-1]:
                if np.sum((yt_g == 1) & (yp_g >= t)) / n_pos >= target_tpr:
                    best_t = float(t)
                    break
        out[g.item() if hasattr(g, "item") else g] = round(best_t, 4)
    return out

34.3.7 Covariate Shift Monitoring with Population Stability Index (PSI)

After deployment, how do you know when a pandemic, flood, or supply disruption has broken your model’s input distribution? Compute the Population Stability Index (PSI) across quantile bins locked on the baseline cohort:

\[\text{PSI} = \sum_{b=1}^{B} \left(p_{\text{act}, b} - p_{\text{exp}, b}\right) \ln\left(\frac{p_{\text{act}, b}}{p_{\text{exp}, b}}\right)\]

Standard operational thresholds classify PSI < 0.10 as Stable, 0.10 <= PSI < 0.25 as Moderate Drift, and PSI >= 0.25 as Severe Drift (retraining required):

def population_stability_index(expected, actual, n_bins=10, eps=1e-6):
    """Compute PSI and drift severity status from quantile bins."""
    exp = np.asarray(expected, dtype=float)
    act = np.asarray(actual, dtype=float)
    if len(exp) == 0 or len(act) == 0:
        raise ValueError("expected and actual arrays must be non-empty")
    edges = np.unique(np.quantile(exp, np.linspace(0.0, 1.0, n_bins + 1)))
    if len(edges) < 2:
        edges = np.array([-np.inf, np.inf])
    else:
        edges = edges.copy()
        edges[0] = -np.inf
        edges[-1] = np.inf
    exp_cnt, _ = np.histogram(exp, bins=edges)
    act_cnt, _ = np.histogram(act, bins=edges)
    p_exp = np.clip(exp_cnt / exp_cnt.sum(), eps, None)
    p_exp = p_exp / p_exp.sum()
    p_act = np.clip(act_cnt / act_cnt.sum(), eps, None)
    p_act = p_act / p_act.sum()
    psi = round(float(np.sum((p_act - p_exp) * np.log(p_act / p_exp))), 4)
    if psi < 0.10:
        status = "Stable"
    elif psi < 0.25:
        status = "Moderate Drift"
    else:
        status = "Severe Drift"
    return {"psi": psi, "drift_status": status}

def compute_fairness_gaps(y_true, y_pred, sensitive_attr):

        m = gr == g
        yt_g, yp_g = yt[m], yp[m]
        sels.append(float(np.mean(yp_g == 1)))
        tp = int(np.sum((yt_g == 1) & (yp_g == 1)))
        fn = int(np.sum((yt_g == 1) & (yp_g == 0)))
        fp = int(np.sum((yt_g == 0) & (yp_g == 1)))
        tn = int(np.sum((yt_g == 0) & (yp_g == 0)))

        fprs.append(fp / (fp + tn) if (fp + tn) > 0 else 0.0)
    eo = max(tprs) - min(tprs)
    fpr_d = max(fprs) - min(fprs)
    return {

        "max_fpr_diff": round(fpr_d, 4),

def subgroup_calibration_audit(y_true, y_prob, groups, n_bins=5):
    """Audit equal-width ECE and Brier score across sorted subgroups."""
    yt = np.asarray(y_true, dtype=float)
    yp = np.asarray(y_prob, dtype=float)
    gr = np.asarray(groups)
    edges = np.linspace(0.0, 1.0, n_bins + 1)
    rows, raw_eces = [], {}
    for g in sorted(pd.unique(gr)):
        m = gr == g
        yt_g, yp_g = yt[m], yp[m]
        n_g = int(np.sum(m))
        ece = 0.0
        for i in range(n_bins):
            lo, hi = edges[i], edges[i + 1]
            if i < n_bins - 1:
                bm = (yp_g >= lo) & (yp_g < hi)
            else:
                bm = (yp_g >= lo) & (yp_g <= hi)
            cnt = int(np.sum(bm))
            if cnt > 0:
                gap = abs(float(yt_g[bm].mean()) - float(yp_g[bm].mean()))
                ece += (cnt / n_g) * gap
        g_val = g.item() if hasattr(g, "item") else g
        raw_eces[str(g_val)] = ece
        rows.append({
            "group": g_val,
            "n": n_g,
            "ece": round(ece, 4),
            "brier": round(float(brier_score_loss(yt_g, yp_g)), 4),
        })
    worst = max(raw_eces, key=raw_eces.get)
    max_gap = round(max(raw_eces.values()) - min(raw_eces.values()), 4)
    return {
        "per_group": pd.DataFrame(
            rows, columns=["group", "n", "ece", "brier"]
        ),
        "worst_ece_group": worst,
        "max_ece_gap": max_gap,
    }

def population_stability_index(expected, actual, n_bins=10, eps=1e-6):
    """Compute PSI and drift severity status from quantile bins."""
    exp = np.asarray(expected, dtype=float)
    act = np.asarray(actual, dtype=float)
    if len(exp) == 0 or len(act) == 0:
        raise ValueError("expected and actual arrays must be non-empty")
    edges = np.unique(np.quantile(exp, np.linspace(0.0, 1.0, n_bins + 1)))
    if len(edges) < 2:
        edges = np.array([-np.inf, np.inf])
    else:
        edges = edges.copy()
        edges[0] = -np.inf
        edges[-1] = np.inf
    exp_cnt, _ = np.histogram(exp, bins=edges)
    act_cnt, _ = np.histogram(act, bins=edges)
    p_exp = np.clip(exp_cnt / exp_cnt.sum(), eps, None)
    p_exp = p_exp / p_exp.sum()
    p_act = np.clip(act_cnt / act_cnt.sum(), eps, None)
    p_act = p_act / p_act.sum()
    psi = round(float(np.sum((p_act - p_exp) * np.log(p_act / p_exp))), 4)
    if psi < 0.10:
        status = "Stable"
    elif psi < 0.25:
        status = "Moderate Drift"
    else:
        status = "Severe Drift"
    return {"psi": psi, "drift_status": status}

def calibrate_group_thresholds_for_tpr(
    y_true, y_prob, groups, target_tpr=0.75
):
    """Pick highest per-group cutoff achieving TPR >= target_tpr."""
    if not (0.0 < target_tpr <= 1.0):
        raise ValueError("target_tpr must lie in (0, 1]")
    yt = np.asarray(y_true, dtype=int)
    yp = np.asarray(y_prob, dtype=float)
    gr = np.asarray(groups)
    out = {}
    for g in sorted(pd.unique(gr)):
        m = gr == g
        yt_g, yp_g = yt[m], yp[m]
        n_pos = int(np.sum(yt_g == 1))
        best_t = 0.0
        if n_pos > 0:
            for t in np.sort(np.unique(yp_g))[::-1]:

                    best_t = float(t)
                    break

    return out

34.8.4 D. Debugging Post-Mortem — Five High-Impact Responsible AI Pitfalls

  • Pitfall 1 — Auditing on In-Sample or Threshold-Leaked Predictions: Selecting Youden’s \(J\) or group thresholds on the test set fabricates artificially small fairness gaps. Always reserve a separate validation split for threshold tuning and evaluate on an untouched test cohort.
  • Pitfall 2 — Crashing on Single-Class Small Strata: In real demographic tables, small subgroups often contain zero positive outcomes. Always check len(np.unique(yt_g)) == 2 before calling roc_auc_score and emit np.nan cleanly.
  • Pitfall 3 — Dropping Out-of-Range Values in PSI: Keeping finite quantile endpoints [min(expected), max(expected)] causes extreme shifted values during clinical shocks to fall outside np.histogram bins. Always set edges[0] = -np.inf and edges[-1] = np.inf, clip shares to >= eps, and re-normalize.
  • Pitfall 4 — Mutating Caller DataFrames During Error Slicing: Writing df["y_prob"] = y_prob directly mutates the researcher’s cohort table (and triggers Pandas 3.x Copy-on-Write surprises). Always start with work = df.copy().
  • Pitfall 5 — Treating Post-Processing as a Cure-All: Group thresholds fix score-offset disparities (like maternal_anemia across residence), but cannot rescue a subgroup where within-group discrimination is poor (Urban stunting AUC 0.1280). When ranking itself fails, inspect worst FN/FP slices and collect better clinical features.
