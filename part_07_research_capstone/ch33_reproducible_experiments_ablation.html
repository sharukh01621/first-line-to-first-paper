Learning Objectives

By the end of this chapter, you will be able to:

  1. Enforce bit-exact multi-library determinism across Python’s random, numpy.random, and torch.manual_seed before any data split or parameter initialization.
  2. Replace hardcoded notebook magic numbers with validated YAML experiment configs (yaml.safe_load) and append-only UTF-8 JSONL experiment ledgers tested safely inside tempfile.TemporaryDirectory().
  3. Quantify split and initialization variance via multi-seed cross-validation (mean ± SD, min, max), eliminating single-seed cherry-picking (“seed hacking”).
  4. Compute non-parametric percentile bootstrap confidence intervals (bootstrap_metric_ci) and run paired bootstrap (paired_bootstrap_test) vs. exact binomial McNemar (mcnemar_exact_comparison) hypothesis tests on paired model predictions.
  5. Design and execute systematic leave-one-group-out feature ablations (run_feature_ablation and cluster-aware GroupKFold ablations) to isolate which clinical domains truly carry predictive signal.
  6. Distinguish statistically significant thresholded classification gains (McNemar) from continuous rank-order equivalence (paired bootstrap ROC-AUC) when writing Methods and Results sections.

33.1 Stage 1 — First-Principles Intuition: Why Single-Seed Notebooks Fail Peer Review

Across Parts V and VI, you built classical ML pipelines and PyTorch neural architectures. Now imagine submitting your manuscript to Nature Digital Medicine, The Lancet Digital Health, or NeurIPS. Reviewer 2 asks three brutal questions:

  • “You reported ROC-AUC = 0.7050 for Logistic Regression and 0.7010 for Random Forest on one split (seed=7). Does that 0.004 gap survive across five random seeds—and is it statistically significant?”
  • “Which clinical predictors actually drove your model—demographics, antenatal care access, socioeconomic wealth, or maternal nutrition? Show us a formal ablation table.”
  • “Where are the exact configuration files and run logs that produced Table 2?”

Without an experimental harness, research code silently fails in four classic ways:

  • Single-Seed Illusion (“Seed Hacking”): On a 470-household survey, simply changing the StratifiedKFold seed from 7 to 84 swings Logistic Regression ROC-AUC from 0.7050 down to 0.6769—a 2.8-point swing caused purely by random fold assignment! Reporting one lucky seed mistakes noise for discovery.
  • Unpaired or Bare-Number Comparisons: Publishing "Model B = 0.696, Model A = 0.695" without confidence intervals or paired hypothesis tests hides huge sampling uncertainty (\(\text{SE} \approx 0.035\) on \(n = 470\)). Worse, comparing two independent CIs throws away the massive statistical power gained by evaluating both models on the exact same resampled patients (paired bootstrap and McNemar’s test).
  • Hidden Hyperparameters & Overwritten Logs: Editing cv_splits = 5 to 3 in cell 14 without saving a YAML config or appending a JSONL ledger row makes last week’s best table impossible to reproduce.
  • Unproven Complexity (Missing Ablations): Claiming that every collected biomarker improves prediction without a leave-one-group-out ablation study hides redundant or noisy covariates that actually hurt out-of-cluster generalization.
NoteMental Model — Four Pillars of a Reviewer-Proof Experiment

Treat every publishable ML study as an auditable laboratory protocol:

  1. Declarative Spec (YAML + Multi-Library Seeds): Every run begins from a validated YAML file and locked Python/NumPy/PyTorch seeds.
  2. Multi-Seed Estimation: Evaluate leak-free Pipeline factories across \(S \ge 5\) seeds so you report mean ± SD alongside [min, max].
  3. Paired Statistical Verification: Attach percentile bootstrap 95% CIs to every headline metric, and compare rival models on identical test cohorts via paired bootstrap (continuous scores) and exact McNemar’s test (binary clinical decisions).
  4. Systematic Ablation & Append-Only Ledger: Drop one domain group at a time to measure \(\Delta_{\text{AUC}} = \text{AUC}_{\text{drop}} - \text{AUC}_{\text{full}}\), and append every completed run to a durable .jsonl ledger.

WarningTwo Subtle Experimental Traps to Guard Against
  1. Python’s bool Subclasses int: Writing isinstance(cv_splits, int) returns True for cv_splits: true in YAML! Always validate integer config fields with isinstance(v, int) and not isinstance(v, bool).
  2. Degenerate Resamples & Zero Discordance: On imbalanced clinical outcomes, a bootstrap resample can occasionally contain only class 0, crashing roc_auc_score unless skipped (len(np.unique(y_b)) < 2). Similarly, exact McNemar (binomtest(min(b, c), b + c, 0.5)) crashes if b + c == 0 unless you return p_value = 1.0.

33.3.2 Multi-Library Deterministic Seed Control (set_all_seeds)

def set_all_seeds(seed=42):
    """Lock Python, NumPy, and PyTorch RNGs and verify scalar draws."""
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    return {
        "seed": int(seed),
        "py_draw": round(float(random.random()), 6),
        "np_draw": round(float(np.random.rand()), 6),
        "torch_draw": round(float(torch.rand(1).item()), 6),
    }

run1 = set_all_seeds(42)
run2 = set_all_seeds(42)
run3 = set_all_seeds(101)
print("Run 1 (seed=42): ", run1)
print("Run 2 (seed=42): ", run2)
print("Bit-exact match?:", run1 == run2)
print("Run 3 (seed=101):", run3)

33.3.3 Config-Driven Runs With YAML & Append-Only JSONL Ledgers

def load_and_validate_config(yaml_path):
    """Load YAML config and validate required experiment fields."""
    with open(yaml_path, "r", encoding="utf-8") as f:
        cfg = yaml.safe_load(f)
    if not isinstance(cfg, dict):
        raise ValueError("Config YAML must be a mapping.")
    required = {"experiment_name", "seeds", "model_type", "cv_splits"}
    missing = required - set(cfg.keys())
    if missing:
        raise ValueError(
            f"Missing required config keys: {sorted(missing)}"
        )
    seeds = cfg["seeds"]
    valid_seeds = (
        isinstance(seeds, list)
        and len(seeds) > 0
        and all(
            isinstance(s, int) and not isinstance(s, bool)
            for s in seeds
        )
    )
    if not valid_seeds:
        raise ValueError("seeds must be a non-empty list of ints.")
    cv = cfg["cv_splits"]
    if not isinstance(cv, int) or isinstance(cv, bool) or cv < 2:
        raise ValueError("cv_splits must be an integer >= 2.")
    return cfg

def append_experiment_ledger(ledger_path, run_record):
    """Append one UTF-8 JSON line and return total non-empty lines."""
    path = Path(ledger_path)
    path.parent.mkdir(parents=True, exist_ok=True)
    with open(path, "a", encoding="utf-8") as f:
        f.write(json.dumps(run_record, sort_keys=True) + "\n")
    with open(path, "r", encoding="utf-8") as f:
        return int(sum(1 for line in f if line.strip()))

sample_cfg = {
    "experiment_name": "mch_stunting_lr_v1",
    "seeds": [7, 21, 42, 84, 105],
    "model_type": "logistic_regression",
    "cv_splits": 5,
}
with tempfile.TemporaryDirectory() as tmpdir:
    cfg_file = Path(tmpdir) / "exp_lr.yaml"
    ledger_file = Path(tmpdir) / "experiments.jsonl"
    cfg_file.write_text(
        yaml.safe_dump(sample_cfg, sort_keys=False), encoding="utf-8"
    )
    cfg = load_and_validate_config(cfg_file)
    n1 = append_experiment_ledger(
        ledger_file, {"exp": cfg["experiment_name"], "auc": 0.6942}
    )
    n2 = append_experiment_ledger(
        ledger_file, {"exp": "mch_stunting_rf_v1", "auc": 0.6998}
    )
    last_ln = ledger_file.read_text(encoding="utf-8").splitlines()[-1]
    print("Validated:", cfg["experiment_name"], "| seeds:", cfg["seeds"])
    print("Ledger entries after 2 runs:", n2)
    print("Last JSONL line:", last_ln)

Notice three production engineering habits working together:

  • yaml.safe_load + Fail-Fast Schema Check: Bad configs (cv_splits: 1, empty seeds, or typos in key names) fail in millisecond 1—never after 4 hours of GPU training.
  • Append-Only JSONL (sort_keys=True): Unlike a single giant JSON array (which corrupts if a job dies mid-write), JSON Lines appends one atomic line per run and loads directly into Pandas via pd.read_json("experiments.jsonl", lines=True).
  • tempfile.TemporaryDirectory(): Keeps unit tests and walkthrough demos 100% isolated so stray .yaml or .jsonl files never pollute Git.

33.3.4 Multi-Seed Cross-Validation Reporting (multi_seed_cv_benchmark)

def multi_seed_cv_benchmark(
    X_in, y_in, model_factory, seeds, cv_splits=5
):
    """Benchmark a model factory across multiple CV split seeds."""
    raw = []
    for s in seeds:
        skf = StratifiedKFold(
            n_splits=cv_splits, shuffle=True, random_state=s
        )
        pipe = Pipeline([
            ("scaler", StandardScaler()),
            ("model", model_factory()),
        ])
        sc = cross_val_score(pipe, X_in, y_in, cv=skf, scoring="roc_auc")
        raw.append(float(sc.mean()))
    return {
        "n_seeds": int(len(seeds)),
        "mean_auc": round(float(np.mean(raw)), 4),
        "std_auc": round(float(np.std(raw)), 4),
        "min_auc": round(float(np.min(raw)), 4),
        "max_auc": round(float(np.max(raw)), 4),
        "seed_scores": [round(v, 4) for v in raw],
    }

seeds5 = [7, 21, 42, 84, 105]
lr_bench = multi_seed_cv_benchmark(
    X, y, lambda: LogisticRegression(max_iter=500), seeds5
)
rf_bench = multi_seed_cv_benchmark(
    X, y,
    lambda: RandomForestClassifier(
        n_estimators=80, max_depth=5, random_state=42
    ),
    seeds5,
)
print("LR 5-seed:", lr_bench)
print("RF 5-seed:", rf_bench)

33.3.5 Bootstrap CIs, Paired Bootstrap & Exact McNemar Comparison

def bootstrap_metric_ci(
    y_true, y_score, metric_fn, n_boot=300, alpha=0.05, seed=42
):
    """Compute non-parametric percentile bootstrap CI & SE."""
    yt, ys = np.asarray(y_true), np.asarray(y_score)
    point = float(metric_fn(yt, ys))
    rng = np.random.default_rng(seed)
    boots = []
    for _ in range(n_boot):
        idx = rng.integers(0, len(yt), size=len(yt))
        if len(np.unique(yt[idx])) < 2:
            continue
        boots.append(float(metric_fn(yt[idx], ys[idx])))
    lo, hi = np.percentile(
        boots, [100 * alpha / 2, 100 * (1 - alpha / 2)]
    )
    return {
        "point": round(point, 4),
        "ci_low": round(float(lo), 4),
        "ci_high": round(float(hi), 4),
        "se": round(float(np.std(boots, ddof=1)), 4),
    }

def paired_bootstrap_test(
    y_true, score_a, score_b, metric_fn, n_boot=400, seed=42
):
    """Run paired bootstrap test of metric(B) - metric(A)."""
    yt, sa, sb = (
        np.asarray(y_true), np.asarray(score_a), np.asarray(score_b)
    )
    delta_pt = float(metric_fn(yt, sb) - metric_fn(yt, sa))
    rng = np.random.default_rng(seed)
    deltas = []
    for _ in range(n_boot):
        idx = rng.integers(0, len(yt), size=len(yt))
        if len(np.unique(yt[idx])) < 2:
            continue
        d = float(
            metric_fn(yt[idx], sb[idx]) - metric_fn(yt[idx], sa[idx])
        )
        deltas.append(d)
    arr = np.asarray(deltas)
    lo, hi = np.percentile(arr, [2.5, 97.5])
    p_raw = 2.0 * min(float(np.mean(arr <= 0)), float(np.mean(arr >= 0)))
    p_val = float(np.clip(p_raw, 0.0, 1.0))
    return {
        "delta_point": round(delta_pt, 4),
        "ci_low": round(float(lo), 4),
        "ci_high": round(float(hi), 4),
        "p_value_two_sided": round(p_val, 4),
    }

def mcnemar_exact_comparison(y_true, pred_a, pred_b):
    """Run exact binomial McNemar test on paired binary predictions."""
    yt, pa, pb = (
        np.asarray(y_true), np.asarray(pred_a), np.asarray(pred_b)
    )
    a_ok, b_ok = (pa == yt), (pb == yt)
    b = int(np.sum(a_ok & ~b_ok))
    c = int(np.sum(~a_ok & b_ok))
    p_val = (
        1.0 if (b + c) == 0
        else float(binomtest(min(b, c), b + c, 0.5).pvalue)
    )
    return {
        "b_only_a_correct": b,
        "c_only_b_correct": c,
        "p_value": round(p_val, 4),
        "significant_05": bool(p_val < 0.05),
    }

skf_oof = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
pipe_lr = Pipeline([
    ("scaler", StandardScaler()),
    ("model", LogisticRegression(max_iter=500)),
])
pipe_rf = Pipeline([
    ("scaler", StandardScaler()),
    ("model", RandomForestClassifier(
        n_estimators=80, max_depth=5, random_state=42
    )),
])
prob_lr = cross_val_predict(
    pipe_lr, X, y, cv=skf_oof, method="predict_proba"
)[:, 1]
prob_rf = cross_val_predict(
    pipe_rf, X, y, cv=skf_oof, method="predict_proba"
)[:, 1]
print("LR 95% CI:", bootstrap_metric_ci(y, prob_lr, roc_auc_score))
print("RF 95% CI:", bootstrap_metric_ci(y, prob_rf, roc_auc_score))
print(
    "Paired Bootstrap (LR - RF):",
    paired_bootstrap_test(y, prob_rf, prob_lr, roc_auc_score),
)
pred_rf = (prob_rf >= 0.25).astype(int)
pred_lr = (prob_lr >= 0.25).astype(int)
print(
    "McNemar Exact (RF vs LR @ t=0.25):",
    mcnemar_exact_comparison(y, pred_rf, pred_lr),
)

def run_feature_ablation(
    X_df, y_in, feature_groups, model_factory, cv_splits=5, seed=42
):
    """Run leave-one-group-out feature ablation under Stratified CV."""
    skf = StratifiedKFold(
        n_splits=cv_splits, shuffle=True, random_state=seed
    )
    pipe_full = Pipeline([
        ("scaler", StandardScaler()),
        ("model", model_factory()),
    ])
    full_sc = cross_val_score(
        pipe_full, X_df, y_in, cv=skf, scoring="roc_auc"
    )
    full_auc = float(full_sc.mean())
    rows = [{
        "ablation": "full_model",
        "mean_auc": round(full_auc, 4),
        "std_auc": round(float(full_sc.std()), 4),
        "delta_vs_full": 0.0,
    }]
    for gname, cols in feature_groups.items():
        pipe_g = Pipeline([
            ("scaler", StandardScaler()),
            ("model", model_factory()),
        ])
        sc = cross_val_score(
            pipe_g, X_df.drop(columns=cols), y_in,
            cv=skf, scoring="roc_auc",
        )
        m = float(sc.mean())
        rows.append({
            "ablation": f"drop_{gname}",
            "mean_auc": round(m, 4),
            "std_auc": round(float(sc.std()), 4),
            "delta_vs_full": round(m - full_auc, 4),
        })
    return pd.DataFrame(rows)

def set_all_seeds(seed=42):

def load_and_validate_config(yaml_path):
    """Load YAML config and validate required experiment fields."""
    with open(yaml_path, "r", encoding="utf-8") as f:
        cfg = yaml.safe_load(f)
    if not isinstance(cfg, dict):
        raise ValueError("Config YAML must deserialize to a dict.")
    required = {"experiment_name", "seeds", "model_type", "cv_splits"}
    missing = required - set(cfg.keys())
    if missing:
        raise ValueError(f"Missing required keys: {sorted(missing)}")
    seeds = cfg["seeds"]
    valid_seeds = (
        isinstance(seeds, list)
        and len(seeds) > 0
        and all(
            isinstance(s, int) and not isinstance(s, bool)
            for s in seeds
        )
    )
    if not valid_seeds:
        raise ValueError("seeds must be a non-empty list of ints.")
    cv = cfg["cv_splits"]
    if not isinstance(cv, int) or isinstance(cv, bool) or cv < 2:
        raise ValueError("cv_splits must be an integer >= 2.")
    return cfg

# To-Do 33.3
def bootstrap_metric_ci(
    y_true, y_score, metric_fn, n_boot=300, alpha=0.05, seed=42
):
    """Compute percentile bootstrap CI and SE for any scoring fn."""
    yt = np.asarray(y_true)
    ys = np.asarray(y_score)
    point = float(metric_fn(yt, ys))
    rng = np.random.default_rng(seed)
    boots = []
    for _ in range(n_boot):
        idx = rng.integers(0, len(yt), size=len(yt))
        if len(np.unique(yt[idx])) < 2:
            continue
        boots.append(float(metric_fn(yt[idx], ys[idx])))
    lo, hi = np.percentile(
        boots, [100 * alpha / 2, 100 * (1 - alpha / 2)]
    )
    return {
        "point": round(point, 4),
        "ci_low": round(float(lo), 4),
        "ci_high": round(float(hi), 4),
        "se": round(float(np.std(boots, ddof=1)), 4),
    }

# To-Do 33.4
def paired_bootstrap_test(
    y_true, score_a, score_b, metric_fn, n_boot=400, seed=42
):
    """Run paired bootstrap test comparing score_b minus score_a."""
    yt = np.asarray(y_true)
    sa = np.asarray(score_a)
    sb = np.asarray(score_b)
    delta_point = float(metric_fn(yt, sb) - metric_fn(yt, sa))
    rng = np.random.default_rng(seed)
    deltas = []
    for _ in range(n_boot):
        idx = rng.integers(0, len(yt), size=len(yt))
        if len(np.unique(yt[idx])) < 2:
            continue
        d = float(
            metric_fn(yt[idx], sb[idx]) - metric_fn(yt[idx], sa[idx])
        )
        deltas.append(d)
    arr = np.asarray(deltas)
    lo, hi = np.percentile(arr, [2.5, 97.5])
    p_raw = 2.0 * min(float(np.mean(arr <= 0)), float(np.mean(arr >= 0)))
    p_val = float(np.clip(p_raw, 0.0, 1.0))
    return {
        "delta_point": round(delta_point, 4),
        "ci_low": round(float(lo), 4),
        "ci_high": round(float(hi), 4),
        "p_value_two_sided": round(p_val, 4),
    }

def mcnemar_exact_comparison(y_true, pred_a, pred_b):
    """Run exact two-sided McNemar binomial test on paired preds."""
    yt = np.asarray(y_true)
    pa = np.asarray(pred_a)
    pb = np.asarray(pred_b)
    a_ok = pa == yt
    b_ok = pb == yt
    b = int(np.sum(a_ok & ~b_ok))
    c = int(np.sum(~a_ok & b_ok))
    p_val = (
        1.0 if (b + c) == 0
        else float(binomtest(min(b, c), b + c, 0.5).pvalue)
    )
    return {
        "b_only_a_correct": b,
        "c_only_b_correct": c,
        "p_value": round(p_val, 4),
        "significant_05": bool(p_val < 0.05),
    }

def mch_ablation_study_report(mch_df, seed=42):
    """Run cluster-aware GroupKFold ablation study on MCH stunting."""
    work = mch_df.copy()
    work["residence"] = (
        work["residence"].astype(str).str.strip().str.title()
    )
    work["anc_visits"] = work["anc_visits"].replace(999, np.nan)
    work["is_urban"] = (work["residence"] == "Urban").astype(int)
    wealth_map = {
        "Poorest": 1, "Poorer": 2, "Middle": 3,
        "Richer": 4, "Richest": 5,
    }
    work["wealth_rank"] = (
        work["wealth_quintile"].astype(str).str.strip()
        .str.title().map(wealth_map)
    )
    feature_groups = {
        "demographics": ["maternal_age_years", "is_urban"],
        "care_access": ["anc_visits"],
        "socioeconomic": ["wealth_rank"],
        "nutrition": ["maternal_hb_g_dl"],
    }
    all_cols = [c for cols in feature_groups.values() for c in cols]
    clean = (
        work[all_cols + ["child_stunted", "cluster_id"]]
        .dropna()
        .reset_index(drop=True)
    )
    X = clean[all_cols]
    y = clean["child_stunted"].astype(int)
    clusters = clean["cluster_id"]

    gkf = GroupKFold(n_splits=5)
    pipe = Pipeline([
        ("scaler", StandardScaler()),
        ("model", LogisticRegression(max_iter=500)),
    ])
    full_sc = cross_val_score(
        pipe, X, y, groups=clusters, cv=gkf, scoring="roc_auc"
    )
    full_auc = float(full_sc.mean())
    rows = [{
        "ablation": "full_model",
        "mean_auc": round(full_auc, 4),
        "std_auc": round(float(full_sc.std()), 4),
        "delta_vs_full": 0.0,
    }]
    for gname, cols in feature_groups.items():
        sc = cross_val_score(
            pipe, X.drop(columns=cols), y,
            groups=clusters, cv=gkf, scoring="roc_auc",
        )
        m = float(sc.mean())
        rows.append({
            "ablation": f"drop_{gname}",
            "mean_auc": round(m, 4),
            "std_auc": round(float(sc.std()), 4),
            "delta_vs_full": round(m - full_auc, 4),
        })
    tbl = pd.DataFrame(rows)
    drops = tbl[tbl["ablation"] != "full_model"]
    critical = str(
        drops.loc[drops["delta_vs_full"].idxmin(), "ablation"]
    ).removeprefix("drop_")
    return {
        "full_auc": round(full_auc, 4),
        "ablation_table": tbl,
        "most_critical_group": critical,
    }

33.8.4 D. Debugging Post-Mortem: Top 3 Chapter 33 Failure Modes

  1. Ignoring bool Subclassing int & Missing Schema Validation: Passing seeds: [true] or cv_splits: 1 silently bypasses naive isinstance(..., int) checks. Always validate YAML configs strictly (isinstance(x, int) and not isinstance(x, bool)) before launching multi-seed loops.
  2. Crashing on Degenerate Bootstrap Draws or Zero McNemar Discordance: Rare-event clinical cohorts occasionally draw a single-class resample (breaking roc_auc_score), and identical classifiers yield b + c == 0 (breaking binomtest). Always skip single-class resamples, clip two-sided bootstrap p-values to [0.0, 1.0], and return 1.0 when b + c == 0.
  3. Flipping Ablation Delta Sign or Keeping the "drop_" Prefix: Define delta_vs_full = ablated_auc - full_auc so negative deltas unambiguously flag features whose removal hurt performance (like socioeconomic dropping cluster-CV AUC by -0.0597), and strip "drop_" when reporting the winning group name.
