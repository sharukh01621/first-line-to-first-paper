36.1.1 Three Mathematical Pillars of Clinical Publication Readiness

Beyond raw ROC-AUC, top biomedical and global-health journals (The Lancet Global Health, BMJ, PLOS Medicine, Nature Medicine) evaluate three quantitative pillars before accepting a predictive modeling manuscript:

  1. Confounding-Adjusted Epidemiological Effect Sizes (aOR):

    In univariate Table 1 comparisons, antenatal care visits (anc_visits) and urban residence (is_urban) both look strongly protective against childhood stunting (\(p = 0.0006\) and \(p = 0.0416\)). Fitting a multivariable logistic regression model \(\text{logit}(P(Y = 1 \mid X)) = \beta_0 + \sum_j \beta_j X_j\) yields adjusted Odds Ratios:

    \[\text{aOR}_j = e^{\beta_j}, \qquad 95\%\ \text{CI} = \left[\,e^{\beta_j - 1.96\,\text{SE}_j},\; e^{\beta_j + 1.96\,\text{SE}_j}\,\right]\]

    As you will prove in Stage 3, once household wealth (wealth_rank) enters the model (\(\text{aOR} = 0.5835\), \(p < 0.0001\)), crude associations for anc_visits and is_urban attenuate—demonstrating classic socioeconomic confounding.

  2. Subgroup Algorithmic Fairness at Youden’s \(J\) Threshold:

    For any out-of-fold probability score \(\hat{p}_i\), Youden’s optimal clinical operating threshold maximizes sensitivity plus specificity minus one:

    \[t^* = \arg\max_{t} \bigl(\text{TPR}(t) - \text{FPR}(t)\bigr)\]

    At \(t^*\), we audit Rural (\(g = 0\)) vs. Urban (\(g = 1\)) disparities via Demographic Parity Difference \(\lvert P(\hat{Y}=1 \mid g=0) - P(\hat{Y}=1 \mid g=1) \rvert\) and Equal Opportunity Difference \(\lvert \text{TPR}_{g=0} - \text{TPR}_{g=1} \rvert\).

  3. Decision Curve Analysis (Vickers & Elkin, 2006):

    A model with \(\text{AUC} = 0.72\) still begs a clinical question: “If a community health worker screens children above probability threshold \(t \in (0, 1)\), does the model do more good than referring everyone or referring no one?” At threshold \(t\), the clinician implicitly weights each false positive at \(t / (1 - t)\) times a true positive, giving Clinical Net Benefit:

    \[\text{NB}_{\text{model}}(t) = \frac{\text{TP}_t}{N} - \frac{\text{FP}_t}{N}\!\left(\frac{t}{1 - t}\right), \qquad \text{NB}_{\text{all}}(t) = \pi - (1 - \pi)\!\left(\frac{t}{1 - t}\right)\]

    where \(\pi = \frac{1}{N}\sum_{i=1}^N y_i\) is stunting prevalence and \(\text{NB}_{\text{none}}(t) = 0\). A model earns clinical deployment strictly where \(\text{NB}_{\text{model}}(t) > \max\bigl(\text{NB}_{\text{all}}(t),\, 0\bigr)\).

WarningZero Target Leakage & Zero Repository Pollution

Two cardinal engineering rules govern every flagship study:

  1. Never Include Derived Outcomes as Features: In mch_survey_sample, child_stunted is defined directly from child_haz < -2.0. Including child_haz as a predictor leaks the label and inflates AUC near 1.00—an instant desk-rejection offense!
  2. Isolate Ephemeral Exports: Always write test release bundles inside tempfile.TemporaryDirectory() during development and automated QA so stray CSVs or binary .joblib files never pollute your Git repository.

36.3.2 Survey Cleaning, Journal Table 1 & Multivariable Adjusted Odds Ratios

WEALTH_MAP = {
    "Poorest": 1, "Poorer": 2, "Middle": 3,
    "Richer": 4, "Richest": 5,
}
FEATURES = [
    "maternal_age_years", "anc_visits",
    "maternal_hb_g_dl", "is_urban", "wealth_rank",
]


def clean_mch_survey(mch_df):
    """Clean survey sentinels & casing without mutating input."""
    df = mch_df.copy()
    anc = pd.to_numeric(df["anc_visits"], errors="coerce")
    df["anc_visits"] = anc.replace(999, np.nan)
    df["residence"] = (
        df["residence"].astype(str).str.strip().str.title()
    )
    df["is_urban"] = (df["residence"] == "Urban").astype(int)
    df["wealth_rank"] = df["wealth_quintile"].map(WEALTH_MAP)
    df = df.dropna(subset=["child_stunted"]).copy()
    df["child_stunted"] = df["child_stunted"].astype(int)
    return df


def build_publication_table1(mch_df):
    """Build Journal Table 1 comparing non-stunted vs stunted."""
    df = clean_mch_survey(mch_df)
    g0 = df[df["child_stunted"] == 0]
    g1 = df[df["child_stunted"] == 1]
    rows = []
    for col in ["maternal_age_years", "anc_visits", "maternal_hb_g_dl"]:
        s0, s1 = g0[col].dropna(), g1[col].dropna()
        _, p_val = stats.ttest_ind(s0, s1, equal_var=False)
        rows.append({
            "variable": col,
            "not_stunted": f"{s0.mean():.2f} ± {s0.std(ddof=1):.2f}",
            "stunted": f"{s1.mean():.2f} ± {s1.std(ddof=1):.2f}",
            "p_value": round(float(p_val), 4),
        })
    ct = pd.crosstab(df["child_stunted"], df["is_urban"])
    _, p_chi, _, _ = stats.chi2_contingency(ct, correction=False)
    c0, pct0 = int(g0["is_urban"].sum()), 100.0 * g0["is_urban"].mean()
    c1, pct1 = int(g1["is_urban"].sum()), 100.0 * g1["is_urban"].mean()
    rows.append({
        "variable": "is_urban",
        "not_stunted": f"{c0} ({pct0:.1f}%)",
        "stunted": f"{c1} ({pct1:.1f}%)",
        "p_value": round(float(p_chi), 4),
    })
    return pd.DataFrame(rows)

36.3.3 4-Model Cluster-Grouped Benchmark (GroupKFold + PyTorch MLP)

def _fit_predict_mlp_fold(X_tr_df, y_tr, X_va_df, fold_seed):
    """Train leak-free 16-unit PyTorch MLP on one CV fold."""
    imp = SimpleImputer(strategy="median")
    scl = StandardScaler()
    X_tr_s = scl.fit_transform(imp.fit_transform(X_tr_df))
    X_va_s = scl.transform(imp.transform(X_va_df))
    torch.set_num_threads(1)
    torch.manual_seed(fold_seed)
    net = nn.Sequential(
        nn.Linear(X_tr_s.shape[1], 16),
        nn.ReLU(),
        nn.Linear(16, 1),
    )
    opt = torch.optim.Adam(net.parameters(), lr=0.02)
    loss_fn = nn.BCEWithLogitsLoss()
    xt = torch.tensor(X_tr_s, dtype=torch.float32)
    yt = torch.tensor(y_tr, dtype=torch.float32).unsqueeze(1)
    xv = torch.tensor(X_va_s, dtype=torch.float32)
    net.train()
    for _ in range(30):
        opt.zero_grad()
        loss_fn(net(xt), yt).backward()
        opt.step()
    net.eval()
    with torch.no_grad():
        return torch.sigmoid(net(xv)).squeeze(-1).numpy()


def run_capstone_model_benchmark(mch_df, seed=42):
    """Benchmark 4 model families under 5-fold cluster GroupKFold."""
    df = clean_mch_survey(mch_df)
    X = df[FEATURES].astype(float)
    y = df["child_stunted"].to_numpy()
    groups = df["cluster_id"].to_numpy()
    gkf = GroupKFold(n_splits=5)

    sk_builders = {
        "LogisticRegression": lambda: Pipeline([
            ("imp", SimpleImputer(strategy="median")),
            ("scl", StandardScaler()),
            ("clf", LogisticRegression(max_iter=1000, random_state=seed)),
        ]),
        "RandomForestClassifier": lambda: Pipeline([
            ("imp", SimpleImputer(strategy="median")),
            ("clf", RandomForestClassifier(
                n_estimators=80, max_depth=4, random_state=seed
            )),
        ]),
        "HistGradientBoostingClassifier": lambda: Pipeline([
            ("imp", SimpleImputer(strategy="median")),
            ("clf", HistGradientBoostingClassifier(
                max_iter=50, max_depth=3, random_state=seed
            )),
        ]),
    }
    rows = []
    for name, make_pipe in sk_builders.items():
        aucs, briers = [], []
        for tr, va in gkf.split(X, y, groups):
            pipe = make_pipe()
            pipe.fit(X.iloc[tr], y[tr])
            probs = pipe.predict_proba(X.iloc[va])[:, 1]
            aucs.append(roc_auc_score(y[va], probs))
            briers.append(brier_score_loss(y[va], probs))
        rows.append({
            "model": name,
            "mean_auc": round(float(np.mean(aucs)), 4),
            "std_auc": round(float(np.std(aucs)), 4),
            "mean_brier": round(float(np.mean(briers)), 4),
        })

    mlp_aucs, mlp_briers = [], []
    for fold_i, (tr, va) in enumerate(gkf.split(X, y, groups)):
        probs = _fit_predict_mlp_fold(
            X.iloc[tr], y[tr], X.iloc[va], seed + fold_i
        )
        mlp_aucs.append(roc_auc_score(y[va], probs))
        mlp_briers.append(brier_score_loss(y[va], probs))
    rows.append({
        "model": "PyTorch_MLP",
        "mean_auc": round(float(np.mean(mlp_aucs)), 4),
        "std_auc": round(float(np.std(mlp_aucs)), 4),
        "mean_brier": round(float(np.mean(mlp_briers)), 4),
    })
    return (
        pd.DataFrame(rows)
        .sort_values("mean_auc", ascending=False)
        .reset_index(drop=True)
    )


leaderboard_df = run_capstone_model_benchmark(mch_raw, seed=42)
print(leaderboard_df.to_string(index=False))

36.3.5 Decision Curve Analysis (Vickers & Elkin, 2006)

def compute_clinical_net_benefit(y_true, y_prob, thresholds):
    """Compute Vickers & Elkin (2006) clinical net benefit."""
    yt = np.asarray(y_true, dtype=int)
    yp = np.asarray(y_prob, dtype=float)
    n = len(yt)
    prev = float(np.mean(yt))
    rows = []
    for t in thresholds:
        t_f = float(t)
        if not (0.0 < t_f < 1.0):
            raise ValueError(
                f"Threshold {t_f} must satisfy 0 < t < 1"
            )
        pred = (yp >= t_f).astype(int)
        tp = int(np.sum((pred == 1) & (yt == 1)))
        fp = int(np.sum((pred == 1) & (yt == 0)))
        odds = t_f / (1.0 - t_f)
        nb_m = round((tp / n) - (fp / n) * odds, 5) + 0.0
        nb_a = round(prev - (1.0 - prev) * odds, 5) + 0.0
        rows.append({
            "threshold": round(t_f, 5),
            "nb_model": nb_m,
            "nb_all": nb_a,
            "nb_none": 0.0,
        })
    return pd.DataFrame(rows)

36.3.8 Break It On Purpose! (Capstone Pipeline Error Anatomy)

ImportantBreak It On Purpose #1 — ValueError (Invalid DCA Threshold t = 1.0) 
compute_clinical_net_benefit(y_all, oof_rf, [0.15, 1.0])

Python’s Traceback:

ValueError: Threshold 1.0 must satisfy 0 < t < 1

Diagnosis: In Vickers & Elkin’s formula \(\text{NB}(t) = \frac{\text{TP}}{N} - \frac{\text{FP}}{N}\frac{t}{1 - t}\), setting \(t = 1.0\) divides by \(1 - t = 0\) (infinite harm-to-benefit ratio), while \(t \le 0\) represents zero harm for false positives.
Fix: Enforce an explicit guard if not (0.0 < t_f < 1.0): raise ValueError(...) before evaluating threshold odds so invalid clinical cutoffs fail loudly rather than producing ZeroDivisionError or nan.

ImportantBreak It On Purpose #2 — ValueError (GroupKFold n_splits Exceeds Unique Clusters) 
tiny_groups = np.array([1, 1, 1, 2, 2, 2])
list(GroupKFold(n_splits=5).split(X_all.iloc[:6], y_all[:6], tiny_groups))

Python’s Traceback:

ValueError: Cannot have number of splits n_splits=5 greater than the number of groups: 2.

Diagnosis: GroupKFold assigns every unique survey cluster (cluster_id) to at most one validation fold so households from the same village never leak across splits. Asking for 5 folds when a regional subset contains only 2 clusters is mathematically impossible.
Fix: Always verify n_unique_clusters >= n_splits (or dynamically cap n_splits = min(5, groups.nunique())) before running grouped cross-validation on small pilot cohorts.

ImportantBreak It On Purpose #3 — KeyError (Missing Required Metric in Abstract Builder) 
incomplete_stats = {k: v for k, v in study_stats.items() if k != "eo_gap"}
draft_structured_abstract(incomplete_stats)

Python’s Traceback:

KeyError: 'eo_gap'

Diagnosis: Automated manuscript generators should never silently substitute "N/A" or 0.0 when an equity or calibration metric is missing—silent fallbacks can publish fabricated zeroes into an abstract!
Fix: Use direct dictionary indexing (study_stats["eo_gap"]) rather than .get("eo_gap", 0.0) so incomplete study dictionaries raise an immediate KeyError during build verification.

36.8.1 A. Concept & Execution Trace Test Key

  1. Leaving 8 999 codes inflates mean anc_visits from 3.90 to 19.70 and explodes variance (\(\text{SD} \approx 125\)), washing out Welch’s \(t\)-test and squashing all real visit counts (0–8) into tiny negative \(z\)-scores inside StandardScaler, which destabilizes neural-network gradients.
  2. Socioeconomic confounding: Wealthier households simultaneously attend more antenatal visits, live more often in urban areas, and have lower stunting risk. Once wealth_rank is held constant, the apparent unadjusted effects of anc_visits and is_urban attenuate sharply.
  3. Because child_stunted is defined deterministically as child_haz < -2.0, including child_haz passes the ground-truth answer directly as an input (target leakage)—impossible to obtain before measuring stunting in prospective screening.
  4. Cluster-correlated households share village-level environments; random splitting leaks cluster signatures across train and validation folds, producing optimistically biased AUC that collapses when deployed in unseen villages.
  5. ROC-AUC measures rank-ordering discrimination (how often a stunted child receives a higher score than a non-stunted child), whereas Brier score measures mean squared probability error (calibration + refinement). Clinical thresholds and Decision Curve Analysis rely on well-calibrated probabilities, not rankings alone.
  6. It is not a coding bug—it reflects genuine base-rate and covariate shift between rural and urban households. Deploying a single global threshold risks missing ~69% of stunted urban children unless clinics adopt subgroup-calibrated thresholds or local recalibration.
  7. At \(t = 0.20\), \(\frac{t}{1 - t} = \frac{0.20}{0.80} = 0.25\). Thus \(\text{NB}_{\text{model}}(0.20) = \frac{14}{100} - \frac{20}{100}(0.25) = 0.14 - 0.05 = \mathbf{0.09}\), while \(\text{NB}_{\text{all}}(0.20) = 0.20 - 0.80(0.25) = \mathbf{0.00}\) and \(\text{NB}_{\text{none}} = \mathbf{0.00}\). Yes—the model strictly beats both strategies (+9 net true cases per 100 screened)!
  8. At \(t = 1.0\), \(\frac{t}{1 - t}\) divides by zero. A threshold of \(t = 0.20\) means the clinician considers catching 1 true stunted child worth 4 false-positive referrals (ratio \(1 : 4\), i.e., false-positive weight \(0.25\)).
  9. Direct indexing (study_stats["eo_gap"]) fails loudly with KeyError if an upstream audit was skipped, preventing an automated paper build from silently publishing a misleading 0.0000 fairness gap.
  10. Packaging SimpleImputer + StandardScaler + estimator inside one standard sklearn Pipeline eliminates train/serve preprocessing skew and custom-class pickle errors, while the SHA-256 digest in manifest.json lets reviewers verify that model.joblib was never corrupted or tampered with after publication.

def build_publication_table1(mch_df):

        "p_value": round(float(p_chi), 4),
    })
    return pd.DataFrame(rows)

def run_capstone_model_benchmark(mch_df, seed=42):
    """Benchmark LR, RF, HGB, and PyTorch MLP via 5-fold GroupKFold."""
    wealth_map = {
        "Poorest": 1, "Poorer": 2, "Middle": 3,
        "Richer": 4, "Richest": 5,
    }
    feats = [
        "maternal_age_years", "anc_visits",
        "maternal_hb_g_dl", "is_urban", "wealth_rank",
    ]
    df = mch_df.copy()
    anc = pd.to_numeric(df["anc_visits"], errors="coerce")
    df["anc_visits"] = anc.replace(999, np.nan)
    df["residence"] = (
        df["residence"].astype(str).str.strip().str.title()
    )
    df["is_urban"] = (df["residence"] == "Urban").astype(int)
    df["wealth_rank"] = df["wealth_quintile"].map(wealth_map)
    df = df.dropna(subset=["child_stunted"]).copy()
    X = df[feats].astype(float)
    y = df["child_stunted"].astype(int).to_numpy()
    groups = df["cluster_id"].to_numpy()
    gkf = GroupKFold(n_splits=5)

    builders = {
        "LogisticRegression": lambda: Pipeline([
            ("imp", SimpleImputer(strategy="median")),
            ("scl", StandardScaler()),
            ("clf", LogisticRegression(max_iter=1000, random_state=seed)),
        ]),
        "RandomForestClassifier": lambda: Pipeline([
            ("imp", SimpleImputer(strategy="median")),
            ("clf", RandomForestClassifier(
                n_estimators=80, max_depth=4, random_state=seed
            )),
        ]),
        "HistGradientBoostingClassifier": lambda: Pipeline([
            ("imp", SimpleImputer(strategy="median")),
            ("clf", HistGradientBoostingClassifier(
                max_iter=50, max_depth=3, random_state=seed
            )),
        ]),
    }
    rows = []
    for name, make_pipe in builders.items():
        aucs, briers = [], []
        for tr, va in gkf.split(X, y, groups):
            pipe = make_pipe()
            pipe.fit(X.iloc[tr], y[tr])
            probs = pipe.predict_proba(X.iloc[va])[:, 1]
            aucs.append(roc_auc_score(y[va], probs))
            briers.append(brier_score_loss(y[va], probs))
        rows.append({
            "model": name,
            "mean_auc": round(float(np.mean(aucs)), 4),
            "std_auc": round(float(np.std(aucs)), 4),
            "mean_brier": round(float(np.mean(briers)), 4),
        })

    torch.set_num_threads(1)
    mlp_aucs, mlp_briers = [], []
    for fold_i, (tr, va) in enumerate(gkf.split(X, y, groups)):
        imp = SimpleImputer(strategy="median")
        scl = StandardScaler()
        X_tr_s = scl.fit_transform(imp.fit_transform(X.iloc[tr]))
        X_va_s = scl.transform(imp.transform(X.iloc[va]))
        torch.manual_seed(seed + fold_i)
        net = nn.Sequential(
            nn.Linear(X_tr_s.shape[1], 16),
            nn.ReLU(),
            nn.Linear(16, 1),
        )
        opt = torch.optim.Adam(net.parameters(), lr=0.02)
        loss_fn = nn.BCEWithLogitsLoss()
        xt = torch.tensor(X_tr_s, dtype=torch.float32)
        yt = torch.tensor(y[tr], dtype=torch.float32).unsqueeze(1)
        xv = torch.tensor(X_va_s, dtype=torch.float32)
        net.train()
        for _ in range(30):
            opt.zero_grad()
            loss_fn(net(xt), yt).backward()
            opt.step()
        net.eval()
        with torch.no_grad():

        mlp_aucs.append(roc_auc_score(y[va], probs))
        mlp_briers.append(brier_score_loss(y[va], probs))
    rows.append({
        "model": "PyTorch_MLP",
        "mean_auc": round(float(np.mean(mlp_aucs)), 4),
        "std_auc": round(float(np.std(mlp_aucs)), 4),
        "mean_brier": round(float(np.mean(mlp_briers)), 4),
    })
    return (
        pd.DataFrame(rows)
        .sort_values("mean_auc", ascending=False)
        .reset_index(drop=True)
    )

def compute_clinical_net_benefit(y_true, y_prob, thresholds):
    """Compute Vickers & Elkin (2006) clinical net benefit table."""
    yt = np.asarray(y_true, dtype=int)
    yp = np.asarray(y_prob, dtype=float)
    n = len(yt)
    prev = float(np.mean(yt))
    rows = []
    for t in thresholds:
        t_f = float(t)
        if not (0.0 < t_f < 1.0):
            raise ValueError(
                f"Threshold {t_f} must satisfy 0 < t < 1"
            )
        pred = (yp >= t_f).astype(int)
        tp = int(np.sum((pred == 1) & (yt == 1)))
        fp = int(np.sum((pred == 1) & (yt == 0)))
        odds = t_f / (1.0 - t_f)
        nb_m = round((tp / n) - (fp / n) * odds, 5) + 0.0
        nb_a = round(prev - (1.0 - prev) * odds, 5) + 0.0
        rows.append({
            "threshold": round(t_f, 5),
            "nb_model": nb_m,
            "nb_all": nb_a,
            "nb_none": 0.0,
        })
    return pd.DataFrame(rows)

36.8.4 D. Debugging Post-Mortem: Top 3 Chapter 36 Failure Modes

  1. Unnoticed Data & Target Leakage (child_haz or Global Preprocessing): Including child_haz leaks child_stunted directly, while fitting SimpleImputer or StandardScaler outside GroupKFold leaks validation cluster distributions. Always restrict features strictly to pre-outcome predictors and wrap preprocessing inside each fold’s Pipeline (or PyTorch fold loop).
  2. Evaluating Fairness or DCA In-Sample Instead of Out-of-Fold: Computing Youden’s \(J\), subgroup TPR gaps, or Decision Curve Analysis on training predictions hides overfitting and exaggerates clinical net benefit. Always audit strictly on out-of-fold or held-out predictions.
  3. Leaving Unhashed Artifacts or Polluting the Working Tree: Publishing model weights without a SHA-256 manifest.json breaks cryptographic reproducibility, while writing scratch exports directly into your repository root breaks CI cleanliness.
