E.2 Glossary of 40 Core Terms (A–Z)

Term Concise Definition Primary Ch.
Ablation Study Systematic removal of one feature group or model component at a time to measure its true contribution to performance. 33
Adjusted Odds Ratio (aOR) Odds ratio estimated from a multivariable logistic regression holding all other covariates constant. 20, 36
Aliasing Two Python variable names pointing to the exact same mutable object in memory so mutating one mutates the other. 7
Autograd PyTorch’s reverse-mode automatic differentiation engine that records tensor operations into a dynamic graph for .backward(). 28
Backpropagation Applying the multivariable chain rule backward from scalar loss to every weight tensor to compute exact gradients. 27
Batch Normalization Layer normalizing activations across each mini-batch during training and using running population stats during .eval(). 29
Benjamini-Hochberg (FDR) Step-up multiple-testing procedure controlling the expected proportion of false discoveries among rejected hypotheses. 20
Bias-Variance Tradeoff Tension between underfitting (high bias, overly rigid model) and overfitting (high variance, memorizing training noise). 21
Big-O Notation Asymptotic upper bound describing how an algorithm’s runtime or memory grows as input size \(n\) increases. 11
Bootstrap Confidence Interval Nonparametric uncertainty interval formed by resampling observations with replacement \(B\) times. 33
Brier Score Mean squared error between predicted probabilities and binary outcomes; measures both calibration and discrimination. 23, 34
Broadcasting NumPy/PyTorch rule aligning trailing array dimensions of size \(1\) without copying data in memory. 16
Calibration (ECE) Agreement between predicted probabilities and observed event frequencies; summarized by Expected Calibration Error. 23, 34
Causal Attention Mask Lower-triangular mask setting future token attention logits to \(-\infty\) so autoregressive models cannot peek ahead. 32
ColumnTransformer Scikit-Learn meta-transformer routing numeric and categorical columns through separate leak-free preprocessing pipelines. 26
Copy-on-Write (CoW) Pandas 3.x memory discipline preventing chained-assignment bugs by ensuring slices never silently mutate parent DataFrames. 17, 18
Covariate Shift (PSI) Change in input feature distributions between training and deployment, quantified by Population Stability Index. 34
Cross-Entropy (Log-Loss) Proper scoring rule penalizing confident wrong probability predictions logarithmically. 23, 27
Data Leakage Contamination of training or preprocessing statistics (scaling, imputation, target encoding) by validation/test information. 21, 26
Decision Curve Analysis Vickers-Elkin framework quantifying clinical Net Benefit of a prediction model across decision thresholds vs. Treat-All/None. 36
Dropout Regularizer randomly zeroing neuron activations during model.train() and turning off automatically in model.eval(). 29
Early Stopping Halting neural training when validation loss fails to improve for patience epochs and restoring the best state_dict. 29
Equal Opportunity Gap Maximum difference in True Positive Rate (sensitivity) across protected or demographic subgroups. 34
Gradient Clipping Rescaling the global parameter gradient norm to \(\le \text{max\_norm}\) to prevent exploding updates in RNNs and deep MLPs. 29, 31
GroupKFold Cross-validation splitter guaranteeing all rows from the same patient, hospital, or DHS cluster stay in a single fold. 21, 26
Hash Table Key-value structure (dict, set) providing \(O(1)\) average lookup time by hashing keys to bucket addresses. 8, 11
Hidden State (Notebook) Stale variables left in Jupyter kernel RAM from deleted or out-of-order cells that break Restart & Run All. 13
LoRA (Low-Rank Adaptation) Parameter-efficient fine-tuning freezing base weight \(W_0\) and learning a tiny rank-\(r\) update \(\Delta W = \frac{\alpha}{r}BA\). 32
McNemar’s Test Exact paired nonparametric hypothesis test comparing discordant errors of two classifiers on the exact same test set. 33
Model Card Structured documentation specifying a model’s intended use, training cohort, subgroup metrics, and clinical limitations. 35
Nested Cross-Validation Two-loop CV separating inner hyperparameter selection from outer unbiased generalization estimation. 26
Permutation Importance Model-agnostic importance measuring test-set metric drop when one feature column is randomly shuffled. 24
PR-AUC Area under the Precision-Recall curve; far more informative than ROC-AUC under severe class imbalance. 23
Regularization (\(L_1\) / \(L_2\)) Penalty on coefficient magnitude (Lasso \(L_1\) drives sparsity; Ridge \(L_2\) shrinks correlated weights smoothly). 22
Residual Connection Identity shortcut \(y = F(x) + x\) letting gradients flow unobstructed through deep CNNs and Transformers. 30, 32
Scaled Dot-Product Attention Core Transformer weighting \(\operatorname{softmax}(QK^\top / \sqrt{d_k})V\) connecting every token to every relevant context token. 32
SHA-256 Manifest Cryptographic 64-character hex fingerprint proving a dataset or model artifact has not changed by a single byte. 15, 35
Shapley Value (SHAP) Game-theoretic attribution dividing a single prediction’s deviation from baseline fairly across all input features. 24
TRIPOD+AI International reporting guideline ensuring transparent, reproducible clinical prediction model manuscripts. 35
Youden’s \(J\) Statistic Classification threshold criterion maximizing \(\text{Sensitivity} + \text{Specificity} - 1\) on the ROC curve. 23, 34

E.3 About the Author

Mezanur Rahman Sharukh is an M.Sc. Statistician and Public Health & Machine Learning Researcher whose work bridges classical biostatistics, survey epidemiology, and reproducible machine learning engineering. His research focuses on maternal and child health disparities, infectious disease surveillance, probability calibration, subgroup fairness in clinical prediction models, and open-source educational tooling for quantitative researchers in low- and middle-income settings.

From First Line to First Paper was written to close the gap between introductory Python tutorials that stop at toy syntax and graduate machine learning papers that assume years of undocumented software engineering fluency. Every dataset, diagnostic check, and notebook in this curriculum was built so a dedicated learner with nothing more than a browser and Google Colab can progress systematically from their very first print() statement to a peer-review-ready, cryptographically verified research artifact.
