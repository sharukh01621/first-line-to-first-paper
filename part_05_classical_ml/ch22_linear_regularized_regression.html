22.1 Stage 1 — First-Principles Intuition: Fitting Lines Without Fitting Noise

In Chapter 21, you learned the universal architecture of supervised machine learning: separate training from test data, prevent data leakage with Pipeline, and judge models by out-of-sample generalization rather than in-sample fit. Now we open the engine hood on the foundational workhorse of predictive modeling: Linear Regression and its regularized extensions.

Given a matrix of \(n\) observations and \(p\) features \(X \in \mathbb{R}^{n \times p}\), a linear regressor predicts a continuous outcome \(\hat{y} \in \mathbb{R}^n\) via an affine combination of weights \(w \in \mathbb{R}^p\) and intercept \(b \in \mathbb{R}\):

\[\hat{y} = X w + b\]

Five core principles govern every algorithm in this chapter:

  • Squared Error vs. Absolute Error: Minimizing Mean Squared Error \(\text{MSE} = \frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2\) produces a smooth, convex bowl with a unique analytical minimum, while RMSE \(= \sqrt{\text{MSE}}\) restores the target’s physical units (here, HAZ Z-scores). MAE \(= \frac{1}{n}\sum |y_i - \hat{y}_i|\) weights outliers linearly rather than quadratically.
  • Closed-Form vs. Iterative Solvers: For moderate feature counts, the Normal Equation \(\hat{\theta} = (X_b^T X_b)^+ X_b^T y\) (computed safely via SVD in np.linalg.lstsq) jumps straight to the global minimum in one shot. When \(n\) or \(p\) grows massive—or in deep neural networks later in Part VI—Batch Gradient Descent walks downhill iteratively along the negative gradient \(-\nabla L(w, b)\).
  • Why Multicollinearity Breaks Unregularized OLS: When two predictors move almost identically (for example, duplicate antenatal clinic visit counters), \((X_b^T X_b)\) becomes nearly singular. OLS can add \(+6.9\) to one weight and \(-6.7\) to the other with nearly zero change in training error, creating massive variance on unseen test households.
  • Regularization Geometry (\(L_2\) vs. \(L_1\) vs. ElasticNet): Adding a penalty \(\alpha \Omega(w)\) to the MSE objective trades a tiny increase in bias for a sharp drop in variance. Ridge (\(\alpha \|w\|_2^2\)) imposes a smooth circular constraint that shrinks correlated weights together; Lasso (\(\alpha \|w\|_1\)) imposes a sharp diamond constraint whose corners lie on the axes, driving weak predictors to exact 0.0; ElasticNet blends both via l1_ratio.
  • Scaling Is Mandatory Before Regularization: Because penalties act directly on coefficient magnitudes \(|w_j|\) or \(w_j^2\), measuring maternal age in years vs. days would alter its penalty by \(365^2\)! Always place StandardScaler() inside a Scikit-Learn Pipeline so every predictor is penalized on a fair 1-SD scale with zero test-set leakage.
NoteMental Model — Why Out-of-Sample R^2 Can Be Negative

In introductory statistics, students learn that \(R^2 \in [0, 1]\) on training data. On an unseen holdout test set, however, \(R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y}_{\text{test}})^2}\) can drop below zero! A negative test \(R^2\) simply means your model’s test MSE is slightly worse than predicting the test-set mean \(\bar{y}_{\text{test}}\)—an immediate diagnostic cue to regularize harder, simplify noisy covariates, or engineer stronger features.

WarningTwo Silent Regularization Traps in Scikit-Learn
  1. Unscaled Penalties: Calling Ridge(alpha=1.0).fit(X_train, y_train) directly on raw features penalizes small-range variables (e.g., binary is_urban) far less than large-range variables (e.g., maternal_age_years). Always wrap StandardScaler() inside a Pipeline.
  2. Negative CV Scores: Scikit-Learn maximizes every scorer inside cross_val_score, so scoring="neg_root_mean_squared_error" returns negative RMSE values (e.g., -1.1359). Always negate (rmses = -scores) before averaging or calling .idxmin().

22.3.3 Closed-Form OLS: The Normal Equation From Scratch

Prepending a column of ones \(X_b = [\mathbf{1}, Z]\) absorbs the intercept \(b\) into a single parameter vector \(\theta = [b, w_1, \dots, w_p]^T\). Setting \(\nabla_\theta \|X_b \theta - y\|_2^2 = 0\) yields the Normal Equation:

\[X_b^T X_b \hat{\theta} = X_b^T y \implies \hat{\theta} = (X_b^T X_b)^+ X_b^T y\]

# Standardize using training-fold statistics ONLY (zero leakage)
mu_tr = X_tr.to_numpy().mean(axis=0)
sd_tr = X_tr.to_numpy().std(axis=0)
Z_tr = (X_tr.to_numpy() - mu_tr) / sd_tr
y_tr_arr = y_tr.to_numpy()

Zb = np.column_stack([np.ones(len(Z_tr)), Z_tr])
theta_lstsq = np.linalg.lstsq(Zb, y_tr_arr, rcond=None)[0]
theta_pinv = np.linalg.pinv(Zb.T @ Zb) @ Zb.T @ y_tr_arr

sk_ols = ols_pipe.named_steps["ols"]
print(f"Normal Eq (lstsq) b={theta_lstsq[0]:.4f}, "
      f"w={np.round(theta_lstsq[1:], 4)}")
print(f"Normal Eq (pinv)  b={theta_pinv[0]:.4f}, "
      f"w={np.round(theta_pinv[1:], 4)}")
print(f"Scikit-Learn OLS  b={sk_ols.intercept_:.4f}, "
      f"w={np.round(sk_ols.coef_, 4)}")

Expected Output:

Normal Eq (lstsq) b=-0.7445, w=[ 0.1694  0.0797 -0.034   0.0006]
Normal Eq (pinv)  b=-0.7445, w=[ 0.1694  0.0797 -0.034   0.0006]
Scikit-Learn OLS  b=-0.7445, w=[ 0.1694  0.0797 -0.034   0.0006]

All three solvers (np.linalg.lstsq, Moore-Penrose pseudoinverse pinv, and sklearn.linear_model.LinearRegression) produce identical standardized parameters down to the fourth decimal place. Notice why lstsq is preferred over np.linalg.inv(Zb.T @ Zb): SVD-based lstsq stays numerically stable even when columns are perfectly collinear.

22.3.4 Pure-NumPy Batch Gradient Descent on MSE

Instead of inverting a \(p \times p\) matrix (which costs \(\mathcal{O}(p^3)\)), Batch Gradient Descent differentiates the MSE loss \(L(w, b) = \frac{1}{n} \sum_{i=1}^n (z_i^T w + b - y_i)^2\) directly:

\[\nabla_w L = \frac{2}{n} Z^T (\hat{y} - y), \qquad \nabla_b L = \frac{2}{n} \sum_{i=1}^n (\hat{y}_i - y_i)\]

def run_batch_gd(Z, y_vec, lr=0.05, epochs=300):
    n, p = Z.shape
    w = np.zeros(p, dtype=float)
    b = 0.0
    history = []
    for _ in range(epochs):
        err = (Z @ w + b) - y_vec
        history.append(float(np.mean(err ** 2)))
        w = w - lr * ((2.0 / n) * (Z.T @ err))
        b = b - lr * ((2.0 / n) * float(np.sum(err)))
    return w, b, history

w_gd, b_gd, losses = run_batch_gd(Z_tr, y_tr_arr, lr=0.05, epochs=300)
print(f"MSE Epoch 1: {losses[0]:.4f} -> Epoch 25: {losses[24]:.4f} "
      f"-> Epoch 300: {losses[-1]:.4f}")
print(f"Batch GD params   b={b_gd:.4f}, w={np.round(w_gd, 4)}")
max_diff = float(np.max(np.abs(w_gd - sk_ols.coef_)))
print(f"Max |w_gd - w_ols|: {max_diff:.6f}")

Expected Output:

MSE Epoch 1: 1.8524 -> Epoch 25: 1.2607 -> Epoch 300: 1.2569
Batch GD params   b=-0.7445, w=[ 0.1694  0.0797 -0.034   0.0006]

Starting from all zeros (MSE = 1.8524), Batch Gradient Descent drops rapidly to 1.2607 by Epoch 25 and converges to the exact OLS minimum (Max |w_gd - w_ols| = 0.000000) by Epoch 300! 22.3.5 Multicollinearity Instability: OLS Explosion vs. Ridge Stabilization

Suppose a survey merges two nearly identical clinic-visit logs (anc_visits and anc_proxy = anc_visits + tiny_noise). Let’s see what happens to OLS versus Ridge (\(L_2\)) regularization:

rng = np.random.default_rng(42)
X_col = X_tr.copy()
# Add a nearly collinear duplicate clinic-visit counter (r > 0.9999)
X_col["anc_proxy"] = (
    X_col["anc_visits"] + rng.normal(0.0, 0.01, size=len(X_col))
)

for label, est in [
    ("OLS (unregularized)", LinearRegression()),
    ("Ridge (alpha=1.0)  ", Ridge(alpha=1.0)),
    ("Ridge (alpha=10.0) ", Ridge(alpha=10.0)),
]:
    pipe = Pipeline([("scaler", StandardScaler()), ("m", est)])
    pipe.fit(X_col, y_tr)
    c = pipe.named_steps["m"].coef_
    l2_norm = float(np.linalg.norm(c))
    print(f"{label} anc={c[0]:+7.3f}, proxy={c[4]:+7.3f} "
          f"| ||w||_2={l2_norm:.3f}")

Adding Ridge’s \(L_2\) term \((Z^T Z + \alpha I)^{-1} Z^T y\) instantly stabilizes the matrix diagonal, splitting the true +0.168 effect cleanly between both counters (+0.081 and +0.087 at \(\alpha = 10.0\)).

22.3.6 Regularization Geometry: Ridge (\(L_2\)) vs. Lasso (\(L_1\)) vs. ElasticNet

Compare the three regularized objectives on the four standardized MCH predictors:

  • Ridge (\(L_2\)): \(\min_{w,b} \sum_{i=1}^n (y_i - \hat{y}_i)^2 + \alpha \|w\|_2^2\) (smooth shrinkage; keeps all features nonzero).
  • Lasso (\(L_1\)): \(\min_{w,b} \frac{1}{2n}\sum_{i=1}^n (y_i - \hat{y}_i)^2 + \alpha \|w\|_1\) (sparse selection; sets weak coefficients to exact 0.0).
  • ElasticNet (\(L_1 + L_2\)): \(\min_{w,b} \frac{1}{2n}\sum_{i=1}^n (y_i - \hat{y}_i)^2 + \alpha \rho \|w\|_1 + \frac{\alpha (1 - \rho)}{2} \|w\|_2^2\) where \(\rho =\) l1_ratio.
models = [
    ("OLS", LinearRegression()),
    ("Ridge(1.0)", Ridge(alpha=1.0)),
    ("Ridge(10.0)", Ridge(alpha=10.0)),
    ("Lasso(0.05)", Lasso(alpha=0.05, max_iter=5000)),
    ("ElasticNet(0.05)", ElasticNet(alpha=0.05, l1_ratio=0.5,
                                    max_iter=5000)),
]
rows = []
for name, est in models:
    pipe = Pipeline([("scaler", StandardScaler()), ("m", est)])
    pipe.fit(X_tr, y_tr)
    pred = pipe.predict(X_te)
    c = pipe.named_steps["m"].coef_
    rows.append({
        "model": name,
        "rmse": round(float(root_mean_squared_error(y_te, pred)), 4),
        "nonzero": int(np.sum(np.abs(c) > 1e-6)),
        "anc": round(float(c[0]), 4),
        "hb": round(float(c[1]), 4),
        "age": round(float(c[2]), 4),
        "urban": round(float(c[3]), 4),
    })
print(pd.DataFrame(rows).to_string(index=False))

22.3.7 Residual Diagnostics & Error Inspection

Never stop at a single headline RMSE. Inspect the residual vector \(e = y_{\text{true}} - \hat{y}\) to catch systematic bias or extreme outliers:

lasso_pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("lasso", Lasso(alpha=0.05, max_iter=5000)),
])
lasso_pipe.fit(X_tr, y_tr)
y_hat_lasso = lasso_pipe.predict(X_te)

22.3.8 Break It On Purpose! (Regression Error Anatomy)

ImportantBreak It On Purpose #1 — LinAlgError (Inverting Singular Collinear X^T X) 
X_sing = np.array([[1.0, 2.0, 4.0], [1.0, 3.0, 6.0], [1.0, 5.0, 10.0]])
np.linalg.inv(X_sing.T @ X_sing)

Python’s Traceback:

LinAlgError: Singular matrix

Diagnosis: Column 2 ([4, 6, 10]) equals exactly \(2 \times\) Column 1 ([2, 3, 5]), so \(\det(X^T X) = 0\) and the matrix has no inverse.
Fix: Never solve OLS with raw np.linalg.inv(X.T @ X). Use SVD-based np.linalg.lstsq(Xb, y, rcond=None)[0], np.linalg.pinv(...), or add a Ridge penalty \((X^T X + \alpha I)\) which guarantees strict invertibility for any \(\alpha > 0\).

ImportantBreak It On Purpose #2 — ValueError (Passing 1D X Instead of 2D (n, p)) 
x_1d = clean["anc_visits"].to_numpy()[:5]
y_1d = clean["child_haz"].to_numpy()[:5]
LinearRegression().fit(x_1d, y_1d)

Python’s Traceback:

ValueError: Expected 2D array, got 1D array instead:
array=[4. 3. 2. 2. 0.].
Reshape your data either using array.reshape(-1, 1) if your data has a
single feature or array.reshape(1, -1) if it contains a single sample.

Diagnosis: Every Scikit-Learn estimator requires a 2D design matrix X of shape (n_samples, n_features). Indexing a single column with clean["anc_visits"] yields a 1D Series/array of shape (n,).
Fix: Slice with double brackets clean[["anc_visits"]] (a 2D DataFrame) or reshape a 1D NumPy vector with x_1d.reshape(-1, 1).

ImportantBreak It On Purpose #3 — ValueError / InvalidParameterError (Negative Ridge Alpha) 
Ridge(alpha=-1.0).fit(X_tr, y_tr)

Python’s Traceback:

InvalidParameterError: The 'alpha' parameter of Ridge must be a float
in the range [0.0, inf) or an array-like. Got -1.0 instead.

Diagnosis: InvalidParameterError (a Scikit-Learn subclass of ValueError) catches negative regularization penalties. A negative \(\alpha\) would reward arbitrarily large weights, destroying convexity and sending \(\|w\|_2 \to \infty\).
Fix: Always search strictly non-negative penalties on a logarithmic grid such as np.logspace(-3, 3, 7) ([0.001, 0.01, ..., 1000.0]).

def build_haz_regression_report(raw_df, alphas=(0.1, 1.0, 10.0, 100.0)):
    """Clean MCH data, tune Ridge via 5-fold CV, and benchmark models."""
    df = raw_df.copy()
    df["residence"] = df["residence"].astype(str).str.strip().str.title()
    df["anc_visits"] = df["anc_visits"].replace(999, np.nan)
    df["is_urban"] = (df["residence"] == "Urban").astype(int)
    feats = [
        "anc_visits", "maternal_hb_g_dl",
        "maternal_age_years", "is_urban",
    ]
    cdf = df[feats + ["child_haz"]].dropna()
    X_all, y_all = cdf[feats], cdf["child_haz"]
    X_a, X_b, y_a, y_b = train_test_split(
        X_all, y_all, test_size=0.2, random_state=42
    )

    # 1. Leak-free 5-fold CV on training split ONLY
    kf = KFold(n_splits=5, shuffle=True, random_state=42)
    cv_rows = []
    for a in alphas:
        pipe = Pipeline([
            ("scaler", StandardScaler()),
            ("ridge", Ridge(alpha=float(a))),
        ])
        rmses = -cross_val_score(
            pipe, X_a, y_a, cv=kf,
            scoring="neg_root_mean_squared_error",
        )
        cv_rows.append({
            "alpha": float(a),
            "cv_rmse": round(float(rmses.mean()), 4),
        })
    cv_df = pd.DataFrame(cv_rows)
    best_a = float(cv_df.loc[cv_df["cv_rmse"].idxmin(), "alpha"])

    # 2. Final holdout evaluation with tuned Ridge
    best_pipe = Pipeline([
        ("scaler", StandardScaler()),
        ("ridge", Ridge(alpha=best_a)),
    ])
    best_pipe.fit(X_a, y_a)
    preds = best_pipe.predict(X_b)
    test_rmse = round(float(root_mean_squared_error(y_b, preds)), 4)
    resid = y_b.to_numpy() - preds
    diag = {
        "mean_resid": round(float(np.mean(resid)), 4),
        "max_abs_err": round(float(np.max(np.abs(resid))), 4),
    }
    return len(cdf), cv_df, best_a, test_rmse, diag

22.8.1 A. Concept & Execution Trace Test Key

  1. Residuals are [0.0, -1.0, 2.0]: \(\text{MAE} = (0 + 1 + 2)/3 = \mathbf{1.0000}\), \(\text{MSE} = (0 + 1 + 4)/3 = \mathbf{1.6667}\), \(\text{RMSE} = \sqrt{5/3} \approx \mathbf{1.2910}\). \(\text{RMSE} > \text{MAE}\) because squaring amplifies the larger error (2.0) disproportionately.
  2. Mean \(\bar{y} = 2.5\), so \(\text{SS}_{\text{tot}} = 1.5^2 + 0.5^2 + 0.5^2 + 1.5^2 = 5.0\). Errors are [-3, -1, 1, 3], so \(\text{SS}_{\text{res}} = 9 + 1 + 1 + 9 = 20.0\). Thus \(R^2 = 1 - 20/5 = \mathbf{-3.0}\). A negative \(R^2\) means the model performs worse than predicting the constant mean \(\bar{y}\).
  3. np.linalg.inv(Xb.T @ Xb) raises np.linalg.LinAlgError: Singular matrix because \(X_b^T X_b\) is rank-deficient (\(\det = 0\)). Using np.linalg.lstsq(Xb, y, rcond=None) (or np.linalg.pinv) computes the minimum-norm least-squares solution safely via SVD.
  4. At \(w = 0, b = 0\): \(\hat{y} = [0, 0]\), error \(e = \hat{y} - y = [-2, -6]\). Gradients: \(\nabla_w L = \frac{2}{2}(1(-2) + 3(-6)) = \mathbf{-20}\), \(\nabla_b L = \frac{2}{2}(-2 + -6) = \mathbf{-8}\). Update with \(\eta = 0.1\): \(w^{(1)} = 0 - 0.1(-20) = \mathbf{2.0}\), \(b^{(1)} = 0 - 0.1(-8) = \mathbf{0.8}\).
  5. Ridge minimizes \(\text{SSE} + \alpha (w_1^2 + w_2^2)\). For \((1, 1)\), the penalty is \(\alpha (1^2 + 1^2) = 2\alpha\); for \((100, -98)\), the penalty is \(\alpha (10000 + 9604) = 19{,}604\alpha\)! Squaring forces correlated features to share weight evenly.
  6. The \(L_1\) constraint region \(|w_1| + |w_2| \le t\) is a diamond with sharp corners sitting directly on the coordinate axes, where elliptical MSE contours naturally touch first (setting one coordinate to exact 0.0). The \(L_2\) sphere \(w_1^2 + w_2^2 \le t\) is smooth everywhere with no corners.
  7. Feature A (anc_visits) gets punished far harder! Because income_bdt has \(10{,}000\times\) larger units, its raw regression slope is tiny (\(\sim 10^{-5}\)), so its squared penalty \(w_B^2 \approx 10^{-10}\) is negligible compared with \(w_A^2\). Standardizing equalizes both features to mean 0, SD 1.
  8. Fitting StandardScaler on the full dataset X leaks validation-fold means and standard deviations into training folds, subtly inflating CV performance. Wrapping StandardScaler() inside a Pipeline refits the scaler independently inside every training fold.
  9. Negating gives [1.24, 1.18, 1.30], whose positive mean CV RMSE is \(\mathbf{1.24}\). Scikit-Learn follows a universal “higher score is better” API across all grid-search and CV utilities, so loss metrics are negated.
  10. Because resid = y_true - y_pred > 0, \(y_{\text{true}} > \hat{y}\), meaning the model is systematically under-predicting by 0.85 units on average. The max_abs_error = 5.4 warns of at least one severe outlier pulling up squared error (MSE/RMSE).

import numpy as np
from sklearn.linear_model import Lasso, Ridge
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

# To-Do 22.1
def regression_metrics(y_true, y_pred):
    """Return dict with MAE, RMSE, and R^2 rounded to 4 decimals."""
    yt = np.asarray(y_true, dtype=float)
    yp = np.asarray(y_pred, dtype=float)
    err = yt - yp
    mae = float(np.mean(np.abs(err)))
    rmse = float(np.sqrt(np.mean(err ** 2)))
    ss_res = float(np.sum(err ** 2))
    ss_tot = float(np.sum((yt - np.mean(yt)) ** 2))
    r2 = 1.0 - ss_res / ss_tot
    return {
        "mae": round(mae, 4),
        "rmse": round(rmse, 4),
        "r2": round(r2, 4),
    }

# To-Do 22.2
def ols_normal_equation(X, y):
    """Solve OLS via Normal Equation / lstsq; return (intercept, coef)."""
    X_arr = np.asarray(X, dtype=float)
    y_arr = np.asarray(y, dtype=float)
    Xb = np.column_stack([np.ones(len(X_arr)), X_arr])
    theta = np.linalg.lstsq(Xb, y_arr, rcond=None)[0]
    return (float(theta[0]), theta[1:])

# To-Do 22.3
def gradient_descent_linear(X, y, lr=0.05, epochs=300):
    """Run batch gradient descent on MSE; return (w, b, loss_history)."""
    X_arr = np.asarray(X, dtype=float)
    y_arr = np.asarray(y, dtype=float)
    n, p = X_arr.shape
    w = np.zeros(p, dtype=float)
    b = 0.0
    loss_history = []
    for _ in range(epochs):
        err = (X_arr @ w + b) - y_arr
        loss_history.append(float(np.mean(err ** 2)))
        dw = (2.0 / n) * (X_arr.T @ err)
        db = (2.0 / n) * float(np.sum(err))
        w = w - lr * dw
        b = b - lr * db
    return (w, float(b), loss_history)

# To-Do 22.4
def fit_ridge_standardized(X_train, y_train, X_test, alpha=1.0):
    """Fit leak-free StandardScaler + Ridge; return (y_pred, coef)."""
    pipe = Pipeline([
        ("scaler", StandardScaler()),
        ("ridge", Ridge(alpha=alpha)),
    ])
    pipe.fit(X_train, y_train)
    y_pred = pipe.predict(X_test)
    return (y_pred, pipe.named_steps["ridge"].coef_)

# To-Do 22.5
def count_lasso_selected_features(
    X_train, y_train, alpha=0.1, tol=1e-6
):
    """Count standardized Lasso coefficients with |coef| > tol."""
    pipe = Pipeline([
        ("scaler", StandardScaler()),
        ("lasso", Lasso(alpha=alpha, max_iter=5000)),
    ])
    pipe.fit(X_train, y_train)
    coefs = pipe.named_steps["lasso"].coef_
    return int(np.sum(np.abs(coefs) > tol))

# To-Do 22.6
def residual_summary(y_true, y_pred):
    """Return mean, std (ddof=0), and max |error| of y_true - y_pred."""
    resid = (
        np.asarray(y_true, dtype=float)
        - np.asarray(y_pred, dtype=float)
    )
    return {
        "mean_residual": round(float(np.mean(resid)), 4),
        "std_residual": round(float(np.std(resid)), 4),

    work["is_urban"] = (work["residence"] == "Urban").astype(int)

    feats = [
        "anc_visits", "maternal_hb_g_dl",
        "maternal_age_years", "is_urban",
    ]
    clean = work[feats + ["child_haz"]].dropna()
    X_tr, X_te, y_tr, y_te = train_test_split(
        clean[feats], clean["child_haz"],
        test_size=0.2, random_state=seed,
    )
    pipe = Pipeline([
        ("scaler", StandardScaler()),
        ("ridge", Ridge(alpha=1.0)),
    ])
    pipe.fit(X_tr, y_tr)
    y_pred = pipe.predict(X_te)
    coefs = {
        f: round(float(c), 4)
        for f, c in zip(feats, pipe.named_steps["ridge"].coef_)
    }
    return {
        "n_clean": int(len(clean)),
        "test_rmse": round(
            float(root_mean_squared_error(y_te, y_pred)), 4
        ),
        "test_r2": round(float(r2_score(y_te, y_pred)), 4),
        "coefs": coefs,
    }

22.8.4 D. Debugging Post-Mortem: Top 3 Chapter 22 Failure Modes

  1. Regularizing Without StandardScaler() Inside a Pipeline: Fitting Ridge or Lasso on raw unscaled predictors distorts penalties by measurement units, while scaling before splitting or before cross_val_score leaks test/validation statistics into training. Always chain Pipeline([("scaler", StandardScaler()), ...]).
  2. Inverting Singular Matrices or Flipping Gradient Signs: Calling np.linalg.inv(Xb.T @ Xb) crashes on perfectly collinear features (LinAlgError), and flipping err = y_hat - y inside gradient descent turns minimization into explosive ascent. Prefer np.linalg.lstsq for closed-form OLS and always assert loss_history[-1] < loss_history[0] in gradient descent.
  3. Forgetting to Negate neg_root_mean_squared_error or Clean Sentinel 999: Scikit-Learn returns negative RMSE scores during CV—negate them before selecting idxmin(). Likewise, leaving anc_visits == 999 inside mch_survey_sample silently wrecks feature standardization and crushes the learned antenatal-care coefficient.
