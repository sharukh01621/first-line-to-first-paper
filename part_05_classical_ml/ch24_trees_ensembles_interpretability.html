24.1 Stage 1 — First-Principles Intuition: Why Trees & Ensembles Rule Tabular Science

Linear and logistic regression assume that every predictor shifts the log-odds smoothly along a straight line. Real clinical and epidemiological data rarely obey neat straight lines:

  • Threshold Effects: Maternal hemoglobin below \(11.0\text{ g/dL}\) signals clinical anemia, and fewer than \(4\) antenatal care (ANC) visits marks WHO-defined inadequate care. A Decision Tree discovers these exact cutoffs automatically.
  • Automatic Feature Interactions: Low wealth paired with fewer than \(4\) ANC visits may elevate child stunting risk far beyond the sum of either factor alone. Every root-to-leaf path in a tree is a natural interaction rule (wealth_rank <= 2.5 AND anc_visits <= 3.5).
  • Monotonic Scale Invariance: Because trees split on order thresholds (\(x \le t\)), you do not need StandardScaler or log-transforms for tree splits to work.

Yet a single unconstrained Decision Tree has an Achilles’ heel: extreme variance. Grow a tree deep enough and it creates one tiny leaf per training household—scoring near 1.000 training AUC while collapsing on new patients.

Modern machine learning solves single-tree fragility through two complementary ensemble philosophies:

  • Bagging & Random Forests (Variance Reduction in Parallel): Train \(B\) deep trees independently on bootstrap resamples of the training rows, randomly restricting each split to a subset of features (max_features="sqrt"). Averaging decorrelated trees slashes variance dramatically, and the ~36.8% of rows omitted from each bootstrap sample provide near-free Out-of-Bag (OOB) validation!
  • Gradient Boosting (Bias Reduction in Sequence): Train shallow trees (“weak learners”) one after another, where each new tree predicts the residual error left behind by the ensemble so far, scaled by a shrinkage learning rate \(\eta\).
  • Histogram Boosting, XGBoost & LightGBM: Modern engines such as XGBoost, LightGBM, and Scikit-Learn’s HistGradientBoostingClassifier bin continuous features into ~255 quantile histograms (making split search \(10\times\)–\(100\times\) faster), apply \(L_2\) leaf regularization, and learn optimal split directions for missing (NaN) values natively.
Conceptual comparison of modern Gradient Boosted Decision Tree (GBDT) engines.
Framework Tree Growth Native NaN? Core Strengths in Research
Scikit-Learn HistGradientBoosting Leaf-wise (binned) Yes Zero extra installs; native Pipeline fit
XGBoost (xgboost) Depth-wise (exact/hist) Yes \(L_1\)/\(L_2\) leaf penalties; GPU & sparse data
LightGBM (lightgbm) Leaf-wise (GOSS/EFB) Yes Fastest on \(100\text{k}+\) rows; native categories

Finally, predictive accuracy alone never earns clinical trust. Peer reviewers demand interpretability—both global (which predictors drive discrimination on held-out patients?) and local (why did the model assign this specific household a 25.7% stunting probability?). Held-out Permutation Importance answers the global question without MDI’s high-cardinality trap, while Shapley values (SHAP) answer the local question with game-theoretic fairness.

NoteMental Model — Two Axes of Tree Interpretability

Always separate global from local explanations in your methods section:

  1. Global (Held-Out Permutation Importance): Shuffle one feature column at a time on the test set and measure how much ROC-AUC drops. Noise features collapse near zero.
  2. Local (Shapley / SHAP Values): Explain one patient’s prediction \(f(x)\) as a baseline risk \(\phi_0\) plus additive feature credits \(\phi_1 + \phi_2 + \dots + \phi_p = f(x) - \phi_0\), averaged across every possible ordering of features.

24.2 Stage 2 — Visual Mental Model: Bagging vs. Boosting & Interpretability

Compare how Bagging (Random Forests) averages independent parallel trees to cut variance, while Boosting (HistGradientBoosting) chains shallow residual trees sequentially to cut bias—and how both feed into held-out interpretability:

Notice the structural contrast at a glance: in Bagging, Tree 1 and Tree 2 never communicate—they train in parallel on different bootstrap draws so their errors cancel when averaged. In Boosting, Tree 2 cannot begin until Tree 1 finishes and exposes the remaining residuals \(r_1\).

WarningThree Silent Tree & Ensemble Pitfalls in Real Studies
  1. Default .feature_importances_ (MDI) Favors Noise: Impurity-based importance is computed on the training set and systematically inflates high-cardinality continuous features—even pure random IDs! Always audit with held-out permutation_importance.
  2. Unbounded Depth Memorizes Small Cohorts: A single tree with max_depth=None can hit train_auc = 1.000 while dropping below a simple stump on validation. Always inspect train_auc - val_auc.
  3. Never Assume Boosting Automatically Wins on Small \(n\): On a \(500\)-row public-health survey, shallow regularized trees or logistic models can rival or beat un-tuned ensembles. Always benchmark all three families empirically on the same stratified split!

Notice two crucial data-hygiene steps before fitting any tree:

  • Sentinel replacement (999 -> np.nan): If 999 stayed inside anc_visits, a tree would treat missingness as “999 clinic visits”—an extreme right-tail artifact.
  • Ordinal mapping (wealth_rank 1..5): Mapping "Poorest" through "Richest" to integers 1..5 preserves the socioeconomic ordering so a single split (wealth_rank <= 2.5) separates the bottom two quintiles from the upper three cleanly.
  • Stratified split (stratify=y): Because child stunting prevalence is imbalanced (13.83%), stratifying preserves the exact same class ratio in both train (352 rows) and test (118 rows).

24.3.2 Gini Impurity, Shannon Entropy & Greedy Decision Stump

For a node with class proportions \(p_1, \dots, p_K\), CART measures node disorder using Gini impurity or base-2 Shannon entropy:

\[G(y) = 1 - \sum_{k=1}^{K} p_k^2, \qquad H(y) = -\sum_{k=1}^{K} p_k \log_2(p_k)\]

A decision stump tests every midpoint \(t\) between consecutive sorted unique values of feature \(x\) and picks the threshold minimizing weighted child Gini:

\[G_{\text{split}}(t) = \frac{n_L}{n} G(y_{x \le t}) + \frac{n_R}{n} G(y_{x > t})\]

def gini_demo(y_vals):
    arr = np.asarray(y_vals)
    if arr.size == 0:
        return 0.0
    _, counts = np.unique(arr, return_counts=True)
    probs = counts / arr.size
    return round(float(1.0 - np.sum(probs ** 2)), 4)

def entropy_demo(y_vals):
    arr = np.asarray(y_vals)
    if arr.size == 0:
        return 0.0
    _, counts = np.unique(arr, return_counts=True)
    probs = counts / arr.size
    return round(float(-np.sum(probs * np.log2(probs))), 4)

def stump_demo(x_vals, y_vals):
    x = np.asarray(x_vals, dtype=float)
    yv = np.asarray(y_vals)
    uniq = np.unique(x)
    mids = (uniq[:-1] + uniq[1:]) / 2.0
    best_t, best_g = float(mids[0]), float("inf")
    for t in mids:
        left, right = yv[x <= t], yv[x > t]
        wg = (len(left) / len(yv)) * gini_demo(left)
        wg += (len(right) / len(yv)) * gini_demo(right)
        if wg < best_g:
            best_g, best_t = wg, float(t)
    return (round(best_t, 4), round(best_g, 4))

print("Root Gini:", gini_demo(y_train),
      "| Root Entropy:", entropy_demo(y_train))
for col in ["wealth_rank", "anc_visits", "maternal_hb_g_dl"]:
    t, g = stump_demo(X_train[col], y_train)
    print(f"Best stump on {col:16s}: thresh={t:.2f}, w_gini={g:.4f}")

24.3.4 Bagging, Random Forests & Out-of-Bag (OOB) Validation

When a Random Forest draws a bootstrap sample of size \(n\) with replacement, the probability that any given household is never selected in a single tree is \((1 - 1/n)^n \approx e^{-1} \approx \mathbf{0.368}\). Evaluating every household using only the ~36.8% of trees that never saw it produces the Out-of-Bag (OOB) score—free internal validation without touching the test set!

oob_rows = []
for d in [2, 4, 6, 8, 12]:
    rf = RandomForestClassifier(
        n_estimators=120, max_depth=d, oob_score=True, random_state=42
    ).fit(X_train, y_train)
    oob_rows.append({
        "max_depth": d,
        "oob_score": round(float(rf.oob_score_), 4),
    })
print(pd.DataFrame(oob_rows).to_string(index=False))

Expected Output:

 max_depth  oob_score
         2     0.8608
         4     0.8636
         6     0.8580
         8     0.8466
        12     0.8494

OOB validation cleanly peaks at max_depth = 4 (0.8636) and declines as deeper trees memorize noise in the bootstrap draws. Remember: oob_score_ reports accuracy by default, so always confirm discrimination on imbalanced outcomes with ROC-AUC and PR-AUC.

24.3.5 Gradient Boosting Residuals, Native NaNs & Ensemble Scaling

In Gradient Boosting, each tree \(h_m(x)\) fits the pseudo-residuals left over by the previous ensemble \(F_{m-1}(x)\) and updates predictions cautiously via learning rate \(\eta\):

\[r_i^{(m)} = y_i - F_{m-1}(x_i), \qquad F_m(x) = F_{m-1}(x) + \eta \cdot h_m(x)\]

# 1. Sequential residual fitting intuition (3 boosting rounds)
y_hb = np.array([9.4, 10.1, 11.2, 12.6, 13.0])
x_anc = np.array([[0], [1], [3], [6], [8]])
pred = np.full_like(y_hb, y_hb.mean())
lr = 0.5
print(f"Step 0 (mean)   MSE: {np.mean((y_hb - pred) ** 2):.4f}")
for step in range(1, 4):
    resid = y_hb - pred
    stump = DecisionTreeRegressor(max_depth=1, random_state=42)
    stump.fit(x_anc, resid)
    pred = pred + lr * stump.predict(x_anc)
    print(f"Step {step} (boost) MSE: {np.mean((y_hb - pred) ** 2):.4f}")

# 2. Native NaN handling of HistGradientBoosting on all 500 MCH rows
X_full = mch[features]
y_full = mch["child_stunted"]

24.3.6 Interpretability: Permutation Importance vs. Default MDI Bias

Let’s test Scikit-Learn’s default .feature_importances_ (Mean Decrease in Impurity, MDI) by injecting a pure random noise column (random_noise_id) into mch_survey_sample:

rng = np.random.default_rng(42)
noisy = clean.copy()
noisy["random_noise_id"] = rng.uniform(0, 1000, size=len(noisy))
f_noise = features + ["random_noise_id"]
Xn_tr, Xn_te, yn_tr, yn_te = train_test_split(
    noisy[f_noise], noisy["child_stunted"],
    test_size=0.25, stratify=noisy["child_stunted"], random_state=42,
)
rf_noise = RandomForestClassifier(
    n_estimators=100, max_depth=6, random_state=42
).fit(Xn_tr, yn_tr)
pi_noise = permutation_importance(
    rf_noise, Xn_te, yn_te, scoring="roc_auc",
    n_repeats=10, random_state=42,
)
imp_df = pd.DataFrame({
    "feature": f_noise,
    "mdi_impurity": np.round(rf_noise.feature_importances_, 4),
    "perm_auc_mean": np.round(pi_noise.importances_mean, 4),
    "perm_auc_std": np.round(pi_noise.importances_std, 4),
}).sort_values("mdi_impurity", ascending=False)
print(imp_df.to_string(index=False))

24.3.7 Exact 3-Feature Shapley Values (SHAP Intuition) From Scratch

How do we explain one individual household’s predicted stunting probability \(f(x)\)? Cooperative game theory’s Shapley value treats each feature as a player joining a coalition from a reference baseline_row to x_row. Because tree models contain feature interactions, the marginal credit of revealing feature \(i\) depends on which features were already revealed. Averaging across all \(p!\) permutations yields the unique attribution satisfying Efficiency, Symmetry, Dummy, and Additivity:

\[\phi_i(x) = \frac{1}{p!} \sum_{\pi \in S_p} \Big[ f\big(S_\pi(i) \cup \{i\}\big) - f\big(S_\pi(i)\big) \Big], \qquad \phi_0 + \sum_{i=1}^{p} \phi_i(x) = f(x)\]

top3 = ["wealth_rank", "anc_visits", "maternal_hb_g_dl"]

    n_estimators=100, max_depth=4, random_state=42
).fit(X_train[top3].to_numpy(), y_train.to_numpy())

def rf3_proba(v):
    arr = np.asarray(v, dtype=float).reshape(1, -1)
    return float(rf3.predict_proba(arr)[0, 1])

def shapley_3_demo(predict_fn, x_row, base_row):
    x = np.asarray(x_row, dtype=float)
    base = np.asarray(base_row, dtype=float)
    base_val = float(predict_fn(base))
    pred_val = float(predict_fn(x))
    contribs = np.zeros(3, dtype=float)
    perms = list(itertools.permutations([0, 1, 2]))
    for perm in perms:
        state = base.copy()
        prev = base_val
        for idx in perm:
            state[idx] = x[idx]
            curr = float(predict_fn(state))
            contribs[idx] += curr - prev
            prev = curr
    shap_vals = contribs / len(perms)
    return {
        "base_value": round(base_val, 4),
        "shap_values": [round(float(v), 4) for v in shap_vals],
        "prediction": round(pred_val, 4),
    }

24.3.8 Break It On Purpose! (Tree & Ensemble Error Anatomy)

ImportantBreak It On Purpose #1 — ValueError / InvalidParameterError (max_depth=0) 
bad_tree = DecisionTreeClassifier(max_depth=0, random_state=42)
bad_tree.fit(X_train, y_train)

Python’s Traceback:

InvalidParameterError: The 'max_depth' parameter of DecisionTreeClassifier
must be an int in the range [1, inf) or None. Got 0 instead.

Diagnosis: InvalidParameterError (a subclass of ValueError) fires because a decision tree must have at least depth 1 (a decision stump) or None (grow until leaves are pure). Setting max_depth=0 leaves zero splits possible.
Fix: Use max_depth >= 1 (e.g., 1 for a stump, 3..6 for regularized trees) or max_depth=None when intentionally testing an unpruned tree.

ImportantBreak It On Purpose #2 — ValueError (oob_score=True With bootstrap=False) 
bad_rf = RandomForestClassifier(
    n_estimators=50, oob_score=True, bootstrap=False, random_state=42
)
bad_rf.fit(X_train, y_train)

Python’s Traceback:

ValueError: Out of bag estimation only available if bootstrap=True

Diagnosis: Out-of-Bag scoring depends mathematically on bootstrap resampling with replacement leaving ~36.8% of training rows unused in each tree. When bootstrap=False, every tree sees 100% of rows, so no out-of-bag rows exist!
Fix: Keep the default bootstrap=True whenever oob_score=True, or use \(k\)-fold cross-validation if you deliberately disable bootstrapping.

ImportantBreak It On Purpose #3 — ValueError (Passing NaNs Into Classic GradientBoostingClassifier) 
bad_gbc = GradientBoostingClassifier(random_state=42)
bad_gbc.fit(Xf_tr, yf_tr)

Python’s Traceback:

ValueError: Input X contains NaN.
GradientBoostingClassifier does not accept missing values encoded as NaN
natively. For supervised learning, you might want to consider
sklearn.ensemble.HistGradientBoostingClassifier and Regressor which
accept missing values encoded as NaNs natively.

Diagnosis: Classic GradientBoostingClassifier (like LogisticRegression and pre-1.4 versions of RandomForestClassifier) refuses NaN inputs and crashes during .fit().
Fix: Either wrap the estimator in a leakage-free Pipeline([("imputer", SimpleImputer(strategy="median")), ("clf", ...)]), drop incomplete rows intentionally, or switch directly to HistGradientBoostingClassifier, which learns optimal left/right branches for missing values natively.

def run_stunting_tree_audit(raw_df, seed=42):
    """Clean MCH data, benchmark 3 tree models, and audit top driver."""
    work = raw_df.copy()
    work["residence"] = (
        work["residence"].astype(str).str.strip().str.title()
    )
    work["anc_visits"] = work["anc_visits"].replace(999, np.nan)
    work["is_urban"] = (work["residence"] == "Urban").astype(int)
    w_map = {
        "Poorest": 1, "Poorer": 2, "Middle": 3,
        "Richer": 4, "Richest": 5,
    }
    work["wealth_rank"] = (
        work["wealth_quintile"].astype(str).str.strip().str.title()
        .map(w_map)
    )
    feats = [
        "maternal_age_years", "anc_visits", "maternal_hb_g_dl",
        "is_urban", "wealth_rank",
    ]
    df = work[feats + ["child_stunted"]].dropna()
    X_tr, X_te, y_tr, y_te = train_test_split(
        df[feats], df["child_stunted"].astype(int),
        test_size=0.25, stratify=df["child_stunted"], random_state=seed,
    )
    models = [
        ("DecisionTree", DecisionTreeClassifier(
            max_depth=5, random_state=seed)),
        ("RandomForest", RandomForestClassifier(
            n_estimators=100, max_depth=6, random_state=seed)),
        ("HistGradientBoosting", HistGradientBoostingClassifier(
            max_depth=4, random_state=seed)),
    ]
    rows, fitted = [], {}
    for name, clf in models:
        clf.fit(X_tr, y_tr)
        proba = clf.predict_proba(X_te)[:, 1]
        rows.append({
            "model": name,
            "roc_auc": round(float(roc_auc_score(y_te, proba)), 4),
            "pr_auc": round(
                float(average_precision_score(y_te, proba)), 4
            ),
        })
        fitted[name] = clf
    board = (
        pd.DataFrame(rows)
        .sort_values("roc_auc", ascending=False)
        .reset_index(drop=True)
    )
    winner = str(board.iloc[0]["model"])
    pi = permutation_importance(
        fitted[winner], X_te, y_te, scoring="roc_auc",
        n_repeats=10, random_state=seed,
    )
    top_feat = feats[int(np.argmax(pi.importances_mean))]
    return board, winner, top_feat

# To-Do 24.1
def gini_impurity(y):
    """Compute Gini impurity 1 - sum(p_k^2) rounded to 4 decimals."""
    arr = np.asarray(y)
    if arr.size == 0:
        return 0.0
    _, counts = np.unique(arr, return_counts=True)
    probs = counts / arr.size
    return round(float(1.0 - np.sum(probs ** 2)), 4)

# To-Do 24.2
def shannon_entropy(y):
    """Compute base-2 Shannon entropy rounded to 4 decimals."""
    arr = np.asarray(y)
    if arr.size == 0:
        return 0.0
    _, counts = np.unique(arr, return_counts=True)
    probs = counts / arr.size
    probs = probs[probs > 0]
    ent = float(-np.sum(probs * np.log2(probs)))
    return round(0.0 if ent == 0.0 else ent, 4)

# To-Do 24.3
def best_stump_split(x_feature, y):
    """Find midpoint threshold minimizing weighted Gini impurity."""
    def _gini(arr):
        if arr.size == 0:
            return 0.0
        _, counts = np.unique(arr, return_counts=True)
        probs = counts / arr.size
        return float(1.0 - np.sum(probs ** 2))

    x = np.asarray(x_feature, dtype=float)
    y_arr = np.asarray(y)
    uniq = np.unique(x)
    mids = (uniq[:-1] + uniq[1:]) / 2.0
    best_t, best_g = float(mids[0]), float("inf")
    n = y_arr.size
    for t in mids:
        left = y_arr[x <= t]
        right = y_arr[x > t]
        wg = (left.size / n) * _gini(left) + (right.size / n) * _gini(right)
        if wg < best_g:
            best_g = wg
            best_t = float(t)
    return (round(best_t, 4), round(best_g, 4))

        n_repeats=10, random_state=seed,
    )
    df = pd.DataFrame({
        "feature": list(feature_names),
        "importance_mean": np.round(res.importances_mean, 4),
        "importance_std": np.round(res.importances_std, 4),
    })
    return df.sort_values(
        "importance_mean", ascending=False
    ).reset_index(drop=True)

import itertools
from sklearn.model_selection import train_test_split

# Exam Task 24.1 (30 pts)
def exact_shapley_3features(predict_fn, x_row, baseline_row):
    """Compute exact 3-feature Shapley values over all 6 permutations."""
    x = np.asarray(x_row, dtype=float)
    base = np.asarray(baseline_row, dtype=float)
    base_val = float(predict_fn(base))
    pred_val = float(predict_fn(x))
    contribs = np.zeros(3, dtype=float)
    perms = list(itertools.permutations([0, 1, 2]))
    for perm in perms:
        state = base.copy()
        prev = base_val
        for idx in perm:
            state[idx] = x[idx]
            curr = float(predict_fn(state))
            contribs[idx] += curr - prev
            prev = curr
    shap_vals = contribs / len(perms)
    return {
        "base_value": round(base_val, 4),
        "shap_values": [round(float(v), 4) for v in shap_vals],
        "prediction": round(pred_val, 4),
    }

def tune_random_forest_oob(X_train, y_train, max_depths, seed=42):
    """Select best RandomForest max_depth using Out-of-Bag accuracy."""
    rows = []
    best_depth = int(max_depths[0])
    best_oob = -1.0
    for d in max_depths:
        rf = RandomForestClassifier(
            n_estimators=120, max_depth=d,
            oob_score=True, random_state=seed,
        ).fit(X_train, y_train)
        score = float(rf.oob_score_)
        rows.append({"max_depth": int(d), "oob_score": round(score, 4)})
        if score > best_oob:
            best_oob = score
            best_depth = int(d)
    return {
        "best_depth": best_depth,
        "best_oob_score": round(best_oob, 4),
        "oob_table": pd.DataFrame(rows),
    }

def public_health_tree_benchmark(mch_df, seed=42):
    """Benchmark 3 tree families on MCH stunting and rank top driver."""
    work = mch_df.copy()
    work["residence"] = (
        work["residence"].astype(str).str.strip().str.title()
    )
    work["anc_visits"] = work["anc_visits"].replace(999, np.nan)
    work["is_urban"] = (work["residence"] == "Urban").astype(int)
    w_map = {
        "Poorest": 1, "Poorer": 2, "Middle": 3,
        "Richer": 4, "Richest": 5,
    }
    work["wealth_rank"] = (
        work["wealth_quintile"].astype(str).str.strip().str.title()
        .map(w_map)
    )
    feats = [
        "maternal_age_years", "anc_visits", "maternal_hb_g_dl",
        "is_urban", "wealth_rank",
    ]
    clean = work[feats + ["child_stunted"]].dropna()
    X = clean[feats]
    y = clean["child_stunted"].astype(int)
    X_tr, X_te, y_tr, y_te = train_test_split(
        X, y, test_size=0.25, stratify=y, random_state=seed
    )
    specs = [
        ("DecisionTree", DecisionTreeClassifier(
            max_depth=5, random_state=seed)),
        ("RandomForest", RandomForestClassifier(
            n_estimators=100, max_depth=6, random_state=seed)),
        ("HistGradientBoosting", HistGradientBoostingClassifier(
            max_depth=4, random_state=seed)),
    ]
    rows, fitted = [], {}
    for name, clf in specs:
        clf.fit(X_tr, y_tr)
        proba = clf.predict_proba(X_te)[:, 1]
        rows.append({
            "model": name,
            "roc_auc": round(float(roc_auc_score(y_te, proba)), 4),
            "pr_auc": round(
                float(average_precision_score(y_te, proba)), 4
            ),
        })
        fitted[name] = clf
    leaderboard = (
        pd.DataFrame(rows)
        .sort_values("roc_auc", ascending=False)
        .reset_index(drop=True)
    )
    best_model = str(leaderboard.iloc[0]["model"])
    pi = permutation_importance(
        fitted[best_model], X_te, y_te, scoring="roc_auc",
        n_repeats=10, random_state=seed,
    )
    top_feature = feats[int(np.argmax(pi.importances_mean))]
    return {
        "leaderboard": leaderboard,
        "best_model": best_model,
        "top_feature": top_feature,
    }

24.8.4 D. Debugging Post-Mortem: Top 3 Chapter 24 Failure Modes

  1. Passing Hard Class Predictions (.predict) Instead of Probabilities (.predict_proba[:, 1]) Into ROC-AUC / PR-AUC: Hard binary labels collapse all probability thresholds to a single operating point, distorting both roc_auc_score and average_precision_score. Always slice column 1 of .predict_proba(X).
  2. Trusting Default MDI .feature_importances_ on Mixed-Cardinality Clinical Data: Training-set impurity gain rewards continuous or ID-like columns with many split thresholds—even pure noise! Always validate global driver rankings with held-out permutation_importance on (X_test, y_test).
  3. Evaluating Only One Feature Order When Explaining Nonlinear Models: In models with feature interactions, changing which feature is turned on first shifts marginal credit dramatically. Averaging across permutations (exact Shapley / TreeSHAP) is the only way to preserve fair attribution and guarantee the Efficiency Axiom \(\phi_0 + \sum_i \phi_i = f(x)\).
