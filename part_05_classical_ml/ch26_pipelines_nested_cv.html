26.1 Stage 1 — First-Principles Intuition: Why Notebooks Break in Peer Review and Production

Across Chapters 21–25, you trained linear models, regularized regressions, decision trees, random forests, gradient boosting ensembles, clustering algorithms, and explainability audits. Yet more than half of published clinical ML papers suffer from subtle methodological leakage that silently inflates reported ROC-AUC before the model ever touches a new clinic.

Four production engineering failures account for nearly every collapse between a promising Jupyter experiment and real-world deployment:

  • Preprocessing Leakage Across Folds: Imputing missing hemoglobin with the entire dataset’s median or fitting StandardScaler before train_test_split leaks test-set distribution statistics into training. Wrapping every preprocessing step inside a Scikit-Learn Pipeline guarantees that medians, means, and category vocabularies are learned exclusively on each training fold.
  • Wrong Cross-Validation Splitter for the Study Design: Randomly splitting households from the same Bangladesh DHS primary sampling unit (cluster_id) lets a model memorize village-level wealth patterns instead of generalizing to unseen communities (GroupKFold). Likewise, randomly shuffling weekly dengue surveillance rows lets a model peek at next week’s monsoon outbreak to predict last week (TimeSeriesSplit).
  • Tuning Optimism Bias (Reporting GridSearchCV.best_score_): When you evaluate 20 hyperparameter combinations via 5-fold CV and publish the highest CV score as your model’s generalization performance, you have overfitted the validation folds! Nested Cross-Validation separates hyperparameter selection (inner loop) from unbiased performance estimation (outer loop).
  • Training–Serving Skew (Saving Bare Models Without Preprocessing): Saving only a trained LogisticRegression object while keeping sentinel-999 cleanup, median imputation, and one-hot encoding scattered across notebook cells guarantees silent bugs in production. Serializing the entire fitted Pipeline with joblib locks preprocessing and model weights into one atomic artifact.
NoteMental Model — One Pipeline, Two Nested Loops, One Artifact

Think of a production ML workflow as three nested protective shells:

  1. Inner Shell (ColumnTransformer + Pipeline): Turns messy raw clinical rows (containing 999, NaN, and unseen districts) into clean numeric tensors with zero leakage.
  2. Middle Shell (Study-Matched CV & Nested CV): Evaluates the entire tuning procedure on held-out clusters, future epi-weeks, or untouched outer folds so reported ROC-AUC / RMSE is reviewer-proof.
  3. Outer Shell (joblib Serialization): Packages the refitted winning Pipeline into a single reproducible file verified for bit-exact prediction parity.

WarningTwo Silent Scikit-Learn Traps to Watch For
  1. Unseen Test Categories: OneHotEncoder defaults to handle_unknown="error", which crashes inference the instant a new district or clinic tier appears at test time. Always set handle_unknown="ignore" and sparse_output=False (required by dense-input models like HistGradientBoostingClassifier).
  2. Pipeline Parameter Naming: Inside a Pipeline([("prep", prep), ("model", clf)]), hyperparameters for GridSearchCV MUST use double-underscore prefixes ("model__C", "prep__num__imputer__strategy"). Passing bare "C" raises ValueError: Invalid parameter 'C'.

26.3.2 Custom Scikit-Learn Transformer (SentinelToNaNTransformer)

class SentinelToNaNTransformer(BaseEstimator, TransformerMixin):
    """Replace a survey sentinel code (e.g., 999) with np.nan."""

    def __init__(self, sentinel=999):
        self.sentinel = sentinel

    def fit(self, X, y=None):
        return self

    def transform(self, X):
        if isinstance(X, pd.DataFrame):
            return X.copy().replace(self.sentinel, np.nan)
        arr = np.asarray(X, dtype=float).copy()
        arr[arr == self.sentinel] = np.nan
        return arr

raw_anc = mch_raw[["anc_visits", "maternal_hb_g_dl"]].copy()
tr = SentinelToNaNTransformer(sentinel=999)
clean_anc = tr.fit_transform(raw_anc)
print("Raw anc_visits max:", raw_anc["anc_visits"].max(),
      "| 999 count:", int((raw_anc["anc_visits"] == 999).sum()))
print("Transformed anc_visits max:", clean_anc["anc_visits"].max(),
      "| NaN count:", int(clean_anc["anc_visits"].isna().sum()))
print("Original raw_anc mutated?:",
      bool((raw_anc["anc_visits"] == 999).sum() != 8))

Expected Output:

Raw anc_visits max: 999 | 999 count: 8
Transformed anc_visits max: 10.0 | NaN count: 8
Original raw_anc mutated?: False

Why does inheriting from (BaseEstimator, TransformerMixin) matter so much?

  • BaseEstimator automatically supplies .get_params() and .set_params(), letting sklearn.base.clone() and GridSearchCV clone your custom transformer inside every CV fold—provided __init__ assigns self.sentinel = sentinel without altering it.
  • TransformerMixin automatically supplies .fit_transform(X, y) by chaining .fit(X, y) (which returns self) and .transform(X).
  • Branching cleanly on isinstance(X, pd.DataFrame) vs. np.asarray(X, dtype=float).copy() prevents both caller mutation and integer-array NaN assignment crashes.

26.3.3 Leak-Free ColumnTransformer + Pipeline for Mixed Clinical Data

num_cols = ["maternal_age_years", "anc_visits", "maternal_hb_g_dl"]
cat_cols = ["residence", "wealth_quintile"]
X = mch[num_cols + cat_cols]
y = mch["child_stunted"]
groups = mch["cluster_id"]

])

Z_demo = prep.fit_transform(X)
print("Prepared matrix shape:", Z_demo.shape,
      "| any NaN?:", bool(np.isnan(Z_demo).any()))
unseen_row = pd.DataFrame([{
    "maternal_age_years": 26,
    "anc_visits": 999,
    "maternal_hb_g_dl": np.nan,
    "residence": "PeriUrban",
    "wealth_quintile": "Middle",

pipe_lr.fit(X, y)
prob = pipe_lr.predict_proba(unseen_row)[0, 1]
print("Unseen-category + 999 prob:", round(float(prob), 4))

Expected Output:

Unseen-category + 999 prob: 0.055

Trace how unseen_row flowed safely through pipe_lr.predict_proba(unseen_row):

26.3.4 Matching CV Splitters to Study Design (StratifiedKFold, GroupKFold, TimeSeriesSplit)

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
skf_auc = cross_val_score(pipe_lr, X, y, cv=skf, scoring="roc_auc")

gkf = GroupKFold(n_splits=5)
gkf_auc = cross_val_score(
    pipe_lr, X, y, groups=groups, cv=gkf, scoring="roc_auc"
)

dhaka = (
    epi_raw[epi_raw["district"] == "Dhaka"]
    .sort_values(["year", "epi_week"])
    .reset_index(drop=True)
)
X_epi = dhaka[["rainfall_mm", "mean_temp_c", "epi_week"]]
y_epi = dhaka["dengue_cases"]
ts_pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("model", Ridge(alpha=1.0)),
])
tscv = TimeSeriesSplit(n_splits=4)
ts_rmse = -cross_val_score(
    ts_pipe, X_epi, y_epi, cv=tscv,
    scoring="neg_root_mean_squared_error",
)
print(f"StratifiedKFold (5-fold) AUC: "
      f"{skf_auc.mean():.4f} +/- {skf_auc.std():.4f}")
print(f"GroupKFold (50 clusters) AUC: "
      f"{gkf_auc.mean():.4f} +/- {gkf_auc.std():.4f}")
print(f"TimeSeriesSplit (Dhaka) RMSE: {ts_rmse.mean():.4f} | "
      f"folds: {[round(float(r), 2) for r in ts_rmse]}")

Expected Output:

StratifiedKFold (5-fold) AUC: 0.6844 +/- 0.0535
GroupKFold (50 clusters) AUC: 0.7168 +/- 0.0802
TimeSeriesSplit (Dhaka) RMSE: 92.6077 | folds: [242.89, 25.03, 59.17, 43.34]

Study the scientific contrast across all three validation strategies:

  • StratifiedKFold preserves the 14% stunting class prevalence (70/500) across folds (AUC = 0.6844 +/- 0.0535), appropriate for independent patient cohorts.
  • GroupKFold holds out entire DHS clusters (10 clusters per validation fold, zero cluster overlap between train and test), revealing larger fold-to-fold variance (+/- 0.0802) driven by community-level heterogeneity.
  • TimeSeriesSplit enforces strict chronological ordering on Dhaka’s 104 weekly dengue counts. Notice why Fold 1 has high RMSE (242.89) while Folds 2–4 drop to 25.03–59.17: Fold 1 predicts the very first unseen monsoon peak from winter training weeks alone, whereas later expanding windows have observed a full seasonal cycle! Remember also to negate neg_root_mean_squared_error so RMSE is positive.

26.3.5 Eliminating Tuning Optimism Bias With True Nested Cross-Validation

Suppose you tune a RandomForestClassifier grid with flat GridSearchCV and report flat_gs.best_score_. How optimistic is that score compared to true Nested CV where every outer fold tunes hyperparameters strictly on its own inner folds?

pipe_rf = Pipeline([
    ("prep", prep),
    ("model", RandomForestClassifier(
        n_estimators=25, random_state=42
    )),
])
rf_grid = {
    "model__max_depth": [2, 4, 8],
    "model__min_samples_leaf": [1, 5, 15],
}
outer_cv = StratifiedKFold(n_splits=4, shuffle=True, random_state=42)
flat_gs = GridSearchCV(pipe_rf, rf_grid, cv=outer_cv, scoring="roc_auc")
flat_gs.fit(X, y)

nested_scores = []
for tr_i, te_i in outer_cv.split(X, y):
    inner_cv = StratifiedKFold(
        n_splits=3, shuffle=True, random_state=42
    )
    gs = GridSearchCV(
        pipe_rf, rf_grid, cv=inner_cv, scoring="roc_auc"
    )
    gs.fit(X.iloc[tr_i], y.iloc[tr_i])
    prob = gs.best_estimator_.predict_proba(X.iloc[te_i])[:, 1]
    nested_scores.append(round(float(roc_auc_score(y.iloc[te_i], prob)), 4))

bias = float(flat_gs.best_score_ - np.mean(nested_scores))
print(f"Naive Flat GridSearchCV AUC: {flat_gs.best_score_:.4f} | "
      f"best: {flat_gs.best_params_}")
print(f"True Nested CV AUC:          {np.mean(nested_scores):.4f} "
      f"+/- {np.std(nested_scores):.4f}")
print("Outer fold scores:", nested_scores)
print(f"Optimism bias (flat - nested): {bias:.4f}")

Expected Output:

Naive Flat GridSearchCV AUC: 0.6827 | best: {'model__max_depth': 8, 'model__min_samples_leaf': 5}
True Nested CV AUC:          0.6716 +/- 0.0360
Outer fold scores: [0.6266, 0.6495, 0.7199, 0.6903]
Optimism bias (flat - nested): 0.0112

There it is in black and white: even on a modest 9-configuration grid, reporting flat_gs.best_score_ (0.6827) inflates expected generalization by +0.0112 ROC-AUC over unbiased Nested CV (0.6716). On larger 100-configuration grids in small clinical cohorts (\(n < 500\)), this selection optimism easily reaches +0.03 to +0.07 AUC!

26.3.6 Efficient Hyperparameter Search (RandomizedSearchCV & Optuna Concepts)

Exhaustive grid search scales exponentially (\(O(m^d)\)) in the number of hyperparameters \(d\). Sampling random combinations (RandomizedSearchCV) or using adaptive Tree-structured Parzen Estimator (TPE) Bayesian optimization (as in Optuna) explores far more unique values of important hyperparameters within the same compute budget:

param_dist = {
    "model__max_depth": [2, 3, 4, 6, 8, None],
    "model__min_samples_leaf": [1, 2, 5, 10, 15],
    "model__max_features": ["sqrt", "log2", 0.7],
}
rs = RandomizedSearchCV(
    pipe_rf,
    param_dist,
    n_iter=6,
    cv=StratifiedKFold(n_splits=4, shuffle=True, random_state=42),
    scoring="roc_auc",
    random_state=42,
)
rs.fit(X, y)
print(f"RandomizedSearchCV (6 draws) best AUC: {rs.best_score_:.4f}")
print("Best params:", rs.best_params_)

Expected Output:

RandomizedSearchCV (6 draws) best AUC: 0.6862
Best params: {'model__min_samples_leaf': 5, 'model__max_features': 'log2', 'model__max_depth': 3}

With only 6 random draws from a 90-point search space, RandomizedSearchCV outperformed the 9-point rigid grid (0.6862 vs. 0.6827) while running 33% fewer model fits! In large deep-learning or gradient-boosting sweeps, Optuna (optuna.create_study(direction="maximize")) takes this one step further by fitting a probabilistic surrogate model (TPE) over completed trials to focus subsequent trials on high-AUC regions while pruning hopeless runs early.

26.3.7 Reproducible Serialization With joblib Inside tempfile.TemporaryDirectory()

X_clean = X.replace(999, np.nan)
deploy_prep = ColumnTransformer([
    ("num", Pipeline([
        ("imputer", SimpleImputer(strategy="median")),
        ("scaler", StandardScaler()),
    ]), num_cols),
    ("cat", cat_pipe, cat_cols),
])
deploy_pipe = Pipeline([
    ("prep", deploy_prep),
    ("model", LogisticRegression(max_iter=500)),
])
deploy_pipe.fit(X_clean, y)
X_sample = X_clean.iloc[:5]
with tempfile.TemporaryDirectory() as tmpdir:
    artifact = Path(tmpdir) / "stunting_lr_pipeline.joblib"
    joblib.dump(deploy_pipe, artifact)
    reloaded = joblib.load(artifact)
    p_orig = deploy_pipe.predict_proba(X_sample)[:, 1]
    p_load = reloaded.predict_proba(X_sample)[:, 1]
    print("Saved artifact bytes:", artifact.stat().st_size)
    print("Predictions bit-identical?:",
          bool(np.allclose(p_orig, p_load)))
    print("Reloaded risk probs:",
          [round(float(p), 4) for p in p_load])

Expected Output:

Saved artifact bytes: 4474
Predictions bit-identical?: True
Reloaded risk probs: [0.2576, 0.3069, 0.2505, 0.1818, 0.3862]

The entire production pipeline—training medians, scaling parameters, one-hot vocabulary, and logistic weights—serializes into just 4,474 bytes and reloads with bit-identical probabilities. Notice a subtle Python MLOps rule demonstrated here: pipelines composed of built-in Scikit-Learn steps reload anywhere out-of-the-box, whereas custom classes (like SentinelToNaNTransformer) must be defined in an importable .py module—not an interactive __main__ notebook cell—before joblib.dump can pickle them cleanly for another server. Wrapping verification demos in tempfile.TemporaryDirectory() guarantees automatic cleanup so stray .joblib binaries never pollute your Git repository.

26.3.8 Break It On Purpose! (Production ML Error Anatomy)

ImportantBreak It On Purpose #1 — ValueError (Unseen Category When handle_unknown='error') 
enc_strict = OneHotEncoder(handle_unknown="error", sparse_output=False)
enc_strict.fit(pd.DataFrame({"district": ["Dhaka", "Sylhet"]}))
enc_strict.transform(pd.DataFrame({"district": ["Khulna"]}))

Python’s Traceback:

ValueError: Found unknown categories ['Khulna'] in column 0 during transform

Diagnosis: OneHotEncoder defaults to handle_unknown="error". The first time a validation fold or new clinic sends a district unseen during training ("Khulna"), inference crashes immediately.
Fix: Always configure OneHotEncoder(handle_unknown="ignore", sparse_output=False) so unseen categories safely map to an all-zero indicator vector.

ImportantBreak It On Purpose #2 — ValueError (Missing model__ Prefix in GridSearchCV)

Python’s Traceback:

ValueError: Invalid parameter 'C' for estimator Pipeline(...).
Valid parameters are: ['memory', 'steps', 'transform_input', 'verbose'].

Diagnosis: GridSearchCV inspects parameters of the outer Pipeline object, not its inner classifier. Bare "C" does not exist on Pipeline.

def audit_and_package_dhs_model(raw_df, seed=42):
    """Run Group-Nested CV, refit best DHS pipeline & verify joblib."""
    df = raw_df.copy()
    df["residence"] = (
        df["residence"].astype(str).str.strip().str.title()
    )
    n_cols = ["maternal_age_years", "anc_visits", "maternal_hb_g_dl"]
    c_cols = ["residence", "wealth_quintile"]
    df[n_cols] = df[n_cols].replace(999, np.nan)
    X_all, y_all = df[n_cols + c_cols], df["child_stunted"]
    grps = df["cluster_id"]

    n_pipe = Pipeline([
        ("imputer", SimpleImputer(strategy="median")),
        ("scaler", StandardScaler()),
    ])
    c_pipe = Pipeline([
        ("imputer", SimpleImputer(strategy="most_frequent")),
        ("encoder", OneHotEncoder(
            handle_unknown="ignore", sparse_output=False
        )),
    ])
    pre = ColumnTransformer([
        ("num", n_pipe, n_cols),
        ("cat", c_pipe, c_cols),
    ])
    cand = Pipeline([
        ("prep", pre),
        ("model", LogisticRegression(max_iter=500)),
    ])

    grid = {"model__C": [0.05, 0.2, 1.0, 5.0]}
    outer = GroupKFold(n_splits=5)
    fold_aucs = []
    for tr_i, te_i in outer.split(X_all, y_all, groups=grps):
        inner = StratifiedKFold(
            n_splits=3, shuffle=True, random_state=seed
        )
        search = GridSearchCV(cand, grid, cv=inner, scoring="roc_auc")
        search.fit(X_all.iloc[tr_i], y_all.iloc[tr_i])
        pr = search.best_estimator_.predict_proba(X_all.iloc[te_i])[:, 1]
        auc_i = roc_auc_score(y_all.iloc[te_i], pr)
        fold_aucs.append(round(float(auc_i), 4))

    final_search = GridSearchCV(
        cand, grid,
        cv=StratifiedKFold(n_splits=3, shuffle=True, random_state=seed),
        scoring="roc_auc",
    )
    final_search.fit(X_all, y_all)
    best_pipe = final_search.best_estimator_

    with tempfile.TemporaryDirectory() as tmpdir:
        out_path = Path(tmpdir) / "dhs_production_pipe.joblib"
        joblib.dump(best_pipe, out_path)
        reloaded = joblib.load(out_path)
        same = bool(np.allclose(
            best_pipe.predict_proba(X_all.iloc[:5])[:, 1],
            reloaded.predict_proba(X_all.iloc[:5])[:, 1],
        ))
        n_bytes = int(out_path.stat().st_size)

    return {
        "nested_group_auc": round(float(np.mean(fold_aucs)), 4),
        "nested_group_std": round(float(np.std(fold_aucs)), 4),
        "best_C": final_search.best_params_["model__C"],
        "artifact_bytes": n_bytes,
        "reload_verified": same,
    }

26.8 Stage 8 — Complete Annotated Solutions & Debugging Post-Mortem

26.8.1 A. Concept & Execution Trace Test Key

  1. Test-fold medians, means, and standard deviations leaked into every training fold, subtly inflating validation accuracy. A Pipeline fits imputers and scalers exclusively on X_train inside each fold and applies .transform(X_val) using those training-only statistics.
  2. Scikit-Learn’s clone() inspects __init__ parameter names via get_params() and expects an identically named, unmodified attribute (self.sentinel). Renaming or mutating it breaks cloning inside cross_val_score and GridSearchCV.
  3. NumPy raises ValueError: cannot convert float NaN to integer. Always convert to a floating-point copy first: arr = np.asarray(X, dtype=float).copy().
  4. SimpleImputer sees 999 as a valid number (leaving it untouched and skewing the training median), and then SentinelToNaNTransformer turns 999 into NaN—sending un-imputed NaNs straight into StandardScaler and crashing LogisticRegression!
  5. It outputs [0.0, 0.0] (all zeros across the known category columns) without raising an error.
    1. GroupKFold grouped by patient_id (prevents repeat-visit patient leakage); (b) TimeSeriesSplit (prevents future-to-past look-ahead leakage); (c) StratifiedKFold (preserves the 3% rare positive class across independent donors).
  7. Scikit-Learn enforces a uniform “higher is better” convention across all scorers so GridSearchCV can always maximize. Multiply by -1 (rmses = -scores) before reporting RMSE.
  8. Each of the 4 outer folds runs 3 inner folds * 5 grid configs = 15 inner fits plus 1 refit of best_estimator_ on the full outer training fold = 16 fits per outer fold \(\Rightarrow 4 \times 16 = \mathbf{64}\) total pipeline .fit() calls!
  9. A \(2^4\) grid tests only 2 unique values along the single important hyperparameter, whereas RandomizedSearchCV(n_iter=20) probes 20 distinct values along every axis. Optuna’s TPE sampler further adapts sequentially, concentrating later trials near promising regions and pruning weak trials early.
  10. Saving only the bare model throws away the fitted sentinel cleaner, median imputer, scaler mean/SD, and one-hot encoder column order—causing silent feature misalignment or crashes when raw rows arrive in production.

# To-Do 26.1
class SentinelToNaNTransformer(BaseEstimator, TransformerMixin):
    """Replace numeric sentinel codes (e.g., 999) with np.nan."""

    def __init__(self, sentinel=999):
        self.sentinel = sentinel

    def fit(self, X, y=None):
        return self

    def transform(self, X):
        if isinstance(X, pd.DataFrame):
            return X.copy().replace(self.sentinel, np.nan)
        arr = np.asarray(X, dtype=float).copy()
        arr[arr == self.sentinel] = np.nan
        return arr

# To-Do 26.2
def build_mixed_preprocessor(num_cols, cat_cols):
    """Return a ColumnTransformer for numeric + categorical features."""
    num_pipe = Pipeline([
        ("imputer", SimpleImputer(strategy="median")),
        ("scaler", StandardScaler()),
    ])
    cat_pipe = Pipeline([
        ("imputer", SimpleImputer(strategy="most_frequent")),
        ("encoder", OneHotEncoder(
            handle_unknown="ignore", sparse_output=False
        )),
    ])
    return ColumnTransformer([
        ("num", num_pipe, num_cols),
        ("cat", cat_pipe, cat_cols),
    ])

# To-Do 26.3
def cross_validate_pipeline(pipe, X, y, cv=5, seed=42):
    """Evaluate a pipeline via StratifiedKFold ROC-AUC cross-validation."""
    skf = StratifiedKFold(
        n_splits=cv, shuffle=True, random_state=seed
    )
    scores = cross_val_score(pipe, X, y, cv=skf, scoring="roc_auc")
    return {
        "mean_roc_auc": round(float(scores.mean()), 4),
        "std_roc_auc": round(float(scores.std()), 4),
        "fold_scores": [round(float(s), 4) for s in scores],
    }

# To-Do 26.4
def group_cv_evaluation(pipe, X, y, groups, n_splits=5):
    """Evaluate a pipeline via GroupKFold ROC-AUC without group leaks."""
    gkf = GroupKFold(n_splits=n_splits)
    scores = cross_val_score(
        pipe, X, y, groups=groups, cv=gkf, scoring="roc_auc"
    )
    return {
        "mean_roc_auc": round(float(scores.mean()), 4),
        "std_roc_auc": round(float(scores.std()), 4),
        "n_splits": int(n_splits),
    }

# To-Do 26.5
def temporal_cv_forecast_rmse(pipe, X, y, n_splits=4):
    """Evaluate chronological forecasting RMSE via TimeSeriesSplit."""
    tscv = TimeSeriesSplit(n_splits=n_splits)
    rmses = -cross_val_score(
        pipe, X, y, cv=tscv, scoring="neg_root_mean_squared_error"
    )
    return {
        "mean_rmse": round(float(rmses.mean()), 4),
        "fold_rmses": [round(float(r), 4) for r in rmses],
    }

# To-Do 26.6
def save_and_reload_pipeline(pipe, model_path, X_sample):
    """Dump a fitted pipeline with joblib, reload, and verify preds."""
    joblib.dump(pipe, model_path)
    reloaded = joblib.load(model_path)
    orig_preds = pipe.predict(X_sample)
    reloaded_preds = reloaded.predict(X_sample)
    return {
        "file_bytes": int(Path(model_path).stat().st_size),
        "predictions_match": bool(
            np.allclose(orig_preds, reloaded_preds)
        ),
        "reloaded_preds": reloaded_preds,
    }

def run_nested_cv_audit(
    pipe, param_grid, X, y, outer_splits=4, inner_splits=3, seed=42
):
    """Run true Nested Stratified CV and return outer AUC audit."""
    outer_cv = StratifiedKFold(
        n_splits=outer_splits, shuffle=True, random_state=seed
    )
    outer_scores = []
    fold_best_params = []
    for tr_idx, te_idx in outer_cv.split(X, y):
        X_tr = X.iloc[tr_idx] if hasattr(X, "iloc") else X[tr_idx]
        X_te = X.iloc[te_idx] if hasattr(X, "iloc") else X[te_idx]
        y_tr = y.iloc[tr_idx] if hasattr(y, "iloc") else y[tr_idx]
        y_te = y.iloc[te_idx] if hasattr(y, "iloc") else y[te_idx]
        inner_cv = StratifiedKFold(
            n_splits=inner_splits, shuffle=True, random_state=seed
        )
        gs = GridSearchCV(
            pipe, param_grid, cv=inner_cv, scoring="roc_auc"
        )
        gs.fit(X_tr, y_tr)
        probs = gs.best_estimator_.predict_proba(X_te)[:, 1]
        outer_scores.append(round(float(roc_auc_score(y_te, probs)), 4))
        fold_best_params.append(gs.best_params_)
    return {
        "outer_mean_auc": round(float(np.mean(outer_scores)), 4),
        "outer_std_auc": round(float(np.std(outer_scores)), 4),
        "outer_scores": outer_scores,
        "fold_best_params": fold_best_params,
    }

26.8.4 D. Debugging Post-Mortem: Top 3 Chapter 26 Failure Modes

  1. Forgetting SentinelToNaNTransformer(999) Before SimpleImputer (or Mutating Inputs): If sentinel 999 is left uncleaned or placed after median imputation, 999 corrupts training means/SDs and produces nonsensical risk probabilities. Always clean sentinels first inside the numeric sub-pipeline on a non-mutated copy.
  2. Omitting handle_unknown="ignore" or model__ Prefixes: Default OneHotEncoder(handle_unknown="error") crashes whenever an unseen district appears in test data, while unprefixed keys like "C" fail inside GridSearchCV(Pipeline(...)). Always check pipe.get_params().keys() before writing a search grid.
  3. Confusing Flat CV Tuning Scores With Unbiased Generalization (or Ignoring Clusters/Time): Reporting GridSearchCV.best_score_ introduces positive optimism bias, and applying random KFold to clustered DHS surveys (cluster_id) or weekly surveillance (epi_week) leaks community and temporal structure. Match the splitter to the study design and wrap hyperparameter search inside Nested CV.
