9.1 Stage 1 — First-Principles Intuition: Volatile RAM vs. the Locked Archive Cabinet

Every variable you built in Chapters 1 through 8—lists of hemoglobin readings, dictionaries of outbreak counts, sets of unique districts—lived in RAM (Random Access Memory). RAM is blazingly fast, yet completely volatile: the moment your Google Colab runtime disconnects or your laptop reboots, every in-memory object vanishes without a trace.

Reproducible science requires persistence: saving cleaned cohorts, summary statistics, and study metadata onto disk so collaborators, statistical packages, and peer reviewers can inspect and verify every step.

NoteMental Model — The Locked Hospital Medical Archive

Working with files in Python works just like borrowing records from a locked hospital archive room:

  1. Archive Street Address (pathlib.Path): Rather than gluing folder names with brittle backslashes ("data\\raw.csv") that fail across Windows, macOS, and Linux, Path(folder) / "raw.csv" builds clean, portable file paths automatically.
  2. Self-Locking Checkout Gate (with open(...)): Opening a file checks out an operating-system handle. Wrapping it inside a with context manager guarantees Python flushes every buffered byte to disk and locks the cabinet again—even if an exception crashes halfway through your loop.
  3. Universal Ink Standard (encoding="utf-8"): Always declare encoding="utf-8" explicitly so clinical symbols (°C, μg/L) and international place names survive identically on every researcher’s computer.
  4. Right Cabinet for the Right Data (Text vs. CSV vs. JSON): Use plain text (.txt) for chronological shift logs, CSV (.csv) for flat row-by-column patient registries, and JSON (.json) for nested hierarchies (study metadata, cutoffs, grouped summaries).

9.1.1 Golden Rule of Non-Destructive Research Pipelines

Never overwrite your raw field survey file! Treat raw files as read-only evidence ("r"), transform them in Python memory, and write cleaned cohorts or aggregated summaries to new derived files ("w"). That way, if you discover a new sentinel code next month, you can re-run the pipeline from scratch with zero data loss.

9.3.1 Modern Paths (pathlib.Path) & Safe Text I/O (with open)

from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    log_path = Path(tmp) / "clinic_shift.txt"
    entries = [
        "08:15 | Dhaka-North | Temp 38.4°C",
        "09:00 | Sylhet-East | Hb 10.6 g/dL",
        "10:30 | Khulna-West | Routine ANC",
    ]
    with open(log_path, "w", encoding="utf-8") as out_f:
        for entry in entries:
            out_f.write(f"{entry}\n")

    print("File name:", log_path.name, "| Exists:", log_path.exists())
    with open(log_path, "r", encoding="utf-8") as in_f:
        for line_no, line in enumerate(in_f, start=1):
            print(f"Line {line_no}: {line.strip()}")

Expected Output:

File name: clinic_shift.txt | Exists: True
Line 1: 08:15 | Dhaka-North | Temp 38.4°C
Line 2: 09:00 | Sylhet-East | Hb 10.6 g/dL
Line 3: 10:30 | Khulna-West | Routine ANC

Key mechanics to inspect closely:

  • Path(tmp) / "clinic_shift.txt": pathlib.Path overloads the / operator to join directories and filenames cleanly on every operating system.
  • Explicit \n on writes: Unlike print(), out_f.write(...) does not append a newline automatically; omitting \n would glue all three entries onto one line.
  • Streaming line reads: Iterating for line in in_f: reads one line at a time using constant memory, and line.strip() removes the trailing \n.

9.3.2 Structured Tables with csv.DictWriter & csv.DictReader

Splitting CSV rows manually with line.split(",") breaks the moment a clinic address or diagnosis note contains a comma inside quotes ("Dhaka, North"). Always use Python’s standard-library csv module instead:

import csv
from pathlib import Path
import tempfile

records = [
    {"patient_id": "P001", "district": "Dhaka", "hb_g_dl": "10.4"},
    {"patient_id": "P002", "district": "Sylhet", "hb_g_dl": "12.1"},
    {"patient_id": "P003", "district": "Khulna", "hb_g_dl": "9.8"},
]

with tempfile.TemporaryDirectory() as tmp:
    csv_path = Path(tmp) / "mch_cohort.csv"
    fields = ["patient_id", "district", "hb_g_dl"]

    with open(csv_path, "w", encoding="utf-8", newline="") as out_f:
        writer = csv.DictWriter(out_f, fieldnames=fields)
        writer.writeheader()
        writer.writerows(records)

    with open(csv_path, "r", encoding="utf-8", newline="") as in_f:
        loaded = list(csv.DictReader(in_f))

    hb_vals = [float(row["hb_g_dl"]) for row in loaded]
    print("Rows loaded:", len(loaded))
    print("First row:", loaded[0])
    print("Mean Hb (g/dL):", round(sum(hb_vals) / len(hb_vals), 2))

Expected Output:

Rows loaded: 3
First row: {'patient_id': 'P001', 'district': 'Dhaka', 'hb_g_dl': '10.4'}
Mean Hb (g/dL): 10.77
WarningTwo Mandatory csv Habits
  1. Always pass newline="" to open(): Both csv.DictReader and csv.DictWriter manage line endings internally. Omitting newline="" inserts extra blank lines between every row on Windows!
  2. Materialize before closing: csv.DictReader(in_f) is a streaming iterator. If you need rows after the with block ends, wrap it in list(csv.DictReader(in_f)) while the file is still open.

9.3.3 Persisting Nested Metadata with json.dump & json.load

Flat CSV tables cannot naturally represent nested dictionaries, lists of study sites, or mixed booleans and floats. JSON (JavaScript Object Notation) preserves that full nested hierarchy cleanly across Python, R, JavaScript, and web APIs:

import json
from pathlib import Path
import tempfile

study_meta = {
    "study_id": "MCH-BD-2026",
    "sites": ["Dhaka", "Sylhet", "Khulna"],
    "cutoffs": {"anemia_g_dl": 11.0, "fever_c": 38.0},
    "active": True,
}

with tempfile.TemporaryDirectory() as tmp:
    json_path = Path(tmp) / "study_meta.json"
    with open(json_path, "w", encoding="utf-8") as out_f:
        json.dump(study_meta, out_f, indent=2)

    with open(json_path, "r", encoding="utf-8") as in_f:
        restored = json.load(in_f)

    print("Study ID:", restored["study_id"])
    print("Anemia cutoff:", restored["cutoffs"]["anemia_g_dl"])
    print("Protocol version:", restored.get("version", "v1.0"))

Expected Output:

Study ID: MCH-BD-2026
Anemia cutoff: 11.0
Protocol version: v1.0

Notice the crucial naming pair in Python’s json module:

  • json.dump(obj, file_handle) / json.load(file_handle) (no trailing s): read/write directly with an open file handle.
  • json.dumps(obj) / json.loads(text_str) (with trailing s for string): convert between Python objects and in-memory JSON strings.

9.3.4 Break It On Purpose! (File I/O & JSON Error Anatomy)

ImportantBreak It On Purpose #1 — FileNotFoundError on Missing CSV 
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    missing_path = Path(tmp) / "nonexistent_cohort.csv"
    with open(missing_path, "r", encoding="utf-8") as f:
        data = f.read()

Python’s Traceback:

FileNotFoundError: [Errno 2] No such file or directory:
'.../nonexistent_cohort.csv'

Diagnosis: Opening a file in read mode ("r") requires the file to already exist on disk. A single misspelled filename or wrong working folder triggers FileNotFoundError.
Fix: Verify missing_path.exists() or inspect missing_path.resolve() to confirm the exact path before opening.

ImportantBreak It On Purpose #2 — json.JSONDecodeError on Malformed JSON 
import json
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    broken_path = Path(tmp) / "broken_report.json"
    broken_path.write_text('{"Dengue": 14, "Cholera": }', encoding="utf-8")
    with open(broken_path, "r", encoding="utf-8") as f:
        report = json.load(f)

Python’s Traceback:

json.decoder.JSONDecodeError: Expecting value: line 1 column 27 (char 26)

Diagnosis: JSON syntax is strict: missing values, trailing commas ({"a": 1,}), or Python single quotes ({'a': 1}) make json.load() reject the file at the exact line and column of the syntax error.
Fix: Always produce JSON files with json.dump(...) rather than hand-building strings or calling str(my_dict).

ImportantBreak It On Purpose #3 — io.UnsupportedOperation Writing to a Read-Only Handle 
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    ro_path = Path(tmp) / "readonly_log.txt"
    ro_path.write_text("Existing shift entry\n", encoding="utf-8")
    with open(ro_path, "r", encoding="utf-8") as f:
        f.write("New urgent entry\n")

Python’s Traceback:

io.UnsupportedOperation: not writable

Diagnosis: The file was opened in read-only mode ("r"), so calling f.write(...) violates the handle’s permissions and raises io.UnsupportedOperation.
Fix: Open with "w" (create/overwrite) or "a" (append to end) whenever you intend to write bytes to disk.

9.4 Stage 4 — The Researcher’s Problem-Structuring Blueprint

Scenario: An Upazila Health Complex exports a messy daily antenatal CSV containing inconsistent district labels (" dhaka ", "DHAKA", "sylhet") and missing hemoglobin sentinels ("", "N/A", "999"). Build a reusable function csv_to_district_hb_json(in_csv, out_json) that reads the raw CSV, normalizes districts, computes each district’s valid mean hemoglobin rounded to 2 decimal places, writes an indented JSON summary to out_json, and returns that summary dictionary.

9.4.1 Blueprint (Completed on Paper Before Coding)

  1. Input & Output Contract:
    • Input: in_csv (Path or str) with columns id,district,hb_g_dl.
    • Output: Indented UTF-8 JSON file at out_json + returned dict[str, float].
  2. Edge Cases & Traps:
    • Every csv.DictReader value is a str—skip "", "N/A", and "999" before calling float(...).
    • Normalize row["district"].strip().title() so " dhaka " and "Dhaka" merge into one "Dhaka" key instead of splitting into duplicate entries.
    • Skip invalid rows before inserting a district key into grouped so an all-invalid district never triggers ZeroDivisionError.
  3. Step-by-Step Algorithm:
    1. Initialize grouped = {}.
    2. Stream in_csv with csv.DictReader; strip hb_g_dl and skip sentinel values.
    3. Normalize district name and append float(raw_hb) via grouped.setdefault(district, []).append(...).
    4. Compute rounded per-district means with a dict comprehension.
    5. Save with json.dump(summary, out_f, indent=2) and return summary.
  4. Verification Plan (Hand Check):
    • Dhaka valid values: 10.4, 11.6 (skipping 999) \(\rightarrow\) \((10.4 + 11.6) / 2 = 11.0\).
    • Sylhet valid values: 12.2, 11.4 (skipping N/A) \(\rightarrow\) \((12.2 + 11.4) / 2 = 11.8\).

9.4.2 Clean Python Implementation (Verbatim in 01_walkthrough.ipynb)

import csv
import json
from pathlib import Path
import tempfile

def csv_to_district_hb_json(in_csv, out_json):
    """Aggregate valid Hb by normalized district and save JSON."""
    grouped = {}
    with open(in_csv, "r", encoding="utf-8", newline="") as in_f:
        for row in csv.DictReader(in_f):
            raw_hb = row["hb_g_dl"].strip()
            if raw_hb in ("", "N/A", "999"):
                continue
            district = row["district"].strip().title()
            grouped.setdefault(district, []).append(float(raw_hb))

    summary = {
        dist: round(sum(vals) / len(vals), 2)
        for dist, vals in grouped.items()
    }
    with open(out_json, "w", encoding="utf-8") as out_f:
        json.dump(summary, out_f, indent=2)
    return summary

with tempfile.TemporaryDirectory() as tmp:
    raw_csv = Path(tmp) / "raw_hb.csv"
    out_json = Path(tmp) / "district_hb.json"
    raw_csv.write_text(
        "id,district,hb_g_dl\n"
        "M1,  dhaka ,10.4\n"
        "M2,DHAKA,999\n"
        "M3,Dhaka,11.6\n"
        "M4,sylhet,12.2\n"
        "M5,Sylhet,N/A\n"
        "M6,SYLHET,11.4\n",
        encoding="utf-8",
    )
    report = csv_to_district_hb_json(raw_csv, out_json)
    print("Returned summary:", report)
    print("Saved JSON:\n" + out_json.read_text(encoding="utf-8"))

Output:

Returned summary: {'Dhaka': 11.0, 'Sylhet': 11.8}
Saved JSON:
{
  "Dhaka": 11.0,
  "Sylhet": 11.8
}

9.8 Stage 8 — Complete Annotated Solutions & Debugging Post-Mortem

9.8.1 A. Concept & Execution Trace Test Key

  1. with open(...) guarantees the file handle is flushed and closed automatically when leaving the block, even if an exception interrupts execution before the end of the function.
  2. Mode "w" truncates and overwrites the file, leaving 2 lines. Mode "a" appends to the end, leaving 12 lines.
  3. pathlib.Path with / produces portable paths across Windows, macOS, and Linux, whereas hardcoded backslashes fail on Unix/Colab systems and risk escape-sequence bugs (\t, \n).
  4. row["hb_g_dl"] is a str ("10.8"). Comparing "10.8" < 11.0 directly raises TypeError: '<' not supported between instances of 'str' and 'float'.
  5. Raises ValueError: I/O operation on closed file, because list(reader) tried to read from f after exiting the with block closed f.
  6. The csv module handles universal newline translation and embedded newlines inside quoted fields itself; passing newline="" prevents Python from double-translating \r\n into extra blank rows on Windows.
  7. json.dump(obj, f) writes to an open file handle; json.dumps(obj) returns a JSON-formatted str in memory.
  8. str(...) outputs Python literal syntax—single quotes ('active') and capitalized True—whereas the JSON standard strictly requires double quotes ("active") and lowercase true.
  9. data.get("missing_count") or 99 treats 0 as falsy and wrongly returns 99; data.get("missing_count", 99) checks key membership and accurately returns 0.
  10. It is cleaned up automatically—TemporaryDirectory is a context manager whose __exit__ method deletes the scratch folder even when an exception occurs.

def mean_csv_column(csv_path, col_name):
    """Return mean of col_name skipping '', 'N/A', '999', or None."""
    values = []
    with open(csv_path, "r", encoding="utf-8", newline="") as f:

import csv
import json

def filter_urgent_to_csv(in_csv, out_csv):
    """Write Urgent rows to out_csv with header and return count."""
    count = 0
    with open(in_csv, "r", encoding="utf-8", newline="") as in_f, \
         open(out_csv, "w", encoding="utf-8", newline="") as out_f:
        reader = csv.DictReader(in_f)
        writer = csv.DictWriter(out_f, fieldnames=reader.fieldnames)
        writer.writeheader()
        for row in reader:
            if row["triage_priority"] == "Urgent":
                writer.writerow(row)
                count += 1
    return count

# Exam Task 9.2 (35 pts)
def summarize_mch_csv_to_json(in_csv, out_json):
    """Compute per-residence mean ANC visits, save JSON, return dict."""
    grouped = {}
    with open(in_csv, "r", encoding="utf-8", newline="") as in_f:
        for row in csv.DictReader(in_f):
            raw_anc = row["anc_visits"].strip()
            if raw_anc in ("", "999", "N/A"):
                continue
            residence = row["residence"].strip().title()
            grouped.setdefault(residence, []).append(float(raw_anc))

    summary = {
        res: round(sum(vals) / len(vals), 2)
        for res, vals in grouped.items()
    }
    with open(out_json, "w", encoding="utf-8") as out_f:
        json.dump(summary, out_f, indent=2)
    return summary

# Exam Task 9.3 (35 pts)
def merge_daily_json_reports(json_paths):
    """Load daily disease->count JSON files and return summed totals."""
    totals = {}
    for path in json_paths:
        with open(path, "r", encoding="utf-8") as f:
            report = json.load(f)
        for disease, count in report.items():
            totals[disease] = totals.get(disease, 0) + count
    return totals

9.8.4 D. Debugging Post-Mortem: Top 3 Chapter 9 Failure Modes

  1. Treating CSV Numbers as Floats Before Cleaning: Because csv.DictReader returns every cell as a string, calling float(row["anc_visits"]) immediately crashes with ValueError on "" or "N/A", or silently includes 999.0 in your published mean. Always strip, filter sentinels ("", "N/A", "999"), and then cast with float().
  2. Reading After the with Block Closes or Skipping writeheader(): Returning csv.DictReader(f) directly instead of list(csv.DictReader(f)) fails the moment the with block exits; likewise, omitting writer.writeheader() leaves your exported CSV without column headers so downstream tools misread row 1 as column names.
  3. Writing Python str(dict) Instead of json.dump(): Printing or writing str(my_dict) produces single quotes and True/False, which breaks every JSON parser with json.JSONDecodeError. Always serialize with json.dump(obj, f, indent=2) and retrieve optional keys with data.get(key, default).
