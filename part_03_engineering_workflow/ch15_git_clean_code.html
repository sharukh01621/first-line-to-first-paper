15.1 Stage 1 — First-Principles Intuition: Why analysis_FINAL_v3_fixed.py Fails Peer Review

Six months after submitting a manuscript, Reviewer #2 asks a routine question: “Table 2 reports a mean maternal hemoglobin of \(11.15\text{ g/dL}\) across \(N = 412\) mothers, yet your supplementary file has \(415\) rows—which three records were dropped, and which version of the cleaning script generated Figure 1?”

If your research folder contains clean_v1.py, clean_v2_new.py, and clean_FINAL_really.py alongside an unlogged overwrite of raw_data.csv, answering Reviewer #2 becomes a forensic nightmare. Professional scientific engineering eliminates this guesswork with four interlocking pillars:

NoteMental Model — The Audited Clinical Trial Lab Notebook

Think of a reproducible research repository like a regulated clinical trial binder:

  1. Tamper-Evident History (Git & GitHub): Every edit is recorded as an immutable, cryptographically chained commit with a concise subject line, author, and timestamp—never overwritten by v2_final filenames.
  2. Confidentiality Wall (.gitignore & Secret Scanners): Raw patient registries (*.csv) and credentials (.env, API tokens) stay strictly off GitHub while code, tests, and tiny provenance manifests are shared openly.
  3. Typed, Self-Explaining Contracts (PEP 8, Ruff & Type Hints): Consistent formatting and explicit types (list[float], Optional[float], TypedDict) turn silent runtime surprises into immediate editor warnings.
  4. Chain of Custody (logging & SHA-256 Fingerprints): Every pipeline run records its exact input file’s 64-character SHA-256 hash and logs every skipped sentinel row (INFO / WARNING) to disk.

15.3.1 Everyday Git Workflow, .gitignore Auditing & Secret Scanning

In your local terminal (outside Colab), a clean feature-branch research cycle uses just seven core commands:

git status                               # Inspect working tree & stage
git switch -c feat/add-sha256-manifest   # Isolate new work on a branch
git add src/provenance.py tests/         # Stage only reviewed code
git diff --staged                        # Audit exact lines before commit
git commit -m "Add SHA-256 manifest builder for cohort CSVs"
git log --oneline -n 5                   # Verify concise commit history
git push -u origin feat/add-sha256-manifest

Notice the commit subject rule enforced by professional teams: keep the first line imperative, concise (\(5 \le \text{len} \le 72\) characters), and free of a trailing period so git log --oneline and GitHub Pull Request headers never truncate awkwardly.

Now let’s audit .gitignore coverage with Python’s standard-library fnmatch and scan a configuration snippet for leaked credentials—run this cell verbatim in 01_walkthrough.ipynb:

import fnmatch

gitignore_text = (
    "# Never commit raw clinical data or secrets\n"
    "*.csv\n"
    ".env\n"
    "*.log\n"
    "__pycache__/*\n"
)
staged_candidates = [
    "README.md",
    "src/clean_cohort.py",
    "raw_mch_2026.csv",
    ".env",
    "run.log",
]

patterns = [
    line.strip()
    for line in gitignore_text.splitlines()
    if line.strip() and not line.strip().startswith("#")
]
tracked = sorted(
    fname for fname in staged_candidates
    if not any(fnmatch.fnmatch(fname, pat) for pat in patterns)
)
print("Active .gitignore patterns:", patterns)
print("Safe to track in Git:", tracked)

config_sample = (
    "STUDY_ID = 'MCH-BD-2026'\n"
    "TOKEN = 'ghp_exampleLeak999'\n"
    "API_KEY=demo_secret_token\n"
)
secret_tags = ("ghp_", "AIza", "sk-", "API_KEY=", "PASSWORD=")
flagged_lines = [
    idx for idx, ln in enumerate(config_sample.splitlines(), start=1)
    if any(tag in ln for tag in secret_tags)
]
print("Flagged secret lines (1-based):", flagged_lines)

Expected Output:

Active .gitignore patterns: ['*.csv', '.env', '*.log', '__pycache__/*']
Safe to track in Git: ['README.md', 'src/clean_cohort.py']
Flagged secret lines (1-based): [2, 3]

Key mechanics to inspect closely:

  • Skipping Comments & Blank Lines: Lines starting with # are documentation inside .gitignore; failing to skip them would mistakenly treat # *.py as an ignore rule.
  • Negating any(...): not any(fnmatch.fnmatch(fname, pat) ...) returns the unignored files—the exact files Git is allowed to commit.
  • 1-Based Line Numbers: enumerate(..., start=1) aligns flagged secret line numbers directly with VS Code, Vim, and GitHub diff line numbers.

15.3.2 Clean Code (PEP 8 / Ruff), Type Hints, and TypedDict Contracts

Clean research code follows PEP 8 conventions—snake_case function/variable names, PascalCase class names, UPPER_CASE constants, 4-space indentation, short readable lines, and one clear responsibility per function. Modern Python teams enforce these rules automatically in milliseconds with Ruff:

ruff check src/ tests/     # Flag unused imports, bugs & PEP 8 violations
ruff format src/ tests/    # Auto-format code to consistent style

Pairing Ruff with Python type hints (list[float], Optional[float], and TypedDict) documents the exact shape of every input and output without changing runtime speed:

from typing import Optional, TypedDict


class CohortSummary(TypedDict):
    site: str
    valid_n: int
    mean_hb: Optional[float]


def summarize_site_hb(
    site: str,
    readings: list[float],
) -> CohortSummary:
    """Return a typed hemoglobin summary for one clinic site."""
    clean = [val for val in readings if 3.0 <= val <= 22.0]
    mean_val: Optional[float] = (
        round(sum(clean) / len(clean), 2) if clean else None
    )
    return {
        "site": site.strip().title(),
        "valid_n": len(clean),
        "mean_hb": mean_val,
    }


dhaka_report = summarize_site_hb("  dhaka ", [10.4, 999.0, 11.6])
empty_report = summarize_site_hb("sylhet", [999.0])
print("Dhaka summary:", dhaka_report)
print("Empty summary:", empty_report)

Expected Output:

Dhaka summary: {'site': 'Dhaka', 'valid_n': 2, 'mean_hb': 11.0}
Empty summary: {'site': 'Sylhet', 'valid_n': 0, 'mean_hb': None}

Notice how Optional[float] explicitly warns every collaborator (and static type checkers like mypy or pyright) that mean_hb can be None when a cohort has zero valid rows—preventing downstream TypeError crashes before the pipeline ever runs.

15.3.3 Structured logging vs. print() (With Clean Handler Teardown)

print() is handy for quick interactive exploration, but it vanishes from terminal scrollback, has no severity levels (DEBUG, INFO, WARNING, ERROR, CRITICAL), and cannot be routed cleanly to an audit log file. Python’s standard-library logging module solves all three problems:

import logging
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    log_path = Path(tmp) / "cohort_run.log"
    logger = logging.getLogger("ch15_walkthrough_demo")
    logger.setLevel(logging.INFO)
    logger.propagate = False

    handler = logging.FileHandler(log_path, mode="w", encoding="utf-8")
    fmt = logging.Formatter("[%(levelname)s] %(message)s")
    handler.setFormatter(fmt)
    logger.addHandler(handler)

    try:
        logger.info("Pipeline started for Dhaka ANC cohort")
        logger.warning("Row 4: skipped sentinel hb_g_dl='999'")
        logger.info("Pipeline completed: 2 valid, 1 skipped")
    finally:
        logger.removeHandler(handler)
        handler.close()

    print(log_path.read_text(encoding="utf-8").strip())

Expected Output:

[INFO] Pipeline started for Dhaka ANC cohort
[WARNING] Row 4: skipped sentinel hb_g_dl='999'
[INFO] Pipeline completed: 2 valid, 1 skipped
WarningMandatory Logging Habit — Always Detach & Close FileHandlers!

Because logging.getLogger(name) returns the same singleton logger object across repeated function calls in a notebook or test suite, forgetting logger.removeHandler(handler) causes every future call to write duplicate lines, and forgetting handler.close() leaks open file handles that block tempfile.TemporaryDirectory() cleanup on Windows. Wrapping teardown in finally: guarantees spotless cleanup every single time.

15.3.4 Cryptographic Dataset Provenance (hashlib.sha256) & Research Templates

Because raw clinical CSV files stay out of Git (.gitignore), how do you prove six months later that data/raw/mch_v1.csv was never accidentally edited in Excel? You compute its SHA-256 cryptographic digest—a deterministic 64-character hexadecimal fingerprint where flipping even a single digit changes roughly half of the output bits (the avalanche effect):

import hashlib
from pathlib import Path
import tempfile


def sha256_file(filepath: Path) -> str:
    """Compute lowercase 64-char SHA-256 hex digest in 64 KB chunks."""
    hasher = hashlib.sha256()
    with open(filepath, "rb") as f:
        while chunk := f.read(65536):
            hasher.update(chunk)
    return hasher.hexdigest()


with tempfile.TemporaryDirectory() as tmp:
    raw_csv = Path(tmp) / "mch_v1.csv"
    raw_csv.write_text("id,hb_g_dl\nP1,10.8\n", encoding="utf-8")
    digest_v1 = sha256_file(raw_csv)

    # Flip a single digit (10.8 -> 10.9) to demonstrate avalanche effect
    raw_csv.write_text("id,hb_g_dl\nP1,10.9\n", encoding="utf-8")
    digest_v2 = sha256_file(raw_csv)

    print("Digest v1 (first 16):", digest_v1[:16], "len=", len(digest_v1))
    print("Digest v2 (first 16):", digest_v2[:16], "len=", len(digest_v2))
    print("Identical files?:", digest_v1 == digest_v2)

Expected Output:

Digest v1 (first 16): b89b84008541b87d len= 64
Digest v2 (first 16): 8137e0963620b790 len= 64
Identical files?: False

15.3.5 Break It On Purpose! (Provenance & Logging Error Anatomy)

ImportantBreak It On Purpose #1 — FileNotFoundError Hashing a Missing Dataset 
import hashlib
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    missing_csv = Path(tmp) / "missing_cohort.csv"
    with open(missing_csv, "rb") as f:
        digest = hashlib.sha256(f.read()).hexdigest()

Python’s Traceback:

FileNotFoundError: [Errno 2] No such file or directory:
'.../missing_cohort.csv'

Diagnosis: Calling open(path, "rb") or path.read_bytes() assumes the dataset exists on disk. In a provenance verifier, a deleted file should be reported cleanly as "missing" rather than crashing the audit script.
Fix: Guard with if not fpath.is_file(): before attempting to read bytes or compute a digest.

ImportantBreak It On Purpose #2 — TypeError Passing str Instead of bytes to hashlib.sha256 
import hashlib

csv_text = "patient_id,hb_g_dl\nP01,11.2\n"
digest = hashlib.sha256(csv_text).hexdigest()

Python’s Traceback:

TypeError: Strings must be encoded before hashing

Diagnosis: Cryptographic hashes operate on raw bytes, never Unicode str objects (because the same characters can be encoded differently in UTF-8 vs. UTF-16). Passing a text string—or opening a file in text mode "r" instead of "rb"—immediately triggers TypeError.
Fix: Open files in binary mode ("rb") or call csv_text.encode("utf-8") before passing data into hashlib.sha256(...).

ImportantBreak It On Purpose #3 — ValueError on Invalid Logging Level String 
import logging

bad_logger = logging.getLogger("ch15_bad_level_demo")
bad_logger.setLevel("URGENT")

Python’s Traceback:

ValueError: Unknown level: 'URGENT'

Diagnosis: Python’s logging module recognizes only the standard severity names ("DEBUG", "INFO", "WARNING", "ERROR", "CRITICAL") or their integer constants. Passing a custom string like "URGENT" or a lowercase string like "info" directly to setLevel(...) raises ValueError.
Fix: Normalize input with .strip().upper() and validate it against the five standard level names before logging.

15.4 Stage 4 — The Researcher’s Problem-Structuring Blueprint

Scenario: Before tagging v1.0.0 on GitHub for manuscript submission, your PI wants a single automated gatekeeper function prepare_release_bundle(repo_dir, log_path) that: (1) hashes every .csv and .json file inside repo_dir / "data" into repo_dir / "manifest.json", (2) scans all .py scripts inside repo_dir / "src" for leaked secret prefixes, (3) writes an INFO/WARNING audit log to log_path with clean handler teardown, and (4) returns a typed ReleaseAudit dictionary indicating whether the bundle is release_ready.

15.4.1 Blueprint (Completed on Paper Before Coding)

  1. Input & Output Contract:
    • Inputs: repo_dir: Path (containing data/ and src/) and log_path: Path.
    • Side effects: Indented manifest.json written inside repo_dir; audit log written cleanly to log_path.
    • Return value: ReleaseAudit (TypedDict) with data_files, manifest_path, secret_leaks, and release_ready.
  2. Edge Cases & Traps:
    • Never leave the FileHandler attached or open—place logger.removeHandler(handler) and handler.close() inside finally:.
    • Sort data/ entries by filename so manifest.json diffs stay deterministic in Git.
    • Check p.is_file() before reading bytes so subdirectories never raise IsADirectoryError.
  3. Step-by-Step Algorithm:
    1. Configure an isolated logger (propagate = False) with a UTF-8 FileHandler.
    2. Inside try:, hash all regular .csv/.json files in repo_dir / "data" into manifest.
    3. Scan every *.py file in repo_dir / "src" line by line (1-based) for the five secret tokens; log a WARNING for every leak.
    4. Write manifest.json with indent=2, compute ready = len(manifest) > 0 and leaks == 0, and log final status.
    5. Detach and close the handler in finally:, then return the typed ReleaseAudit dict.
  4. Verification Plan (Hand Check):
    • 1 CSV file in data/ + 1 clean Python script in src/ \(\rightarrow\) data_files = 1, secret_leaks = 0, release_ready = True, and 2 INFO log lines.

15.4.2 Clean Python Implementation (Verbatim in 01_walkthrough.ipynb)

import hashlib
import json
import logging
from pathlib import Path
import tempfile
from typing import TypedDict


class ReleaseAudit(TypedDict):
    data_files: int
    manifest_path: str
    secret_leaks: int
    release_ready: bool


def prepare_release_bundle(
    repo_dir: Path,
    log_path: Path,
) -> ReleaseAudit:
    """Build a SHA-256 manifest, scan src/ for secrets, and log audit."""
    logger = logging.getLogger("ch15_release_gate")
    logger.setLevel(logging.INFO)
    logger.propagate = False
    handler = logging.FileHandler(log_path, mode="w", encoding="utf-8")
    handler.setFormatter(logging.Formatter("[%(levelname)s] %(message)s"))
    logger.addHandler(handler)

    secret_tags = ("ghp_", "AIza", "sk-", "API_KEY=", "PASSWORD=")
    manifest: dict[str, dict[str, object]] = {}
    leaks = 0

    try:
        data_dir = repo_dir / "data"
        for p in sorted(data_dir.iterdir(), key=lambda x: x.name):
            if p.is_file() and p.suffix.lower() in {".csv", ".json"}:
                digest = hashlib.sha256(p.read_bytes()).hexdigest()
                manifest[p.name] = {
                    "bytes": p.stat().st_size,
                    "sha256": digest,
                }
        logger.info("Hashed %d dataset file(s)", len(manifest))

        src_dir = repo_dir / "src"
        for py_file in sorted(src_dir.glob("*.py")):
            text = py_file.read_text(encoding="utf-8")
            for ln_no, line in enumerate(text.splitlines(), start=1):
                if any(tag in line for tag in secret_tags):
                    leaks += 1
                    logger.warning(
                        "Leak in %s line %d", py_file.name, ln_no
                    )

        manifest_file = repo_dir / "manifest.json"
        with open(manifest_file, "w", encoding="utf-8") as out_f:
            json.dump(manifest, out_f, indent=2)

        ready = len(manifest) > 0 and leaks == 0
        logger.info("Release ready: %s", ready)
    finally:
        logger.removeHandler(handler)
        handler.close()

    return {
        "data_files": len(manifest),
        "manifest_path": manifest_file.name,
        "secret_leaks": leaks,
        "release_ready": ready,
    }


with tempfile.TemporaryDirectory() as tmp:
    repo = Path(tmp)
    (repo / "data").mkdir()
    (repo / "src").mkdir()
    (repo / "data" / "mch_clean.csv").write_text(
        "id,hb_g_dl\nP1,11.4\n", encoding="utf-8"
    )
    (repo / "src" / "analyze.py").write_text(
        "STUDY = 'MCH-BD-2026'\n", encoding="utf-8"
    )
    audit_log = repo / "release_audit.log"
    result = prepare_release_bundle(repo, audit_log)
    print("Audit Result:\n" + json.dumps(result, indent=2))
    print("Audit Log:\n" + audit_log.read_text(encoding="utf-8").strip())

Output:

Audit Result:
{
  "data_files": 1,
  "manifest_path": "manifest.json",
  "secret_leaks": 0,
  "release_ready": true
}
Audit Log:
[INFO] Hashed 1 dataset file(s)
[INFO] Release ready: True

import fnmatch
import hashlib
import logging
from pathlib import Path

# To-Do 15.1
def check_gitignore_coverage(gitignore_text, filenames):
    """Return sorted list of filenames NOT matched by .gitignore."""
    patterns = [
        line.strip()
        for line in gitignore_text.splitlines()
        if line.strip() and not line.strip().startswith("#")
    ]
    unignored = [
        fname for fname in filenames
        if not any(fnmatch.fnmatch(fname, pat) for pat in patterns)
    ]
    return sorted(unignored)

# To-Do 15.2
def validate_commit_message(message):
    """Validate first commit subject line; return (is_valid, reason)."""
    lines = message.splitlines()
    subject = lines[0].strip() if lines else ""
    if not subject:
        return (False, "Subject line cannot be empty")
    if len(subject) < 5:
        return (False, "Subject line must be at least 5 characters")
    if len(subject) > 72:
        return (False, "Subject line must be at most 72 characters")
    if subject.endswith("."):
        return (False, "Subject line should not end with a period")
    return (True, "Valid commit subject")

# To-Do 15.3
def scan_for_leaked_secrets(text):
    """Return 1-based line numbers containing sensitive secret tokens."""
    patterns = ("ghp_", "AIza", "sk-", "API_KEY=", "PASSWORD=")
    return [
        line_no
        for line_no, line in enumerate(text.splitlines(), start=1)
        if any(pat in line for pat in patterns)
    ]

# To-Do 15.4
_LOG_LEVELS = {
    "DEBUG": logging.DEBUG,
    "INFO": logging.INFO,
    "WARNING": logging.WARNING,
    "ERROR": logging.ERROR,
    "CRITICAL": logging.CRITICAL,
}

def write_structured_log(log_path, level, message):
    """Append '[LEVEL] message' to log_path via a closed FileHandler."""
    level_name = level.strip().upper()
    if level_name not in _LOG_LEVELS:
        raise ValueError(f"Unknown log level: {level!r}")
    logger = logging.getLogger("ch15_todo_logger")
    logger.setLevel(logging.DEBUG)
    logger.propagate = False
    handler = logging.FileHandler(log_path, mode="a", encoding="utf-8")
    handler.setFormatter(logging.Formatter("[%(levelname)s] %(message)s"))
    logger.addHandler(handler)
    try:
        logger.log(_LOG_LEVELS[level_name], message)
    finally:
        logger.removeHandler(handler)
        handler.close()

# To-Do 15.5
def compute_file_sha256(filepath):
    """Return lowercase 64-char SHA-256 hex digest of filepath."""
    hasher = hashlib.sha256()
    with open(filepath, "rb") as f:
        while chunk := f.read(65536):
            hasher.update(chunk)
    return hasher.hexdigest()

# To-Do 15.6
def build_dataset_manifest(data_dir):
    """Map sorted .csv/.json filenames to byte size and SHA-256."""
    manifest = {}
    for p in sorted(Path(data_dir).iterdir(), key=lambda x: x.name):
        if p.is_file() and p.suffix.lower() in {".csv", ".json"}:
            digest = hashlib.sha256(p.read_bytes()).hexdigest()
            manifest[p.name] = {
                "bytes": p.stat().st_size,
                "sha256": digest,
            }
    return manifest

def verify_data_provenance(data_dir, manifest_dict):
    """Verify data_dir files against manifest_dict SHA-256 digests."""
    root = Path(data_dir)
    matched = []
    modified = []
    missing = []
    for fname in sorted(manifest_dict):
        fpath = root / fname
        if not fpath.is_file():
            missing.append(fname)
            continue
        actual_sha = hashlib.sha256(fpath.read_bytes()).hexdigest()
        if actual_sha == manifest_dict[fname]["sha256"]:
            matched.append(fname)
        else:
            modified.append(fname)
    return {
        "matched": matched,
        "modified": modified,
        "missing": missing,
        "all_verified": len(modified) == 0 and len(missing) == 0,
    }

# Exam Task 15.3 (35 pts)
def run_logged_cleaning_pipeline(in_csv, out_json, log_path):
    """Hash, clean, log, and summarize hb_g_dl CSV to indented JSON."""
    src_sha = hashlib.sha256(Path(in_csv).read_bytes()).hexdigest()
    logger = logging.getLogger("ch15_capstone_pipeline")
    logger.setLevel(logging.INFO)
    logger.propagate = False
    handler = logging.FileHandler(log_path, mode="w", encoding="utf-8")
    handler.setFormatter(logging.Formatter("[%(levelname)s] %(message)s"))
    logger.addHandler(handler)

    valid_vals = []
    rejected = 0
    try:
        logger.info("Pipeline started (sha256=%s)", src_sha)
        with open(in_csv, "r", encoding="utf-8", newline="") as in_f:
            for row_num, row in enumerate(csv.DictReader(in_f), start=1):
                raw = row["hb_g_dl"].strip()
                if raw in ("", "N/A", "999"):
                    rejected += 1
                    logger.warning("Row %d rejected: %r", row_num, raw)
                else:
                    valid_vals.append(float(raw))

        mean_hb = (
            round(sum(valid_vals) / len(valid_vals), 2)
            if valid_vals
            else None
        )
        summary = {
            "source_sha256": src_sha,
            "valid_count": len(valid_vals),
            "rejected_count": rejected,
            "mean_hb": mean_hb,
        }
        logger.info(
            "Pipeline finished: valid=%d, rejected=%d",
            len(valid_vals),
            rejected,
        )
    finally:
        logger.removeHandler(handler)
        handler.close()

    with open(out_json, "w", encoding="utf-8") as out_f:
        json.dump(summary, out_f, indent=2)
    return summary

15.8.4 D. Debugging Post-Mortem: Top 3 Chapter 15 Failure Modes

  1. Leaking logging.FileHandler Across Calls: Adding a FileHandler to a named logger without logger.removeHandler(handler) and handler.close() inside a finally: block silently duplicates every subsequent log message and can lock tempfile.TemporaryDirectory() folders on cleanup.
  2. Hashing Text Mode Instead of Binary Mode ("r" vs. "rb"): Passing decoded strings into hashlib.sha256() triggers TypeError: Strings must be encoded before hashing (or UnicodeDecodeError on binary assets). Always read raw bytes via open(path, "rb") or Path(path).read_bytes().
  3. Forgetting Existence & Negation Guards: Returning matched files instead of unignored files in .gitignore audits, or hashing a missing manifest entry without checking fpath.is_file() first, flips security checks upside down or crashes mid-audit with FileNotFoundError.
