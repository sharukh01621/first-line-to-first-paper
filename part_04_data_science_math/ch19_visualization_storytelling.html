Learning Objectives

By the end of this chapter, you will be able to:

  1. Build every chart with Matplotlib’s Object-Oriented API (fig, ax = plt.subplots(...)), returning (fig, ax) or (fig, axes) from reusable functions and closing figures cleanly with plt.close(fig) to prevent RAM leaks.

19.1 Stage 1 — First-Principles Intuition: Exploratory Sketches vs. Publication Figures

In Chapters 16–18, you learned to vectorize math with NumPy, aggregate tables with Pandas, and scrub messy clinical surveys. Yet a journal reviewer rarely inspects your raw .csv file—the very first thing a reviewer, policymaker, or thesis examiner reads is Figure 1.

There is a massive gap between an exploratory sketch (calling plt.hist(x) with default blue bars, missing units, and overlapping labels) and a publication-ready figure:

  • Every axis carries units: Writing "Hemoglobin (g/dL)" and "Systolic BP (mmHg)" eliminates ambiguity across international clinical readers.
  • Perceptual honesty comes first: Human eyes judge aligned position and length far more accurately than pie-chart angles or dual y-axis slopes. Sorting bar charts by magnitude and stacking related time series with sharex=True makes patterns effortless to verify.
  • Colorblind accessibility is mandatory: Roughly \(8\%\) of men and \(0.5\%\) of women experience red-green color-vision deficiency. Replacing default red/green contrasts with the Okabe-Ito palette (#0072B2 blue, #E69F00 orange, #D55E00 vermilion, #009E73 bluish green, #56B4E9 sky blue) keeps figures legible in both color and grayscale print.
  • Reproducible figure functions beat throwaway cells: Wrapping each chart in a function that returns (fig, ax) lets you unit-test titles, thresholds, and artist counts—and regenerate every manuscript figure automatically when new survey waves arrive.
NoteMental Model — Canvas Frame (Figure), Drawing Panels (Axes) & Ink (Artists)

Think of Matplotlib as a medical journal page layout:

  • Figure (fig): The entire blank journal page (e.g., 10.5 x 4.2 inches). It owns overall margins, fig.suptitle(...), and the export printer (fig.savefig(...)).
  • Axes (ax or axes[i]): An individual framed chart panel sitting on the page. Every axis label (ax.set_xlabel), panel title (ax.set_title), tick mark, spine, and legend lives on an Axes.
  • Artists (patches, lines, collections, texts): The actual ink drawn inside an Axes—histogram bars (Rectangle patches), trend lines (Line2D), scatter points (PathCollection), and heatmap annotations (Text).

19.1.1 Why the Object-Oriented API (fig, ax) Beats plt.plot(...)

Beginners often copy tutorials using plt.plot(...), plt.title(...), and plt.xlabel(...). That state-machine interface secretly mutates whichever panel Matplotlib thinks is “currently active”—a recipe for chaos the moment you build a 1x2 or 2x1 multi-panel paper figure. By explicitly creating fig, ax = plt.subplots(...) and calling methods on ax, every line of code names the exact panel it modifies.

19.2 Stage 2 — Visual Mental Model: Matplotlib Object-Oriented Hierarchy

Trace how every Matplotlib and Seaborn visualization flows from a single Figure container down to Axes panels, visual Artists, and camera-ready file export:

Notice that Seaborn sits directly on top of this hierarchy: passing ax=ax into sns.heatmap(..., ax=ax) or sns.scatterplot(..., ax=ax) draws Seaborn’s statistical artists right into your chosen Matplotlib Axes, so you retain 100% control over titles, subplots, and 300-DPI exports.

WarningThe Silent Figure Memory Leak in Batch Scripts

Every call to plt.subplots() registers a live Figure inside Matplotlib’s global manager. If a loop generates 50 district reports without calling plt.close(fig) after fig.savefig(...), all 50 figures stay pinned in RAM—triggering RuntimeWarning: More than 20 figures have been opened and eventually crashing Colab. Always pair every batch figure creation or automated test with plt.close(fig)!

Watch how fig, ax = plt.subplots(...) layers histogram bars, a WHO \(11.0\text{ g/dL}\) dashed anemia cutoff, a callout arrow, and clean despined axes:

OKABE_ITO = {

fig, ax = plt.subplots(figsize=(6.5, 4.0))

Expected Output:

Patches: 16 | Lines: 1
Title:   Clinic Triage Hemoglobin Distribution

Three publication habits are working together here:

  • Programmatic inspectability: ax.patches holds the 16 histogram bars and ax.lines holds the dashed cutoff line—the exact artists our automated checks verify!
  • Despining reduces chartjunk: Hiding the top and right box borders (ax.spines["top"].set_visible(False)) increases the data-ink ratio cleanly.
  • Explicit cleanup: Calling plt.close(fig) releases memory immediately once the figure is inspected or saved.

19.3.3 Okabe-Ito Palette: Sorted Horizontal Bars & Grouped Scatter

Always sort categorical bars by magnitude rather than alphabetically, and encode clinical triage severity with distinct Okabe-Ito hues:

district_summary = (
    clinic.assign(is_anemic=clinic["hemoglobin_g_dl"] < 11.0)
    .groupby("district", as_index=False)["is_anemic"]
    .mean()
    .rename(columns={"is_anemic": "anemia_pct"})
)
district_summary["anemia_pct"] *= 100
ordered = district_summary.sort_values("anemia_pct", ascending=True)

fig, ax = plt.subplots(figsize=(6.5, 3.8))
ax.barh(ordered["district"], ordered["anemia_pct"], color="#009E73")
ax.set_title("Anemia Prevalence by District (Sorted)")
ax.set_xlabel("Anemia Prevalence (%)")
ax.set_ylabel("District")
top_row = ordered.iloc[-1]
print(f"Top district: {top_row['district']} ({top_row['anemia_pct']:.1f}%)")
plt.close(fig)

fig, ax = plt.subplots(figsize=(6.5, 4.0))
priority_colors = {"Routine": "#0072B2", "Moderate": "#D55E00"}
for priority, sub in clinic.groupby("triage_priority"):
    ax.scatter(
        sub["bmi"],
        sub["systolic_bp"],
        color=priority_colors.get(priority, "#E69F00"),
        alpha=0.8,
        label=priority,
    )
ax.set_title("BMI vs. Systolic BP by Triage Priority")
ax.set_xlabel("BMI (kg/m^2)")
ax.set_ylabel("Systolic Blood Pressure (mmHg)")
ax.legend(title="Triage Priority")
print("Scatter groups plotted:", len(ax.collections))
plt.close(fig)

Expected Output:

Top district: Rangpur (13.8%)
Scatter groups plotted: 2

Notice why we sorted ascending=True before calling ax.barh(...): Matplotlib draws horizontal bars from \(y = 0\) (bottom) up to \(y = N - 1\) (top), so sorting ascending places Rangpur (13.8%) squarely at the top!

19.3.5 Multi-Panel Subplots (1x2 MCH Wealth Equity)

When comparing two public health indicators across the same socioeconomic gradient, side-by-side panels (plt.subplots(1, 2, ...)) with an explicit quintile_order reindex let readers scan disparities instantaneously:

quintile_order = ["Poorest", "Poorer", "Middle", "Richer", "Richest"]

fig, axes = plt.subplots(1, 2, figsize=(10.5, 4.0))

fig.suptitle("MCH Health Inequities Across Wealth Quintiles")

print("Poorest vs Richest stunting (%):")

19.3.6 Seaborn Correlation Heatmap & 300-DPI Dual Export

For correlation matrices spanning \([-1, +1]\), always pair a diverging colormap ("coolwarm" or "RdBu_r") with center=0 and annot=True, then export both raster (300-DPI PNG) and vector (PDF) formats inside a temporary directory during testing:

num_cols = ["age_years", "bmi", "systolic_bp", "hemoglobin_g_dl"]
corr_mat = clinic[num_cols].corr()

fig, ax = plt.subplots(figsize=(5.8, 4.6))
sns.heatmap(
    corr_mat, annot=True, fmt=".2f", center=0, cmap="coolwarm", ax=ax
)
ax.set_title("Clinic Triage Feature Correlation Matrix")

with tempfile.TemporaryDirectory() as tmpdir:
    png_path = Path(tmpdir) / "corr_heatmap.png"
    pdf_path = Path(tmpdir) / "corr_heatmap.pdf"
    fig.savefig(png_path, dpi=300, bbox_inches="tight")
    fig.savefig(pdf_path, dpi=300, bbox_inches="tight")
    print("300-DPI PNG bytes:", png_path.stat().st_size)
    print("Vector PDF bytes: ", pdf_path.stat().st_size)

plt.close(fig)

19.3.7 Break It On Purpose! (Visualization Error Anatomy)

ImportantBreak It On Purpose #1 — ValueError (Mismatched x and y Lengths) 
fig, ax = plt.subplots()
try:
    weeks = [1, 2, 3, 4]
    cases = [18, 29, 44]
    ax.plot(weeks, cases)
finally:
    plt.close(fig)

Python’s Traceback:

ValueError: x and y must have same first dimension,
but have shapes (4,) and (3,)

Diagnosis: weeks has 4 entries while cases has only 3 (often caused by dropping NaNs from y without aligning x, or slicing one series differently).
Fix: Filter and align a single DataFrame first (sub = df.dropna(subset=["epi_week", "dengue_cases"])), then plot sub["epi_week"] against sub["dengue_cases"].

ImportantBreak It On Purpose #2 — KeyError (Missing Column in DataFrame) 
fig, ax = plt.subplots()
try:
    ax.hist(clinic["hb_g_dl"])
finally:
    plt.close(fig)

Python’s Traceback:

KeyError: 'hb_g_dl'

Diagnosis: The clinic_triage table names the column "hemoglobin_g_dl", not "hb_g_dl".
Fix: Print list(clinic.columns) before writing plotting code so column names match the DataFrame schema exactly.

ImportantBreak It On Purpose #3 — ValueError (Invalid Colormap Name) 
fig, ax = plt.subplots()
try:
    sns.heatmap(
        corr_mat, cmap=plt.get_cmap("hospital_rainbow"), ax=ax
    )
finally:
    plt.close(fig)

Python’s Traceback:

ValueError: 'hospital_rainbow' is not a valid value for name.
Did you mean one of: 'gist_rainbow', 'gist_rainbow_r', 'rainbow'?

Diagnosis: "hospital_rainbow" is not a registered Matplotlib colormap (and rainbow colormaps distort perception anyway!).
Fix: Use perceptually uniform sequential palettes ("viridis", "cividis", "crest") for ordered quantities, and zero-centered diverging palettes ("coolwarm", "RdBu_r", "vlag") for signed correlations.

19.4 Stage 4 — The Researcher’s Problem-Structuring Blueprint

Scenario: An epidemiological surveillance team publishes a weekly dengue bulletin comparing dengue incidence against monsoon rainfall for any target district. They need a single reusable function that (1) builds a 2x1 shared-x figure (avoiding deceptive dual y-axes), (2) exports both a 300-DPI PNG and a vector PDF into any output folder, (3) closes the figure to guarantee zero memory leaks, and (4) returns the exported byte counts for automated CI verification.

19.4.1 Blueprint (Completed on Paper Before Coding)

  1. Inputs & Units:

    • epi_df: Pandas DataFrame (year, epi_week, district, dengue_cases [count], rainfall_mm [mm]).
    • district (str), out_dir (str | Path), dpi (int, default 300).

  2. Edge Cases & Traps:

    • Multi-year data: epi_surveillance spans 2024 and 2025 (52 weeks each), so plotting raw epi_week alone would fold 2025 back on top of 2024! Sort by ["year", "epi_week"] and plot along sequential week index range(1, len(sub) + 1).
    • Uncreated output folders: call Path(out_dir).mkdir(parents=True, exist_ok=True).
    • Memory leaks & stray test files: call plt.close(fig) immediately after saving, and run demos inside tempfile.TemporaryDirectory().

  3. Step-by-Step Algorithm:

    • Filter epi_df to district, sort by ["year", "epi_week"], compute 4-week rolling mean.
    • Create fig, axes = plt.subplots(2, 1, sharex=True, figsize=(8.0, 5.2)).
    • Plot weekly cases + 4-week trend with legend on axes[0]; plot rainfall_mm bars on axes[1]; apply fig.tight_layout().
    • Export <district>_outbreak.png and <district>_outbreak.pdf at dpi with bbox_inches="tight", close fig, and return byte sizes.

  4. Verification Plan:

    • Confirm png_bytes > 0, pdf_bytes > 0, len(plt.get_fignums()) == 0, and zero files left behind after the TemporaryDirectory block exits.

19.4.2 Clean Python Implementation (Verbatim in 01_walkthrough.ipynb)

def generate_outbreak_report(epi_df, district, out_dir, dpi=300):
    """Build a 2x1 outbreak figure, export PNG+PDF, and close safely."""
    sub = (
        epi_df[epi_df["district"] == district]
        .sort_values(["year", "epi_week"])
        .reset_index(drop=True)
    )
    x = range(1, len(sub) + 1)
    roll = sub["dengue_cases"].rolling(4, min_periods=1).mean()

    fig, axes = plt.subplots(2, 1, sharex=True, figsize=(8.0, 5.2))
    axes[0].plot(x, sub["dengue_cases"], color="#56B4E9", alpha=0.6,
                 label="Weekly Cases")
    axes[0].plot(x, roll, color="#D55E00", linewidth=2.2,
                 label="4-Week Rolling Mean")
    axes[0].set_title(f"Dengue Surveillance & Rainfall — {district}")
    axes[0].set_ylabel("Dengue Cases")
    axes[0].legend(frameon=False)

    axes[1].bar(x, sub["rainfall_mm"], color="#0072B2", alpha=0.8)
    axes[1].set_title(f"Weekly Rainfall — {district}")
    axes[1].set_xlabel("Sequential Epidemiological Week")
    axes[1].set_ylabel("Rainfall (mm)")
    fig.tight_layout()

    out = Path(out_dir)
    out.mkdir(parents=True, exist_ok=True)
    png_p = out / f"{district.lower()}_outbreak.png"
    pdf_p = out / f"{district.lower()}_outbreak.pdf"
    fig.savefig(png_p, dpi=dpi, bbox_inches="tight")
    fig.savefig(pdf_p, dpi=dpi, bbox_inches="tight")
    plt.close(fig)
    return {
        "png_bytes": int(png_p.stat().st_size),
        "pdf_bytes": int(pdf_p.stat().st_size),
    }

with tempfile.TemporaryDirectory() as tmpdir:
    report = generate_outbreak_report(epi, "Dhaka", tmpdir, dpi=300)
    print("Exported Dhaka report bundle:", report)

plt.close("all")

19.8.1 A. Concept & Execution Trace Test Key

  1. fig (the Figure) owns fig.suptitle(...) and fig.savefig(...); axes[0] and axes[1] (the Axes panels) own set_xlabel(...) and legend().
  2. Rajshahi (22.0%) appears at the top! Matplotlib plots horizontal bars bottom-to-top (\(y = 0, 1, 2\)), so sorting descending puts the largest bar (41.2%) at \(y = 0\) (the bottom). Always sort ascending=True for ax.barh(...).
  3. Roughly \(8\%\) of men have red-green color-vision deficiency, making pure red and green indistinguishable (and they collapse into identical gray in monochrome print). Use the Okabe-Ito colorblind-safe palette (#0072B2, #D55E00, #009E73, #E69F00).
  4. Dual y-axes (twinx()) let arbitrary axis limits manufacture fake intersections or exaggerate slopes, whereas a 2x1 sharex=True layout preserves honest independent scales while keeping epidemiological weeks aligned vertically.
  5. Without center=0, Seaborn stretches the full blue-to-red "coolwarm" range across \([+0.25, +1.00]\), painting the positive correlation \(+0.25\) deep blue (making it look strongly negative!). Passing center=0 locks \(0.0\) to neutral white.
  6. A jagged “sawtooth” line jumps backwards from week 52 of 2024 to week 1 of 2025, overplotting both years on top of each other.
  7. At \(600\%\) zoom, a 72-DPI raster PNG becomes visibly pixelated/blurry, whereas a vector PDF stores mathematical paths and text glyphs that remain razor-sharp at any magnification.
  8. bbox_inches="tight" inside fig.savefig(...).
  9. plt.close(fig) (or plt.close("all") at script teardown).
    1. ValueError: x and y must have same first dimension, but have shapes (4,) and (3,); (b) KeyError: 'hb_g_dl'.

from pathlib import Path
import matplotlib.pyplot as plt
import seaborn as sns

# To-Do 19.1
def plot_hb_distribution(df, cutoff=11.0):
    """Plot hemoglobin histogram with a dashed WHO clinical cutoff."""
    fig, ax = plt.subplots(figsize=(6.5, 4.0))
    hb = df["hemoglobin_g_dl"].dropna()
    ax.hist(hb, bins=15, color="#0072B2", edgecolor="white")
    ax.axvline(
        cutoff,
        color="#D55E00",
        linestyle="--",
        linewidth=2.0,
        label=f"Cutoff ({cutoff} g/dL)",
    )
    ax.set_title("Patient Hemoglobin Distribution")
    ax.set_xlabel("Hemoglobin (g/dL)")
    ax.set_ylabel("Patient Count")
    ax.legend(frameon=False)
    return fig, ax

# To-Do 19.2
def plot_district_anemia_bar(summary_df):
    """Plot sorted horizontal bar chart of district anemia prevalence."""
    ordered = summary_df.sort_values("anemia_pct", ascending=True)
    fig, ax = plt.subplots(figsize=(6.5, 4.0))
    ax.barh(ordered["district"], ordered["anemia_pct"], color="#009E73")
    ax.set_title("Anemia Prevalence by District")
    ax.set_xlabel("Anemia Prevalence (%)")
    ax.set_ylabel("District")
    return fig, ax

# To-Do 19.3
def plot_bmi_vs_sbp_scatter(df):
    """Plot BMI vs. systolic BP colored by triage_priority with legend."""
    palette = ["#0072B2", "#E69F00", "#D55E00", "#009E73"]
    fig, ax = plt.subplots(figsize=(6.5, 4.2))
    for idx, (priority, sub) in enumerate(df.groupby("triage_priority")):
        ax.scatter(
            sub["bmi"],
            sub["systolic_bp"],
            color=palette[idx % len(palette)],
            alpha=0.8,
            label=priority,
        )
    ax.set_title("BMI vs. Systolic BP by Triage Priority")
    ax.set_xlabel("BMI (kg/m^2)")
    ax.set_ylabel("Systolic BP (mmHg)")
    ax.legend(title="Triage Priority")
    return fig, ax

def plot_dengue_seasonality(epi_df, district):
    """Plot weekly dengue cases and 4-week rolling mean for a district."""
    sub = (
        epi_df[epi_df["district"] == district]
        .sort_values(["year", "epi_week"])
        .reset_index(drop=True)

        label="4-Week Rolling Mean",
    )
    ax.set_title(f"Weekly Dengue Seasonality — {district}")
    ax.set_xlabel("Sequential Epi Week")
    ax.set_ylabel("Dengue Cases")
    ax.legend(frameon=False)
    return fig, ax

def plot_correlation_heatmap(df, cols):
    """Plot a zero-centered annotated Seaborn correlation heatmap."""
    corr = df[cols].corr()
    fig, ax = plt.subplots(figsize=(5.8, 4.8))
    sns.heatmap(
        corr, annot=True, fmt=".2f", center=0, cmap="coolwarm", ax=ax
    )
    ax.set_title("Feature Correlation Heatmap")
    return fig, ax

def save_publication_figure(fig, out_path, dpi=300):
    """Save a Matplotlib figure tightly at target DPI and return bytes."""
    path = Path(out_path)
    path.parent.mkdir(parents=True, exist_ok=True)
    fig.savefig(path, dpi=dpi, bbox_inches="tight")
    return int(path.stat().st_size)

def build_mch_equity_panel(mch_df):
    """Build a 1x2 MCH stunting & anemia equity figure by wealth."""
    order = ["Poorest", "Poorer", "Middle", "Richer", "Richest"]
    cols = ["child_stunted", "maternal_anemia"]
    summary = (
        mch_df.groupby("wealth_quintile")[cols]
        .mean()
        .reindex(order)
        * 100
    )
    fig, axes = plt.subplots(1, 2, figsize=(10.5, 4.2))
    axes[0].bar(summary.index, summary["child_stunted"], color="#0072B2")
    axes[0].set_title("Child Stunting by Wealth Quintile")
    axes[0].set_xlabel("Wealth Quintile")
    axes[0].set_ylabel("Stunting Prevalence (%)")

    axes[1].bar(summary.index, summary["maternal_anemia"], color="#D55E00")
    axes[1].set_title("Maternal Anemia by Wealth Quintile")
    axes[1].set_xlabel("Wealth Quintile")
    axes[1].set_ylabel("Anemia Prevalence (%)")

    fig.suptitle("Maternal & Child Health Equity Across Wealth Quintiles")
    fig.tight_layout()
    return fig, axes

def export_figure_bundle(fig, out_dir, stem, dpi=300):
    """Export tight PNG + PDF figure bundle and return path/byte map."""
    out = Path(out_dir)
    out.mkdir(parents=True, exist_ok=True)
    png_path = out / f"{stem}.png"
    pdf_path = out / f"{stem}.pdf"
    fig.savefig(png_path, dpi=dpi, bbox_inches="tight")
    fig.savefig(pdf_path, dpi=dpi, bbox_inches="tight")
    return {
        "png": png_path,
        "pdf": pdf_path,
        "png_bytes": int(png_path.stat().st_size),
        "pdf_bytes": int(pdf_path.stat().st_size),
    }

19.8.4 D. Debugging Post-Mortem: Top 3 Chapter 19 Failure Modes

  1. Forgetting return fig, ax (Calling plt.show() Instead): Plotting functions that only display to screen return None, breaking automated grading, multi-figure pipelines, and reproducible export scripts. Always return (fig, ax) or (fig, axes) and let the caller decide whether to display, inspect, save, or close the figure.
  2. Plotting Proportions (0.28) Instead of Percentages (28.0%) or Alphabetical Quintiles: groupby("wealth_quintile").mean() sorts "Middle" before "Poorest" and returns 0..1 fractions. Reindexing explicitly (["Poorest", ..., "Richest"]) and multiplying by 100 ensures the chart matches its % axis label and domain order.
  3. Leaving Unclosed Figures or Stray Export Artifacts Behind: Forgetting plt.close(fig) inside loops leaks memory across dozens of charts, while writing test PNGs straight into your Git workspace pollutes commits. Always export demos inside tempfile.TemporaryDirectory() and close every figure explicitly.
