17.1 Stage 1 — First-Principles Intuition: Why Tabular Research Needs Pandas

In Chapter 16, you saw how NumPy accelerates homogeneous numerical arrays—a matrix where every entry shares the exact same float64 type. Real clinical cohorts, economic surveys, and genomics metadata are almost never homogeneous: a single patient row mixes a string ID ("UHC-0001"), a categorical district ("Sylhet"), an integer age (55), and floating-point vitals (37.5 °C, 12.2 g/dL).

Pandas sits directly on top of NumPy to give each column its own typed NumPy/Arrow vector while binding every row and column to explicit, alignment-aware labels:

  • Series (1D Labeled Vector): One typed column paired with a row Index (for example, df["temp_c"] holds 120 float64 body temperatures).
  • DataFrame (2D Labeled Table): An ordered dictionary of Series sharing one common row Index—each column can hold a different dtype (str, int64, float64, bool).
  • Vectorized Column Operations: Writing df["weight_kg"] / (df["height_cm"] / 100) ** 2 computes BMI across 120—or 12 million—rows in compiled C loops without a single Python for loop.
NoteMental Model — Indexed Laboratory Ledger vs. Loose Lists

Think of a DataFrame as a bound hospital ledger where every row has a stamped chart label (Index) and every column has a printed header and unit:

  • .iloc[row_pos, col_pos] counts physical lines from the top of the page starting at 0 (like Python list slicing, the stop index is exclusive).
  • .loc[row_label, col_label] looks up rows and columns by their printed labels (just like a dictionary, and slice endpoints are inclusive).
  • Wide vs. Long Format: Wide tables put repeated visits in separate columns (sbp_day1, sbp_day2)—handy for paired differences (day2 - day1). Tidy long tables stack one measurement per row (patient_id, visit, sbp)—required by Seaborn, Statsmodels, and longitudinal mixed-effects models.

17.1.1 The Modern Pandas 3.x Copy-on-Write Discipline

Older Pandas tutorials are packed with inplace=True and chained indexing like df[df["age_years"] >= 18]["bmi"] = ..., which caused notorious SettingWithCopyWarning bugs. In Pandas 3.x, Copy-on-Write (CoW) is active by default: chained assignment fails or silently does nothing to df, and inplace=True returns None. Throughout this book, we follow one ironclad rule: never mutate inputs in place—always derive new tables via out = df.copy() or .assign(...), and return the new DataFrame explicitly.

17.2 Stage 2 — Visual Mental Model: Indexing & Wide-to-Long Reshaping

Trace how a single DataFrame routes through .loc/.iloc indexing, boolean filtering, and pd.melt / pd.crosstab reshaping without ever mutating the raw cohort table:

Keep two visual invariants anchored in your head as you code:

  1. Row filters preserve old index numbers (e.g., [3, 16, 28, ...]) until you explicitly call .reset_index(drop=True).
  2. Reshaping changes table geometry, not data truth: pd.melt stretches \(N\) patients \(\times\) \(K\) visits into \(N \cdot K\) tidy rows, whereas pd.crosstab compresses individual rows into a compact district-by-priority count matrix.
WarningPandas .std() vs. NumPy np.std() Default Trap!

By default, Pandas Series.std() computes the sample standard deviation with Bessel’s correction (ddof=1, dividing by \(n - 1\)), whereas NumPy np.std() defaults to the population standard deviation (ddof=0, dividing by \(n\)). Mixing the two in a statistical pipeline silently shifts every standard deviation and \(z\)-score!

import pandas as pd

df = tutor.load_data("clinic_triage", as_pandas=True)

print("Shape:", df.shape)

17.3.2 Label vs. Position Indexing (.loc vs. .iloc)

Watch the exact difference between integer-position slicing (.iloc) and label-based slicing (.loc):

print("iloc[0:3, 0:3] (exclusive stop):")
print(df.iloc[0:3, 0:3])

by_id = df.set_index("patient_id")
print("\nloc['UHC-0001':'UHC-0003', ['district', 'temp_c']] (inclusive):")
print(by_id.loc["UHC-0001":"UHC-0003", ["district", "temp_c"]])

Expected Output:

1   UHC-0002      Sylhet         55

Compare those two slices side by side:

17.3.3 Boolean Masking with &, |, ~, and .isin()

To isolate clinical sub-cohorts without writing loops, build elementwise boolean Series masks and combine them with bitwise operators (& for AND, | for OR, ~ for NOT):

adult_fever = (df["age_years"] >= 18) & (df["temp_c"] >= 38.0)
target_dist = df["district"].isin(["Dhaka", "Sylhet"])

sub = df.loc[adult_fever & target_dist].reset_index(drop=True)
other_count = int((~target_dist).sum())

print("Adult fever rows (all districts):", int(adult_fever.sum()))
print("Adult fever in Dhaka/Sylhet:     ", len(sub))
print("Outside Dhaka/Sylhet rows:       ", other_count)
print(sub[["patient_id", "district", "age_years", "temp_c"]].head(3))

Expected Output:

Adult fever rows (all districts): 21
Adult fever in Dhaka/Sylhet:      4
Outside Dhaka/Sylhet rows:        90
  patient_id district  age_years  temp_c
0   UHC-0017   Sylhet         31    38.8
1   UHC-0029    Dhaka         41    38.4
2   UHC-0042   Sylhet         32    38.6

Trace three critical syntax habits here:

  • Parentheses around every comparison: Operator precedence binds & tighter than >=, so omitting parentheses around (df["age_years"] >= 18) raises TypeError.
  • .isin([...]) replaces chained | checks: Checking membership across 2 or 20 districts stays concise and fast.
  • .reset_index(drop=True): Without drop=True, Pandas turns the old scattered row labels (16, 28, 41, ...) into an extra column named "index".

17.3.4 Vectorized Columns, .assign(), & Pandas 3.x Copy-on-Write

Derive clinical features cleanly with .assign(...) (or out = df.copy(); out["col"] = ...) so your raw dataset remains 100% immutable:

enriched = df.assign(

print("Anemic patients:     ", int(enriched["is_anemic"].sum()))
cols = ["patient_id", "bmi", "hemoglobin_g_dl", "is_anemic"]
print(enriched[cols].head(3))

17.3.5 Deterministic Multi-Key Sorting with .sort_values()

Whenever two patients share the exact same fever temperature, sorting by a single column leaves tie order arbitrary. Always pass a secondary tie-breaker column (patient_id) with an explicit ascending list:

cols = ["patient_id", "district", "temp_c", "triage_priority"]
top_fever = (
    df.sort_values(
        by=["temp_c", "patient_id"],
        ascending=[False, True],
    )[cols]
    .head(5)
    .reset_index(drop=True)
)
print(top_fever)

Expected Output:

  patient_id    district  temp_c triage_priority
0   UHC-0004    Rajshahi    39.0        Moderate
1   UHC-0107     Rangpur    38.9        Moderate
2   UHC-0017      Sylhet    38.8        Moderate
3   UHC-0057     Rangpur    38.7        Moderate

17.3.6 Reshaping Data: pd.melt, pd.crosstab, & pivot_table

long_bp = pd.melt(

17.3.7 Break It On Purpose! (Pandas Error Anatomy)

ImportantBreak It On Purpose #1 — KeyError (Nonexistent Column Name) 
print(df["hemoglobin"].mean())

Python’s Traceback:

KeyError: 'hemoglobin'

Diagnosis: Column names in Pandas are exact dictionary keys—our dataset stores "hemoglobin_g_dl", not "hemoglobin".
Fix: Inspect list(df.columns) whenever you encounter a KeyError, and verify exact spelling and units (df["hemoglobin_g_dl"].mean()).

ImportantBreak It On Purpose #2 — ValueError (Ambiguous Truth Value of a Series) 
bad_mask = (df["age_years"] >= 18) and (df["temp_c"] >= 38.0)
print(bad_mask.sum())

Python’s Traceback:

ValueError: The truth value of a Series is ambiguous. Use a.empty,
a.item(), a.any() or a.all().

Diagnosis: Python’s logical and tries to collapse a 120-element boolean Series into a single scalar True/False, which is meaningless.
Fix: Replace and / or / not with elementwise bitwise & / | / ~, keeping parentheses around each comparison: (df["age_years"] >= 18) & (df["temp_c"] >= 38.0).

ImportantBreak It On Purpose #3 — IndexError (.iloc Out-of-Bounds Row) 
print(df.iloc[120])

Python’s Traceback:

IndexError: single positional indexer is out-of-bounds

Diagnosis: A 120-row DataFrame has valid 0-based positions 0 through 119. Requesting .iloc[120] steps one slot past the last row!
Fix: Use df.iloc[-1] for the final row, or check len(df) before indexing by integer position.

17.4 Stage 4 — The Researcher’s Problem-Structuring Blueprint

Scenario: A district health director wants a reproducible Adult Fever-Rate Audit from clinic_triage: restrict to adult patients (age_years >= 18), compute each adult’s 2-decimal BMI and has_fever flag (temp_c >= 38.0) without mutating df, tabulate afebrile vs. febrile counts per district, calculate fever_pct rounded to 1 decimal place, and rank districts from highest to lowest fever burden.

17.4.1 Blueprint (Completed on Paper Before Coding)

  1. Purity & Cohort Selection Contract:

    • Filter adults with df.loc[df["age_years"] >= 18].copy() so the original 120-row table remains untouched (len(df.columns) == 11).
    • Add bmi and has_fever via .assign(bmi=lambda d: ..., has_fever=lambda d: ...) and reset the index (drop=True).

  2. Contingency & Rate Formula:

    • Build a 2-column count table via pd.crosstab(cohort["district"], cohort["has_fever"]) (False \(\rightarrow\) afebrile, True \(\rightarrow\) febrile).
    • Compute \(\text{fever\_pct} = \text{round}\!\left(\frac{\text{febrile}}{\text{afebrile} + \text{febrile}} \times 100,\ 1\right)\).

  3. Ranking & Hand Check:

    • Sort descending by fever_pct using .sort_values("fever_pct", ascending=False).
    • Verify row sums match the 97-adult cohort (27 + 16 + 9 + 20 + 12 + 13 = 97) and original df still has 11 columns.

17.4.2 Clean Python Implementation (Verbatim in 01_walkthrough.ipynb)

cohort = (
    df.loc[df["age_years"] >= 18]
    .copy()
    .assign(
        bmi=lambda d: (
            d["weight_kg"] / (d["height_cm"] / 100) ** 2
        ).round(2),
        has_fever=lambda d: d["temp_c"] >= 38.0,
    )
    .reset_index(drop=True)
)

fever_table = pd.crosstab(cohort["district"], cohort["has_fever"])
fever_table.columns = ["afebrile", "febrile"]
total_adults = fever_table["afebrile"] + fever_table["febrile"]
fever_table["fever_pct"] = (
    fever_table["febrile"] / total_adults * 100
).round(1)
ranked = fever_table.sort_values("fever_pct", ascending=False)

print(
    "Adult cohort size:", len(cohort),
    "| Original df cols:", len(df.columns),
)
print(ranked)

Output:

Sylhet             7        2       22.2
Rajshahi          16        4       20.0
Chattogram        10        2       16.7
Dhaka             11        2       15.4

17.8.1 A. Concept & Execution Trace Test Key

  1. df["temp_c"] is a 1D Series with shape (120,); df[["temp_c"]] is a 2D DataFrame with shape (120, 1).
  2. df.iloc[1:3] returns 2 rows (positions 1, 2 — exclusive stop); df.loc[1:3] returns 3 rows (labels 1, 2, 3 — inclusive endpoints).
  3. Python’s and cannot evaluate a multi-element boolean Series as a single truth value. Replace and with & and keep parentheses around each condition.
  4. Bitwise & binds tighter than >=, so Python tries to evaluate 18 & df["temp_c"] first, raising TypeError. Always parenthesize both sides.
  5. None — Pandas methods invoked with inplace=True return None instead of the sorted DataFrame.
  6. An extra column named "index" containing [16, 28, 41, 77] is inserted as the first column. Always pass drop=True unless you want to preserve old labels as data.
  7. s.std() (ddof=1) returns \(\sqrt{8.0 / 2} = \mathbf{2.0}\); s.std(ddof=0) returns \(\sqrt{8.0 / 3} \approx \mathbf{1.633}\).
  8. (135, 3) — \(45 \times 3 = 135\) rows and 3 columns (patient_id, variable, value).
  9. Khulna is silently dropped from the output instead of appearing with 0 Urgent patients (0.0%). pd.crosstab keeps every district and fills missing cells with integer 0.
  10. Assigning df["bmi"] = ... directly mutates the caller’s DataFrame as a hidden side effect, breaking reproducibility if the caller expects the original schema later in the notebook.

17.8.3 C. Annotated Solutions — Chapter 17 Coding Exam (Mirrored in 03_coding_exam_SOLUTION.ipynb)

# Exam Task 17.1 (30 pts)
def prepare_triage_cohort(df):
    """Return non-mutating adult triage cohort with bmi and is_anemic."""
    adults = df.loc[df["age_years"] >= 18].copy()
    height_m = adults["height_cm"] / 100
    adults["bmi"] = (adults["weight_kg"] / (height_m ** 2)).round(2)
    adults["is_anemic"] = adults["hemoglobin_g_dl"] < 11.0
    return adults.reset_index(drop=True)

# Exam Task 17.2 (35 pts)
def rank_districts_by_urgent_share(df):
    """Rank districts by % Urgent patients desc, then district asc."""
    is_urgent = df["triage_priority"] == "Urgent"
    counts = pd.crosstab(df["district"], is_urgent)
    total = counts.sum(axis=1)
    urgent = (
        counts[True]
        if True in counts.columns
        else pd.Series(0, index=total.index)
    )
    out = pd.DataFrame(
        {
            "district": total.index,
            "total_patients": total.astype(int).values,
            "urgent_patients": urgent.astype(int).values,
        }
    )
    out["urgent_pct"] = (
        out["urgent_patients"] / out["total_patients"] * 100
    ).round(1)
    return out.sort_values(
        by=["urgent_pct", "district"],
        ascending=[False, True],
    ).reset_index(drop=True)

# Exam Task 17.3 (35 pts)
def reshape_and_compare_visits(wide_df):
    """Melt baseline/followup Hb and return (long_df, mean_change)."""
    long_df = pd.melt(
        wide_df,
        id_vars=["patient_id"],
        value_vars=["hb_baseline", "hb_followup"],
        var_name="visit",
        value_name="hb_g_dl",
    )
    deltas = wide_df["hb_followup"] - wide_df["hb_baseline"]
    mean_change = float(round(deltas.mean(), 2))
    return long_df, mean_change

17.8.4 D. Debugging Post-Mortem: Top 3 Chapter 17 Failure Modes

  1. Mutating Input DataFrames or Using inplace=True: Writing df["bmi"] = ... directly on an argument leaks columns back into the caller’s table, and df = df.sort_values(..., inplace=True) sets df to None. Always copy (out = df.copy() or .assign(...)) and return the fresh DataFrame.
  2. Mixing Python and/or/not with Pandas Series Masks: Every Pandas boolean mask is a vector of booleans, not a single truth value. Always write (cond_a) & (cond_b), (cond_a) | (cond_b), or ~(cond_a) with parentheses around each condition.
  3. Dropping Zero-Count Categories During Filtering: Filtering to "Urgent" rows before counting districts erases zero-urgent districts from denominator tables and prevalence rankings. Use pd.crosstab or full-table boolean sums so every district stays accounted for.
