Learning Objectives

By the end of this chapter, you will be able to:

  1. Distinguish MCAR, MAR, and MNAR missingness mechanisms and build deterministic column-level missingness audit tables before and after cleaning.
  2. Clean dirty household surveys in pure Pandas 3.x style—copying inputs explicitly, normalizing inconsistent string casing (.str.strip().str.title()), neutralizing DHS sentinel codes (999 \(\rightarrow\) NaN), and coercing mixed-type columns safely with pd.to_numeric(..., errors="coerce").

  4. Join relational patient and laboratory tables with pd.merge(..., how="left", validate="one_to_one") so duplicate keys raise MergeError immediately instead of silently exploding row counts.
  5. Produce publication-ready Table 1 health-equity summaries using Split-Apply-Combine named .agg() and engineer zero-leakage panel time-series features (1-week lags and rolling means) strictly within each district.

18.1 Stage 1 — First-Principles Intuition: Why Real Research Data Breaks Clean Code

In Chapter 17, you learned Pandas fundamentals on tidy DataFrames. Real public health surveys (like the Demographic and Health Surveys, DHS) and weekly epidemiological surveillance feeds rarely arrive tidy:

  • Hidden Sentinel Codes: Survey interviewers record "Don't know" as 999, 99, or -99. If you compute mch["anc_visits"].mean() without neutralizing 999 first, just 8 sentinel rows out of 500 inflate average antenatal care visits from \(3.77\) to an absurd \(19.7\)!
  • Dirty Categorical Strings: Field enumerators type "Rural", "rural", " rural ", and "URBAN". Left unnormalized, .groupby("residence") splits one stratum into four fragmented rows and corrupts every downstream summary.
  • Silent Row Explosions in Joins: Joining a 500-patient registry to a lab table that accidentally contains two hemoglobin tests for one patient quietly turns 500 rows into 501+—double-counting that patient in every prevalence estimate.
  • Cross-District Time-Series Leakage: Computing .shift(1) or .rolling(4).mean() on a stacked multi-district table lets Chattogram’s December dengue surge bleed directly into Dhaka’s Week 1 feature!

18.1.1 Missing-Data Mechanisms: MCAR, MAR, and MNAR

Before dropping or imputing a single NaN, ask why the value is missing:

Mechanism Meaning Public Health Example Safe Wrangling Action
MCAR Missing Completely At Random Lab vial dropped on floor Complete-case or simple imputation is unbiased
MAR Missing At Random (given observed strata) Rural clinics have more missing Hb tests than urban clinics Impute within observed strata (e.g., per-residence median)
MNAR Missing Not At Random (depends on unobserved value itself) Severely ill patients skip follow-up weigh-ins Do not blindly impute; flag missingness and run sensitivity analysis
NotePandas 3.x Copy-on-Write Rule — Pure Functions Only!

Starting in Pandas 3.x, Copy-on-Write is enforced globally: chained assignments like df["anc_visits"][mask] = np.nan fail or behave unpredictably, and inplace=True is discouraged because it returns None and obscures state mutations. Adopt one clean habit for every wrangling function you write:

  • Start with out = df.copy().
  • Transform columns with direct assignment: out["col"] = ....
  • End with return out, leaving the caller’s raw DataFrame untouched.

Trace the exact order of operations that protects research tables from sentinel distortion, join row explosions, and cross-group leakage:

Notice why stage order is non-negotiable:

  • You must normalize "rural" \(\rightarrow\) "Rural" before grouping to compute per-residence medians, otherwise lowercase rows form their own tiny broken group.
  • You must replace 999 \(\rightarrow\) NaN before evaluating thresholds like anc_visits >= 4, otherwise 999 >= 4 falsely evaluates to True!

18.3.3 Group-Median Imputation with .groupby(...).transform("median")

Because hemoglobin missingness differs across strata (16 Rural vs. 6 Urban missing readings, with medians \(11.4\) vs. \(11.6\text{ g/dL}\)), imputing by per-residence median respects MAR structure better than plugging in one global average:

# Check missing Hb by residence (MAR diagnostic) and group medians
hb_na_by_res = mch.groupby("residence")["maternal_hb_g_dl"].apply(
    lambda s: int(s.isna().sum())
)
hb_med_by_res = mch.groupby("residence")["maternal_hb_g_dl"].median()
print("Missing Hb by residence:", hb_na_by_res.to_dict())
print("Median Hb by residence: ", hb_med_by_res.to_dict())

# Impute missing Hb with per-residence median (non-mutating copy)
mch_imp = mch.copy()
group_medians = (
    mch_imp.groupby("residence")["maternal_hb_g_dl"]
    .transform("median")
)
mch_imp["maternal_hb_g_dl"] = mch_imp["maternal_hb_g_dl"].fillna(
    group_medians
)

post_means = (
    mch_imp.groupby("residence")["maternal_hb_g_dl"]
    .mean().round(2).to_dict()
)
print("Remaining Hb NaNs:", int(mch_imp["maternal_hb_g_dl"].isna().sum()))
print("Post-imputation means:", post_means)

Expected Output:

Missing Hb by residence: {'Rural': 16, 'Urban': 6}
Median Hb by residence:  {'Rural': 11.4, 'Urban': 11.6}
Remaining Hb NaNs: 0
Post-imputation means: {'Rural': 11.41, 'Urban': 11.6}

Why .transform("median") instead of .median()? .groupby("residence")["maternal_hb_g_dl"].median() collapses the table to 2 rows (Rural, Urban), whereas .transform("median") broadcasts each group’s median back onto all 500 rows with exact index alignment so .fillna(group_medians) fills every missing entry cleanly in one vectorized pass.

18.3.4 Safe Relational Joins with pd.merge(..., validate="one_to_one")

When linking a patient intake table to a separate laboratory table, always specify both how= (usually "left" to retain your full cohort) and validate= to enforce key uniqueness:

patients = pd.DataFrame(
    {
        "patient_id": ["P-101", "P-102", "P-103", "P-104"],
        "residence": ["Rural", "Urban", "Rural", "Urban"],
    }
)
labs = pd.DataFrame(
    {
        "patient_id": ["P-101", "P-102", "P-104", "P-999"],
        "ferritin_ng_ml": [18.5, 42.0, 31.2, 25.0],
    }
)

joined = pd.merge(
    patients, labs, on="patient_id", how="left", validate="one_to_one"
)
print(joined.to_string(index=False))

Expected Output:

patient_id residence  ferritin_ng_ml
     P-101     Rural            18.5
     P-102     Urban            42.0
     P-103     Rural             NaN
     P-104     Urban            31.2

Notice two critical guarantees here:

  • Unmatched patient P-103 stays in the cohort with NaN for ferritin_ng_ml (unlike how="inner", which would silently drop her).
  • Orphan lab record P-999 is excluded (unlike how="outer", which would inject an unenrolled person).

18.3.6 Panel Time Series: Per-District Lags & Rolling Windows

Epidemiological surveillance data (epi_surveillance) is a panel dataset: multiple districts tracked repeatedly across weeks and years. Always sort by ["district", "year", "epi_week"] first, then run .shift(1) and .rolling(...) strictly inside .groupby("district"):

epi = epi_raw.sort_values(["district", "year", "epi_week"]).copy()
epi["prev_week_cases"] = epi.groupby("district")["dengue_cases"].shift(1)
epi["rolling_4w"] = (
    epi.groupby("district")["dengue_cases"]
    .transform(lambda s: s.rolling(window=4, min_periods=1).mean())
    .round(2)
)

cols = ["district", "year", "epi_week", "dengue_cases",

18.3.7 Break It On Purpose! (Wrangling Error Anatomy)

ImportantBreak It On Purpose #1 — pd.errors.MergeError (Duplicate Keys Caught!) 
dup_labs = pd.DataFrame(
    {
        "patient_id": ["P-101", "P-101", "P-102"],
        "ferritin_ng_ml": [18.5, 22.0, 42.0],
    }
)
pd.merge(
    patients, dup_labs, on="patient_id", how="left", validate="one_to_one"
)

Python’s Traceback:

pandas.errors.MergeError: Merge keys are not unique in right dataset;
not a one-to-one merge

Diagnosis: dup_labs has two rows for "P-101". Without validate="one_to_one", Pandas would silently duplicate "P-101" in the merged table!
Fix: Deduplicate or aggregate dup_labs per patient_id (e.g., taking the latest or mean lab value) before merging.

ImportantBreak It On Purpose #2 — KeyError (Missing Join Key) 
misnamed_labs = pd.DataFrame(
    {"household_id": ["P-101", "P-102"], "hb_g_dl": [11.4, 10.2]}
)
pd.merge(patients, misnamed_labs, on="patient_id", how="left")

Python’s Traceback:

KeyError: 'patient_id'

Diagnosis: patients uses "patient_id" while misnamed_labs uses "household_id", so on="patient_id" cannot find the join column on the right table.
Fix: Either rename the column first (misnamed_labs.rename(columns={"household_id": "patient_id"})) or pass explicit left_on="patient_id", right_on="household_id".

ImportantBreak It On Purpose #3 — ValueError (.astype(float) on Dirty Text) 
dirty_hb = pd.Series(["11.2", "N/A", "9.8"])
dirty_hb.astype(float)

Python’s Traceback:

ValueError: could not convert string to float: 'N/A'

Diagnosis: Strict .astype(float) crashes on the very first non-numeric token ("N/A", ".", "", or "missing"), which are ubiquitous in CSV exports from clinic spreadsheets.
Fix: Always cast messy numeric columns with pd.to_numeric(series, errors="coerce") so valid numbers become floats and unparseable tokens cleanly become NaN.

18.4 Stage 4 — The Researcher’s Problem-Structuring Blueprint

Scenario: A Ministry of Health policy brief needs an automated, reproducible function build_equity_brief(raw_mch) that takes a raw DHS maternal-child survey, cleans all dirty casing and sentinel codes, imputes missing maternal hemoglobin by residence median, derives WHO’s 4+ antenatal care visits (anc_4plus) indicator, and outputs a flat, sorted residence \(\times\) wealth_quintile equity table without mutating raw_mch.

18.4.1 Blueprint (Completed on Paper Before Coding)

  1. Non-Mutating Cleaning Sequence (Strict Order):

    • Copy raw_mch (df = raw_mch.copy()).
    • Normalize residence with .str.strip().str.title() first.
    • Neutralize sentinel anc_visits == 999 \(\rightarrow\) np.nan before thresholding.
    • Coerce maternal_hb_g_dl via pd.to_numeric(..., errors="coerce") and impute missing values with per-residence median via .groupby("residence")["maternal_hb_g_dl"].transform("median").
    • Derive anc_4plus = (df["anc_visits"] >= 4).fillna(False).astype(bool).

  2. Stratified Aggregation Contract:

    • Group with groupby(["residence", "wealth_quintile"], as_index=False) so stratification keys stay flat columns.
    • Compute n_households, stunting_pct, anemia_pct, and anc4_pct (each percentage scaled by \(100\) and rounded to 1 decimal place).
    • Sort deterministically by ["residence", "wealth_quintile"] and reset the index.

  3. Verification Plan:

    • Check Rural + Poorest vs. Urban + Richest: anc4_pct should rise sharply with both wealth and urbanicity, and raw_mch["anc_visits"] must still contain its original 8 sentinel 999 entries untouched.

18.4.2 Clean Python Implementation (Verbatim in 01_walkthrough.ipynb)

def build_equity_brief(raw_mch):
    """Clean DHS survey and summarize residence x wealth equity gaps."""
    df = raw_mch.copy()
    df["residence"] = df["residence"].str.strip().str.title()
    df["anc_visits"] = df["anc_visits"].replace(999, np.nan)
    df["maternal_hb_g_dl"] = pd.to_numeric(
        df["maternal_hb_g_dl"], errors="coerce"
    )
    med = df.groupby("residence")["maternal_hb_g_dl"].transform("median")
    df["maternal_hb_g_dl"] = df["maternal_hb_g_dl"].fillna(med)
    df["anc_4plus"] = (df["anc_visits"] >= 4).fillna(False).astype(bool)

    brief = df.groupby(
        ["residence", "wealth_quintile"], as_index=False
    ).agg(
        n_households=("household_id", "count"),
        stunting_pct=("child_stunted", "mean"),
        anemia_pct=("maternal_anemia", "mean"),
        anc4_pct=("anc_4plus", "mean"),
    )
    for col in ("stunting_pct", "anemia_pct", "anc4_pct"):
        brief[col] = (brief[col] * 100).round(1)
    return brief.sort_values(["residence", "wealth_quintile"]).reset_index(
        drop=True
    )

equity_brief = build_equity_brief(mch_raw)
print(equity_brief.to_string(index=False))

18.8.1 A. Concept & Execution Trace Test Key

  1. MAR (Missing At Random): Missingness depends on an observed variable (residence), not on the unobserved hemoglobin value itself—making per-residence median imputation principled.
  2. True! Because \(999 \ge 4\), computing anc_4plus before replacing 999 with np.nan falsely classifies unknown antenatal history as meeting the WHO 4+ visit target.
  3. Creating out = df.copy() and using direct assignment (out["x"] = ...) respects Pandas 3.x Copy-on-Write, preserves the caller’s raw data for auditability, and avoids inplace=True returning None.
  4. .astype(float) raises ValueError: could not convert string to float: 'N/A', whereas pd.to_numeric(..., errors="coerce") returns Series([10.5, NaN, 12.0], dtype=float64).

18.8.2 B. Annotated Solutions — Guided To-Dos (Mirrored in 02_guided_todos_SOLUTION.ipynb)

import numpy as np
import pandas as pd

# To-Do 18.1
def clean_mch_survey(df):
    """Return a cleaned copy of a dirty DHS/MCH household survey."""
    out = df.copy()
    out["residence"] = out["residence"].str.strip().str.title()
    out["anc_visits"] = out["anc_visits"].replace(999, np.nan)
    out["maternal_hb_g_dl"] = pd.to_numeric(
        out["maternal_hb_g_dl"], errors="coerce"
    )
    return out

# To-Do 18.2
def audit_missingness_table(df):
    """Return column-level missing counts and percentages sorted neatly."""
    counts = df.isna().sum().astype(int)
    pcts = (counts / len(df) * 100).round(2)
    audit = pd.DataFrame(
        {"missing_count": counts, "missing_pct": pcts}
    )
    return audit.sort_index().sort_values(
        "missing_pct", ascending=False, kind="mergesort"
    )

# To-Do 18.3
def impute_group_median(df, value_col, group_col):
    """Fill NaNs in value_col using per-group medians without mutation."""
    out = df.copy()
    medians = out.groupby(group_col)[value_col].transform("median")
    out[value_col] = out[value_col].fillna(medians)
    return out

# To-Do 18.4
def safe_merge_patient_labs(patients_df, labs_df):
    """Left-join patients to labs with strict 1-to-1 key validation."""
    return pd.merge(
        patients_df,
        labs_df,
        on="patient_id",
        how="left",
        validate="one_to_one",
    )

# To-Do 18.5
def groupby_wealth_outcomes(mch_df):
    """Aggregate stunting, anemia, and ANC outcomes by wealth quintile."""
    out = mch_df.groupby("wealth_quintile").agg(
        n_households=("child_stunted", "size"),
        stunting_pct=("child_stunted", "mean"),
        anemia_pct=("maternal_anemia", "mean"),
        mean_anc=("anc_visits", "mean"),
    )
    out["stunting_pct"] = (out["stunting_pct"] * 100).round(1)
    out["anemia_pct"] = (out["anemia_pct"] * 100).round(1)
    out["mean_anc"] = out["mean_anc"].round(2)
    return out

# To-Do 18.6
def add_rolling_dengue_avg(epi_df, window=4):
    """Add per-district rolling dengue mean without boundary leakage."""
    out = epi_df.sort_values(["district", "year", "epi_week"]).copy()
    out["rolling_dengue"] = (
        out.groupby("district")["dengue_cases"]
        .transform(lambda s: s.rolling(window=window, min_periods=1).mean())
        .round(2)
    )
    return out

18.8.3 C. Annotated Solutions — Chapter 18 Coding Exam (Mirrored in 03_coding_exam_SOLUTION.ipynb)

# Exam Task 18.1 (30 pts)
def build_clean_dhs_analytic_table(mch_df):
    """Clean DHS survey, impute Hb by residence, and flag anc_4plus."""
    out = mch_df.copy()
    out["residence"] = out["residence"].str.strip().str.title()
    out["anc_visits"] = out["anc_visits"].replace(999, np.nan)
    out["maternal_hb_g_dl"] = pd.to_numeric(
        out["maternal_hb_g_dl"], errors="coerce"
    )
    medians = out.groupby("residence")["maternal_hb_g_dl"].transform(
        "median"
    )
    out["maternal_hb_g_dl"] = out["maternal_hb_g_dl"].fillna(medians)
    out["anc_4plus"] = (
        (out["anc_visits"] >= 4).fillna(False).astype(bool)
    )
    return out

# Exam Task 18.2 (35 pts)
def equity_gap_by_residence_wealth(clean_mch_df):
    """Stratify stunting, anemia, and ANC4+ by residence and wealth."""
    out = clean_mch_df.groupby(
        ["residence", "wealth_quintile"], as_index=False
    ).agg(
        n_households=("child_stunted", "size"),
        stunting_pct=("child_stunted", "mean"),
        anemia_pct=("maternal_anemia", "mean"),
        anc4_pct=("anc_4plus", "mean"),
    )
    for col in ("stunting_pct", "anemia_pct", "anc4_pct"):
        out[col] = (out[col] * 100).round(1)
    return out.sort_values(
        ["residence", "wealth_quintile"]
    ).reset_index(drop=True)

# Exam Task 18.3 (35 pts)
def prepare_epi_time_features(epi_df):
    """Engineer incidence, 1-week lag, and 4-week rolling dengue mean."""
    out = epi_df.sort_values(["district", "year", "epi_week"]).copy()
    out["incidence_per_100k"] = (
        out["dengue_cases"] / out["population"] * 100_000
    ).round(2)
    out["prev_week_cases"] = (
        out.groupby("district")["dengue_cases"].shift(1)
    )
    out["rolling_4w_cases"] = (
        out.groupby("district")["dengue_cases"]
        .transform(lambda s: s.rolling(window=4, min_periods=1).mean())
        .round(2)
    )
    return out

18.8.4 D. Debugging Post-Mortem: Top 3 Chapter 18 Failure Modes

  1. Wrong Cleaning Order (999 >= 4 & Unnormalized Group Imputation): Thresholding anc_visits >= 4 before neutralizing 999 inflates ANC4+ coverage, and imputing hemoglobin before normalizing "rural" to "Rural" splits rural respondents across separate medians. Always follow: Normalize categories \(\rightarrow\) Neutralize sentinels \(\rightarrow\) Coerce & Impute \(\rightarrow\) Derive indicators.
  2. Unvalidated Merges (Silent Row Explosion): Calling pd.merge(patients, labs, on="patient_id", how="left") without validate="one_to_one" lets duplicate lab keys silently inflate sample sizes and double-count sick patients.
  3. Global Lags/Rolling Windows on Panel Data: Calling .shift(1) or .rolling(4).mean() directly on a multi-district DataFrame leaks one district’s final weeks into the next district’s Week 1. Always sort by [entity, time] and scope window operators inside .groupby(entity).
