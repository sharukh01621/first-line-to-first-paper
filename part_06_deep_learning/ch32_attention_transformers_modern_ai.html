32.1 Stage 1 — First-Principles Intuition: From Sequential Bottlenecks to Attention & LoRA

In Chapters 27–31, you built PyTorch tensors and autograd, custom Dataset / DataLoader pipelines, MLPs, CNNs for medical imaging, and recurrent sequence models (RNNs/LSTMs). Recurrent models process a clinical discharge summary one word at a time (\(h_1 \to h_2 \to \dots \to h_T\)). That sequential chain creates two fatal limitations at scale:

  • Long-Range Information Bottleneck: Every early clue ("allergic to penicillin" on token 4) must survive dozens of recurrent multiplications before reaching token 120 ("prescribe antibiotic"), causing gradients to vanish or distort.
  • Zero Parallelism Across Time: Token \(t\) cannot be computed until token \(t - 1\) finishes, wasting modern GPU matrix-multiplication hardware.

Self-Attention (Vaswani et al., 2017, “Attention Is All You Need”) replaces the sequential chain with an all-pairs lookup table computed in one parallel matrix multiply:

\[\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V\]

Each token projects its embedding into three specialized roles:

  • Query (\(Q\)): “What clinical context am I looking for right now?”
  • Key (\(K\)): “What clinical information do I advertise to other tokens?”
  • Value (\(V\)): “What feature vector should I pass forward if another token attends to me?”

Why is dividing by \(\sqrt{d_k}\) mandatory? If entries of \(Q\) and \(K\) have mean \(0\) and variance \(1\), their dot product \(q \cdot k = \sum_{j=1}^{d_k} q_j k_j\) has variance \(d_k\) (standard deviation \(\sqrt{d_k}\)). For \(d_k = 64\), raw dot products swing between \(-20\) and \(+20\), pushing softmax to near one-hot saturation (0.9999 vs. 0.0001) where its Jacobian collapses to zero! Dividing by \(\sqrt{d_k}\) restores unit variance (\(\text{Var} = 1\)) and keeps gradients flowing cleanly.

32.3.3 Scaled Dot-Product Attention & Causal Autoregressive Masking

def scaled_dot_product_attention(Q, K, V, mask=None):
    """Compute scaled dot-product attention (mask: 1=allow, 0=block)."""
    d_k = Q.size(-1)
    scores = (Q @ K.transpose(-2, -1)) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    attn = torch.softmax(scores, dim=-1)
    return attn @ V, attn

torch.manual_seed(7)
Q_ex = torch.randn(1, 4, 8)
K_ex = torch.randn(1, 4, 8)
V_ex = torch.randn(1, 4, 8)
causal_mask = torch.tril(torch.ones(1, 4, 4))
ctx, causal_attn = scaled_dot_product_attention(
    Q_ex, K_ex, V_ex, mask=causal_mask
)
upper_max = torch.triu(causal_attn[0], diagonal=1).max().item()
row_err = (causal_attn.sum(dim=-1) - 1.0).abs().max().item()
print("Context shape:", tuple(ctx.shape),
      "| Attn shape:", tuple(causal_attn.shape))

print(np.round(causal_attn[0].detach().numpy(), 3))

Trace the mechanics carefully:

  • Using K.transpose(-2, -1) (negative indices!) guarantees the exact same function handles both 3D single-head (B, T, d_k) and 4D multi-head (B, H, T, d_k) tensors.
  • Filling mask == 0 with float("-inf") before torch.softmax(scores, dim=-1) sends \(e^{-\infty} = 0.0\) strictly to zero while automatically renormalizing the allowed positions so every row sums to 1.000000.
  • Notice Row 0 ([1.0, 0, 0, 0]): token 0 sees only itself; token 2 sees tokens 0, 1, and 2 (0.088 + 0.849 + 0.063 = 1.0) and never peeks at future token 3. That exact triangular mask powers every autoregressive LLM (GPT, Gemini, Llama).

32.3.4 Sinusoidal Positional Encoding (Vaswani et al., 2017)

def sinusoidal_positional_encoding(max_len, d_model):
    """Return (max_len, d_model) float32 sinusoidal position table."""
    pe = torch.zeros(max_len, d_model, dtype=torch.float32)
    pos = torch.arange(0, max_len, dtype=torch.float32).unsqueeze(1)
    div_term = torch.exp(
        torch.arange(0, d_model, 2, dtype=torch.float32)
        * (-math.log(10000.0) / d_model)
    )
    pe[:, 0::2] = torch.sin(pos * div_term)
    pe[:, 1::2] = torch.cos(pos * div_term[: d_model // 2])
    return pe

pe = sinusoidal_positional_encoding(max_len=12, d_model=16)
cos = nn.CosineSimilarity(dim=0)
print("PE shape:", tuple(pe.shape), "| dtype:", pe.dtype)
print("pos=0 first 6 dims:", np.round(pe[0, :6].numpy(), 3))
print(f"cos(pos0, pos1): {cos(pe[0], pe[1]).item():.4f} | "
      f"cos(pos0, pos10): {cos(pe[0], pe[10]).item():.4f}")

Expected Output:

PE shape: (12, 16) | dtype: torch.float32
pos=0 first 6 dims: [0. 1. 0. 1. 0. 1.]
cos(pos0, pos1): 0.9356 | cos(pos0, pos10): 0.4558

Why compute div_term in log-space (exp(2i * -ln(10000) / d_model)) instead of 1.0 / (10000 ** (2i / d_model))? Log-space exponentiation is numerically cleaner and standard across PyTorch implementations. Notice also the geometric property: adjacent positions (pos0, pos1) share high cosine similarity (0.9356), while distant positions (pos0, pos10) decay smoothly (0.4558).

32.3.5 Multi-Head Self-Attention & Transformer Encoder Block

class MultiHeadSelfAttention(nn.Module):
    """Multi-head self-attention with W_q, W_k, W_v, W_o projections."""

    def __init__(self, d_model, num_heads):
        super().__init__()
        if d_model % num_heads != 0:
            raise ValueError(
                f"d_model ({d_model}) must be divisible by "
                f"num_heads ({num_heads})"
            )
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        B, T, _ = x.shape
        H, dk = self.num_heads, self.d_k
        Q = self.W_q(x).view(B, T, H, dk).transpose(1, 2)
        K = self.W_k(x).view(B, T, H, dk).transpose(1, 2)
        V = self.W_v(x).view(B, T, H, dk).transpose(1, 2)
        ctx, attn = scaled_dot_product_attention(Q, K, V, mask=mask)
        merged = ctx.transpose(1, 2).contiguous().view(
            B, T, self.d_model
        )
        return self.W_o(merged), attn


class TransformerEncoderBlock(nn.Module):
    """Pre/Post-LN Transformer Encoder: MHA + Residual + GELU FFN."""

    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.attn = MultiHeadSelfAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.drop = nn.Dropout(dropout)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
        )

    def forward(self, x, mask=None):
        attn_out, weights = self.attn(x, mask=mask)
        x = self.norm1(x + self.drop(attn_out))
        x = self.norm2(x + self.drop(self.ffn(x)))
        return x, weights

torch.manual_seed(42)
block = TransformerEncoderBlock(d_model=16, num_heads=4, d_ff=32)

Study the tensor reshape idiom in MultiHeadSelfAttention.forward:

  1. self.W_q(x) maps (B, T, d_model) \(\to\) (B, T, d_model).
  2. .view(B, T, H, dk) splits only the last feature axis into H parallel heads of size d_k = d_model // H.
  3. .transpose(1, 2) swaps T and H into (B, H, T, dk) so scaled_dot_product_attention runs all H heads simultaneously in one batched matmul.
  4. .transpose(1, 2).contiguous().view(B, T, d_model) concatenates all head outputs cleanly before mixing across heads with self.W_o.

32.3.6 Clinical Triage Note Classifier & Attention Interpretability

class ClinicalVocabTokenizer:
    """Deterministic whitespace clinical tokenizer with PAD & UNK."""

    PAD_ID = 0
    UNK_ID = 1

    def __init__(self):
        self.token_to_id = {"<PAD>": 0, "<UNK>": 1}
        self.id_to_token = {0: "<PAD>", 1: "<UNK>"}

    def fit(self, texts):
        words = sorted(
            {w for t in texts for w in t.lower().split()}
        )
        self.token_to_id = {"<PAD>": 0, "<UNK>": 1}
        for idx, word in enumerate(words, start=2):
            self.token_to_id[word] = idx
        self.id_to_token = {
            v: k for k, v in self.token_to_id.items()
        }
        return self

    def encode(self, text, max_len):
        ids = [
            self.token_to_id.get(w, self.UNK_ID)
            for w in text.lower().split()
        ][:max_len]
        return ids + [self.PAD_ID] * (max_len - len(ids))

    def __len__(self):
        return len(self.token_to_id)


def make_clinical_triage_notes(n_per_class=90, seed=42):
    """Synthesize deterministic Routine (0) vs Urgent (1) notes."""
    rng = np.random.default_rng(seed)
    shared = ["patient", "ward", "reports", "clinic", "history"]
    routine = [
        "mild", "stable", "refill", "followup", "normal",
        "routine", "afebrile", "checkup", "rash", "cleared",
    ]
    urgent = [
        "severe", "chest", "pain", "dyspnea", "hypoxia",
        "sepsis", "tachycardia", "syncope", "bleeding", "emergency",
    ]
    texts, labels = [], []
    for _ in range(n_per_class):
        ctx = list(rng.choice(shared, size=2, replace=False))
        r_toks = list(rng.choice(routine, size=4, replace=False))
        u_toks = list(rng.choice(urgent, size=4, replace=False))
        if rng.random() < 0.2:
            r_toks[0] = str(rng.choice(urgent))
        if rng.random() < 0.2:
            u_toks[0] = str(rng.choice(routine))
        r_note = ctx + r_toks
        u_note = ctx + u_toks
        rng.shuffle(r_note)
        rng.shuffle(u_note)
        texts.append(" ".join(r_note))
        labels.append(0)
        texts.append(" ".join(u_note))
        labels.append(1)
    return texts, np.array(labels, dtype=np.int64)


class ClinicalNoteTransformer(nn.Module):
    """Mini Encoder Transformer for clinical triage classification."""

    def __init__(self, vocab_size, max_len=10, d_model=16, heads=2):
        super().__init__()
        self.emb = nn.Embedding(
            vocab_size, d_model, padding_idx=0
        )
        self.register_buffer(
            "pe", sinusoidal_positional_encoding(max_len, d_model)
        )
        self.enc = TransformerEncoderBlock(
            d_model, heads, d_ff=32, dropout=0.1
        )
        self.head = nn.Linear(d_model, 1)

    def forward(self, ids):
        pad_mask = (ids != 0).float()
        attn_mask = pad_mask.unsqueeze(1).unsqueeze(2)
        x = self.emb(ids) + self.pe[: ids.size(1)]
        h, attn = self.enc(x, mask=attn_mask)
        w = pad_mask.unsqueeze(-1)
        pooled = (h * w).sum(dim=1) / w.sum(dim=1).clamp(min=1.0)
        return self.head(pooled), attn

32.3.7 Parameter-Efficient Fine-Tuning With LoRA (\(\Delta W = B A\))

Full fine-tuning of a 7-billion-parameter clinical LLM requires storing gradients and Adam momentum states for every weight (>80 GB VRAM). Low-Rank Adaptation (LoRA; Hu et al., 2021) freezes the pretrained matrix \(W_0 \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}\) and learns only two tiny low-rank matrices \(A \in \mathbb{R}^{r \times d_{\text{in}}}\) and \(B \in \mathbb{R}^{d_{\text{out}} \times r}\) with \(r \ll \min(d_{\text{in}}, d_{\text{out}})\):

\[h = W_0 x + \frac{\alpha}{r} B (A x)\]

class LoRALinear(nn.Module):
    """Freeze base nn.Linear and learn low-rank delta (B @ A)."""

    def __init__(self, base_linear, rank=4, alpha=8.0):
        super().__init__()
        self.base_linear = base_linear
        for p in self.base_linear.parameters():
            p.requires_grad = False
        self.rank = rank
        self.alpha = float(alpha)
        self.scaling = float(alpha) / rank
        in_f = base_linear.in_features
        out_f = base_linear.out_features
        self.lora_A = nn.Parameter(torch.randn(rank, in_f) * 0.02)
        self.lora_B = nn.Parameter(torch.zeros(out_f, rank))

    def forward(self, x):
        base_out = self.base_linear(x)
        delta = (x @ self.lora_A.T @ self.lora_B.T) * self.scaling
        return base_out + delta

32.3.8 Break It On Purpose! (Transformer Error Anatomy)

ImportantBreak It On Purpose #1 — ValueError (d_model Not Divisible by num_heads) 
bad_mha = MultiHeadSelfAttention(d_model=30, num_heads=4)

Python’s Traceback:

ValueError: d_model (30) must be divisible by num_heads (4)

Diagnosis: Multi-Head Attention splits d_model evenly across num_heads subspaces of width \(d_k = d_{\text{model}} / H\). Because 30 / 4 = 7.5 is not an integer, .view(B, T, 4, d_k) would crash silently or misalign features.
Fix: Always choose d_model as an exact multiple of num_heads (e.g., d_model=32, num_heads=4 or BERT’s d_model=768, num_heads=12) and enforce d_model % num_heads == 0 in __init__.

ImportantBreak It On Purpose #2 — IndexError (OOV Token ID >= vocab_size in nn.Embedding) 
tiny_emb = nn.Embedding(num_embeddings=10, embedding_dim=8)
tiny_emb(torch.tensor([2, 12]))

Python’s Traceback:

IndexError: index out of range in self

Diagnosis: nn.Embedding(10, 8) allocates a lookup table with valid indices 0..9. Passing token ID 12 (e.g., from a mismatched tokenizer or unmapped OOV clinical abbreviation) indexes past the end of the embedding table.
Fix: Always initialize nn.Embedding(len(tokenizer), d_model, padding_idx=0) from the exact fitted tokenizer and route unseen test words to UNK_ID = 1.

ImportantBreak It On Purpose #3 — RuntimeError (Misaligned Mask Shape in masked_fill) 
bad_mask = torch.ones(1, 5)
scaled_dot_product_attention(Q_ex, K_ex, V_ex, mask=bad_mask)

Python’s Traceback:

RuntimeError: The size of tensor a (5) must match the size of tensor b (4) at non-singleton dimension 2

Diagnosis: scores has shape (1, 4, 4) (or (B, H, T, T) in multi-head mode), while bad_mask had trailing dimension 5 instead of 4. PyTorch broadcasting requires every mask axis to either match scores or equal 1.
Fix: Shape padding masks as (B, 1, 1, T) (broadcasting cleanly over all heads and query positions) and causal masks as (1, 1, T, T) (or (1, T, T) for 3D single-head attention).

def run_clinical_transformer_lora_audit(seed=42):
    """Train triage Transformer, wrap Q/V in LoRA, and audit params."""
    torch.manual_seed(seed)
    np.random.seed(seed)
    texts, y = make_clinical_triage_notes(n_per_class=90, seed=seed)
    tr_t, va_t, y_tr, y_va = train_test_split(
        texts, y, test_size=0.25, stratify=y, random_state=seed
    )
    tok = ClinicalVocabTokenizer().fit(tr_t)
    X_tr = torch.tensor([tok.encode(t, 10) for t in tr_t])
    X_va = torch.tensor([tok.encode(t, 10) for t in va_t])
    y_tr_t = torch.tensor(y_tr, dtype=torch.float32).unsqueeze(1)

    model = ClinicalNoteTransformer(len(tok), max_len=10, d_model=16)
    opt = torch.optim.Adam(model.parameters(), lr=0.02)
    loss_fn = nn.BCEWithLogitsLoss()
    for _ in range(25):
        model.train()
        opt.zero_grad()
        logits, _ = model(X_tr)
        loss_fn(logits, y_tr_t).backward()
        opt.step()

    model.eval()
    with torch.no_grad():
        va_logits, va_attn = model(X_va)
        va_probs = torch.sigmoid(va_logits).squeeze(-1).numpy()

    # Freeze entire model and attach rank-2 LoRA adapters to W_q & W_v
    for p in model.parameters():
        p.requires_grad = False
    model.enc.attn.W_q = LoRALinear(
        model.enc.attn.W_q, rank=2, alpha=4.0
    )
    model.enc.attn.W_v = LoRALinear(
        model.enc.attn.W_v, rank=2, alpha=4.0
    )
    with torch.no_grad():
        lora_logits, _ = model(X_va)
        parity = bool(
            (va_logits - lora_logits).abs().max().item() < 1e-6
        )
    total_p = sum(p.numel() for p in model.parameters())
    train_p = sum(
        p.numel() for p in model.parameters() if p.requires_grad
    )
    return {
        "val_acc": round(float(((va_probs >= 0.5) == y_va).mean()), 4),
        "val_auc": round(float(roc_auc_score(y_va, va_probs)), 4),
        "attn_shape": tuple(va_attn.shape),
        "lora_trainable_params": int(train_p),
        "lora_trainable_pct": round(100.0 * train_p / total_p, 2),
        "step0_parity_ok": parity,
    }

32.8.1 A. Concept & Execution Trace Test Key

  1. Because \(q \cdot k = \sum_{j=1}^{64} q_j k_j\) sums 64 unit-variance terms, \(\text{Var}(q \cdot k) = 64\) (\(\text{SD} = 8\)). Dividing by \(\sqrt{64} = 8\) restores \(\text{Var} = 1\) (\(\text{SD} = 1\)). Without scaling, extreme logits drive softmax into near one-hot saturation where \(\partial \text{softmax}_i / \partial z_j \approx 0\) (vanishing gradients).
  2. Row-stochastic probability normalization breaks! Zeroing masked entries after softmax leaves the remaining probabilities summing to < 1.0 (e.g., 0.35), shrinking value magnitudes inconsistently across positions. Masking with -inf before softmax guarantees exact zeros and rows summing to 1.0.
  3. At pos = 0, even indices evaluate \(\sin(0) = 0.0\) and odd indices evaluate \(\cos(0) = 1.0\), giving [0.0, 1.0, 0.0, 1.0, 0.0, 1.0].
  4. Calling .view(2, 4, 5, 4) directly on contiguous (B, T, d_model) memory slices across the sequence axis T, mixing features from different tokens into the same head! Splitting the last feature axis first (.view(2, 5, 4, 4)) and then swapping axes (.transpose(1, 2)) keeps every token intact inside every head.
  5. Without + x residual highways, gradients multiply through 24 consecutive Jacobians and decay exponentially (vanishing gradients), making deep Transformers fail to converge.
  6. Fitting the tokenizer on validation notes leaks vocabulary statistics (and inflates coverage artificially). When trained strictly on training notes, unseen "bradycardia" safely maps to UNK_ID = 1, preventing an nn.Embedding IndexError.
  7. Naive h.mean(dim=1) averages 7 <PAD> vectors into Note A, diluting its symptom signal by 70% compared to Note B. Masked mean pooling ((h * w).sum(1) / w.sum(1).clamp(min=1.0)) averages strictly over real clinical tokens.
  8. If both A = 0 and B = 0, then \(\partial L / \partial A \propto B^\top = 0\) and \(\partial L / \partial B \propto A^\top = 0\)—a dead saddle point where neither matrix learns! If both are random, \(B A \neq 0\) on step 0, adding random noise that disrupts pretrained foundation-model weights. Setting B = 0 and A ~ N(0, 0.02^2) gives exact step-0 parity and non-zero initial gradient on B.
  9. Rank \(r = 8\) adds \(8 \times (4096 + 4096) = \mathbf{65{,}536}\) trainable parameters, which is \(65{,}536 / (16{,}777{,}216 + 65{,}536) \approx \mathbf{0.39\%}\) of the layer (>99.6% reduction!).

import math
import torch
import torch.nn as nn

# To-Do 32.1
def scaled_dot_product_attention(Q, K, V, mask=None):
    """Compute scaled dot-product attention (mask: 1=allow, 0=block)."""
    d_k = Q.size(-1)
    scores = (Q @ K.transpose(-2, -1)) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    attn = torch.softmax(scores, dim=-1)
    return attn @ V, attn

# To-Do 32.2
def sinusoidal_positional_encoding(max_len, d_model):
    """Return (max_len, d_model) float32 sinusoidal position table."""
    pe = torch.zeros(max_len, d_model, dtype=torch.float32)
    pos = torch.arange(0, max_len, dtype=torch.float32).unsqueeze(1)
    div_term = torch.exp(
        torch.arange(0, d_model, 2, dtype=torch.float32)
        * (-math.log(10000.0) / d_model)
    )
    pe[:, 0::2] = torch.sin(pos * div_term)
    pe[:, 1::2] = torch.cos(pos * div_term[: d_model // 2])
    return pe

class MultiHeadSelfAttention(nn.Module):
    """Multi-head self-attention with W_q, W_k, W_v, W_o projections."""

    def __init__(self, d_model, num_heads):
        super().__init__()
        if d_model % num_heads != 0:
            raise ValueError(
                "d_model must be divisible by num_heads"
            )
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        B, T, _ = x.shape
        H, dk = self.num_heads, self.d_k
        Q = self.W_q(x).view(B, T, H, dk).transpose(1, 2)
        K = self.W_k(x).view(B, T, H, dk).transpose(1, 2)
        V = self.W_v(x).view(B, T, H, dk).transpose(1, 2)
        ctx, attn = scaled_dot_product_attention(Q, K, V, mask=mask)
        merged = ctx.transpose(1, 2).contiguous().view(
            B, T, self.d_model
        )
        return self.W_o(merged), attn

# To-Do 32.4
class TransformerEncoderBlock(nn.Module):
    """Transformer Encoder Block: MHA + LayerNorm + GELU FFN."""

    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.attn = MultiHeadSelfAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.drop = nn.Dropout(dropout)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
        )

    def forward(self, x, mask=None):
        attn_out, weights = self.attn(x, mask=mask)
        x = self.norm1(x + self.drop(attn_out))
        x = self.norm2(x + self.drop(self.ffn(x)))
        return x, weights

class ClinicalVocabTokenizer:
    """Deterministic whitespace clinical tokenizer with PAD & UNK."""

    PAD_ID = 0
    UNK_ID = 1

    def __init__(self):
        self.token_to_id = {"<PAD>": 0, "<UNK>": 1}
        self.id_to_token = {0: "<PAD>", 1: "<UNK>"}

    def fit(self, texts):
        words = sorted(
            {w for t in texts for w in t.lower().split()}
        )
        self.token_to_id = {"<PAD>": 0, "<UNK>": 1}
        for idx, word in enumerate(words, start=2):
            self.token_to_id[word] = idx
        self.id_to_token = {
            v: k for k, v in self.token_to_id.items()
        }
        return self

    def encode(self, text, max_len):
        ids = [
            self.token_to_id.get(w, self.UNK_ID)
            for w in text.lower().split()
        ][:max_len]
        return ids + [self.PAD_ID] * (max_len - len(ids))

    def __len__(self):
        return len(self.token_to_id)

# To-Do 32.6
class LoRALinear(nn.Module):
    """Freeze base nn.Linear and learn low-rank delta (B @ A)."""

    def __init__(self, base_linear, rank=4, alpha=8.0):
        super().__init__()
        self.base_linear = base_linear
        for p in self.base_linear.parameters():
            p.requires_grad = False
        self.rank = rank
        self.alpha = float(alpha)
        self.scaling = float(alpha) / rank
        in_f = base_linear.in_features
        out_f = base_linear.out_features
        self.lora_A = nn.Parameter(torch.randn(rank, in_f) * 0.02)
        self.lora_B = nn.Parameter(torch.zeros(out_f, rank))

    def forward(self, x):
        base_out = self.base_linear(x)
        delta = (x @ self.lora_A.T @ self.lora_B.T) * self.scaling
        return base_out + delta

def train_clinical_note_transformer(seed=42, epochs=25):
    """Train a 180-note clinical triage Transformer on CPU."""
    torch.manual_seed(seed)
    rng = np.random.default_rng(seed)
    shared = ["patient", "ward", "reports", "clinic", "history"]
    routine = [
        "mild", "stable", "refill", "followup", "normal",
        "routine", "afebrile", "checkup", "rash", "cleared",
    ]
    urgent = [
        "severe", "chest", "pain", "dyspnea", "hypoxia",
        "sepsis", "tachycardia", "syncope", "bleeding", "emergency",
    ]
    texts, labels = [], []
    for _ in range(90):
        ctx = list(rng.choice(shared, size=2, replace=False))
        r_tok = list(rng.choice(routine, size=4, replace=False))
        u_tok = list(rng.choice(urgent, size=4, replace=False))
        if rng.random() < 0.2:
            r_tok[0] = str(rng.choice(urgent))
        if rng.random() < 0.2:
            u_tok[0] = str(rng.choice(routine))
        rn, un = ctx + r_tok, ctx + u_tok
        rng.shuffle(rn)
        rng.shuffle(un)
        texts.extend([" ".join(rn), " ".join(un)])
        labels.extend([0, 1])
    y = np.array(labels, dtype=np.int64)

    tr_t, va_t, y_tr, y_va = train_test_split(
        texts, y, test_size=0.25, stratify=y, random_state=seed
    )
    tok = ClinicalVocabTokenizer().fit(tr_t)
    X_tr = torch.tensor([tok.encode(t, 10) for t in tr_t])
    X_va = torch.tensor([tok.encode(t, 10) for t in va_t])
    y_tr_t = torch.tensor(y_tr, dtype=torch.float32).unsqueeze(1)

    class _TriageNet(nn.Module):
        def __init__(self, v_size):
            super().__init__()
            self.emb = nn.Embedding(v_size, 16, padding_idx=0)
            self.register_buffer(
                "pe", sinusoidal_positional_encoding(10, 16)
            )
            self.enc = TransformerEncoderBlock(16, 2, 32, 0.1)
            self.head = nn.Linear(16, 1)

        def forward(self, ids):
            pm = (ids != 0).float()
            am = pm.unsqueeze(1).unsqueeze(2)
            x = self.emb(ids) + self.pe[: ids.size(1)]
            h, attn = self.enc(x, mask=am)
            w = pm.unsqueeze(-1)
            pooled = (h * w).sum(dim=1) / w.sum(dim=1).clamp(min=1.0)
            return self.head(pooled), attn

    model = _TriageNet(len(tok))
    opt = torch.optim.Adam(model.parameters(), lr=0.02)
    loss_fn = nn.BCEWithLogitsLoss()
    for _ in range(epochs):
        model.train()
        opt.zero_grad()
        logits, _ = model(X_tr)
        loss_fn(logits, y_tr_t).backward()
        opt.step()

    model.eval()
    with torch.no_grad():
        va_logits, va_attn = model(X_va)
        probs = torch.sigmoid(va_logits).squeeze(-1).numpy()
    val_acc = round(float(((probs >= 0.5) == y_va).mean()), 4)
    val_auc = round(float(roc_auc_score(y_va, probs)), 4)
    return {
        "val_acc": val_acc,
        "val_auc": val_auc,
        "attention_shape": tuple(va_attn.shape),
    }

def audit_lora_parameter_efficiency(d_in=64, d_out=64, rank=4):
    """Audit LoRA parameter count, step-0 parity, and freeze state."""
    torch.manual_seed(0)
    base = nn.Linear(d_in, d_out)
    lora = LoRALinear(base, rank=rank, alpha=2.0 * rank)
    x = torch.randn(4, d_in)
    with torch.no_grad():
        max_diff = (base(x) - lora(x)).abs().max().item()
        parity_ok = bool(max_diff < 1e-6)
    loss = lora(x).pow(2).mean()
    loss.backward()
    frozen_ok = bool(
        base.weight.grad is None
        and lora.lora_A.grad is not None
        and lora.lora_B.grad is not None
    )
    base_params = sum(p.numel() for p in base.parameters())
    lora_params = sum(
        p.numel() for p in lora.parameters() if p.requires_grad
    )
    pct = round(
        100.0 * lora_params / (base_params + lora_params), 2
    )
    return {
        "base_params": int(base_params),
        "lora_trainable_params": int(lora_params),
        "trainable_pct": pct,
        "initial_parity_ok": parity_ok,
        "base_frozen_ok": frozen_ok,
    }

32.8.4 D. Debugging Post-Mortem: Top 3 Chapter 32 Failure Modes

  1. Forgetting / math.sqrt(d_k) or Masking After Softmax: Unscaled dot products saturate softmax and kill gradients, while post-softmax masking breaks row-sum normalization. Always scale by 1 / math.sqrt(d_k) and apply scores.masked_fill(mask == 0, float("-inf")) before torch.softmax(scores, dim=-1).
  2. Scrambling Token Axes in Multi-Head .view() or Misaligned Mask Shapes: Never reshape (B, T, d_model) directly to (B, H, T, d_k); always use .view(B, T, H, d_k).transpose(1, 2) and pass broadcast-safe masks ((B, 1, 1, T) for padding or (1, 1, T, T) for causal decoding).
  3. Breaking LoRA Step-0 Parity or Leaving Base Weights Unfrozen: Forgetting p.requires_grad = False on base_linear.parameters() defeats LoRA’s memory savings and risks catastrophic forgetting, while initializing lora_B randomly corrupts the pretrained model’s initial predictions.
