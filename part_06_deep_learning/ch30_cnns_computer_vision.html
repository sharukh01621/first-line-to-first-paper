30.1 Stage 1 — First-Principles Intuition: Why Images Need Convolution, Not Flattening

Suppose a radiology clinic hands you a modest \(256 \times 256\) grayscale chest X-ray (\(65{,}536\) pixels) and asks a standard Multi-Layer Perceptron (MLP) to detect pulmonary nodules. Flattening that image into a 1D vector and connecting it to a single hidden layer of 256 neurons creates \(16{,}777{,}472\) trainable parameters in layer 1 alone! Even worse, if a nodule shifts 5 pixels to the right between two patients, a dense MLP treats it as a completely unrelated feature vector and must relearn the pattern at every pixel coordinate.

Convolutional Neural Networks (CNNs) replace brute-force dense connectivity with five biological and mathematical inductive biases:

  • Local Receptive Fields & Weight Sharing: A \(3 \times 3\) kernel inspects only a local neighborhood at a time and slides those exact same 9 weights across every spatial coordinate. A Conv2d(1, 8, kernel_size=3, padding=1) layer requires only 80 parameters regardless of whether the X-ray is \(16 \times 16\) or \(1024 \times 1024\)—a 209,718x parameter reduction!
  • Translation Equivariance: Because the same filter slides everywhere, shifting a bright focal lesion nodule by \((\Delta y, \Delta x)\) shifts its feature-map activation by \((\Delta y, \Delta x)\) without destroying detection.
  • Hierarchical Spatial Abstraction: Early layers detect low-level edges and intensity gradients; mid-level layers after MaxPool2d(2) assemble contours and circular blobs; deep layers after AdaptiveAvgPool2d(1) summarize global lesion presence for any input resolution.
  • Residual Skip Highways (out + x): Stacking dozens of plain convolutions causes vanishing gradients and degradation. Adding the identity shortcut \(y = \text{ReLU}(F(x) + x)\) lets gradients flow unimpeded straight through deep vision backbones such as ResNet.
  • Transfer Learning & Pixel Attribution: Clinical cohorts rarely contain millions of labeled scans. Freezing pretrained convolutional filters while fine-tuning a lightweight head (self.fc) prevents overfitting, and input-gradient saliency maps (\(|\partial \text{logit} / \partial x|\)) verify that the CNN focuses on the actual lesion rather than scanner borders or text markers.
NoteMental Model — PyTorch NCHW Tensor Contract

Every PyTorch 2D CNN layer strictly expects 4D channel-first tensors shaped (N, C, H, W):

  • N = batch size (number of scans or patches processed together),
  • C = channels (1 for grayscale X-ray / CT slice / microscopy, 3 for RGB histology),
  • H = image height (rows), and W = image width (columns).

Forgetting N or C (passing 2D (H, W)), passing RGB C=3 to a grayscale Conv2d(1, ...), or leaving NumPy/OpenCV channel-last (N, H, W, C) order causes instant RuntimeError crashes!

30.3.2 Pure-NumPy 2D Cross-Correlation Verified Against F.conv2d

Deep learning frameworks call conv2d a “convolution,” though mathematically it computes 2D cross-correlation (sliding kernel \(\mathbf{K}\) across padded image \(\tilde{\mathbf{I}}\) without flipping \(\mathbf{K}\) by \(180^\circ\)):

\[Y[i, j] = \sum_{u=0}^{K_h - 1} \sum_{v=0}^{K_w - 1} \tilde{I}[i \cdot S + u,\; j \cdot S + v] \cdot K[u, v]\]

Let’s code it in 15 lines of pure NumPy and verify floating-point parity against torch.nn.functional.conv2d:

def conv2d_numpy(image_2d, kernel_2d, stride=1, padding=0):
    img = np.asarray(image_2d, dtype=np.float32)
    ker = np.asarray(kernel_2d, dtype=np.float32)
    if padding > 0:
        img = np.pad(
            img, ((padding, padding), (padding, padding)), mode="constant"
        )
    kh, kw = ker.shape
    h_out = (img.shape[0] - kh) // stride + 1
    w_out = (img.shape[1] - kw) // stride + 1
    out = np.zeros((h_out, w_out), dtype=np.float32)
    for i in range(h_out):
        for j in range(w_out):
            patch = img[
                i * stride : i * stride + kh,
                j * stride : j * stride + kw,
            ]
            out[i, j] = np.sum(patch * ker)
    return out

rng = np.random.default_rng(42)
sample_img = rng.normal(size=(6, 6)).astype(np.float32)
sobel_x = np.array(
    [[1.0, 0.0, -1.0], [2.0, 0.0, -2.0], [1.0, 0.0, -1.0]],
    dtype=np.float32,
)
np_out = conv2d_numpy(sample_img, sobel_x, stride=1, padding=1)
pt_out = F.conv2d(
    torch.from_numpy(sample_img).unsqueeze(0).unsqueeze(0),
    torch.from_numpy(sobel_x).unsqueeze(0).unsqueeze(0),
    stride=1,
    padding=1,
).squeeze().numpy()
max_err = float(np.max(np.abs(np_out - pt_out)))
print(f"Output shape: {np_out.shape} | Max diff vs F.conv2d: {max_err:.2e}")

Expected Output:

Output shape: (6, 6) | Max diff vs F.conv2d: 2.38e-07

Three details deserve close attention:

  • Zero input mutation: np.asarray and np.pad leave sample_img and sobel_x untouched.
  • No kernel flip: Multiplying patch * ker directly matches F.conv2d to 2.38e-07 (single-precision machine epsilon!). Flipping ker[::-1, ::-1] would disagree on asymmetric kernels.
  • Why .unsqueeze(0).unsqueeze(0)? PyTorch’s F.conv2d requires 4D (N, C, H, W) tensors, so we prepend batch size N=1 and channel count C=1 to both the image and the filter.

30.3.3 Output-Shape Arithmetic & MaxPool2d vs. AdaptiveAvgPool2d

Every 2D convolution transforms height \(H_{\text{in}}\) and width \(W_{\text{in}}\) according to:

\[H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} + 2P - K}{S} \right\rfloor + 1, \qquad W_{\text{out}} = \left\lfloor \frac{W_{\text{in}} + 2P - K}{S} \right\rfloor + 1\]

Let’s verify this formula and contrast fixed spatial downsampling (MaxPool2d(2)) against resolution-agnostic global pooling (AdaptiveAvgPool2d(1)):

def conv2d_shape(h_in, w_in, kernel_size, stride=1, padding=0):
    if stride <= 0:
        raise ValueError("stride must be positive")
    h_out = (h_in + 2 * padding - kernel_size) // stride + 1
    w_out = (w_in + 2 * padding - kernel_size) // stride + 1
    if h_out <= 0 or w_out <= 0:
        raise ValueError("output dimensions must be positive")
    return (int(h_out), int(w_out))

for label, args in [
    ("Valid 3x3 (16x16)", (16, 16, 3, 1, 0)),
    ("Same 3x3  (16x16)", (16, 16, 3, 1, 1)),
    ("Stride-2  (32x24)", (32, 24, 5, 2, 2)),

    print(f"{label} -> {conv2d_shape(*args)}")

30.3.4 Building MedicalPatchCNN & ResidualConvBlock Skip Connections

Now assemble both core vision modules: our compact classifier MedicalPatchCNN (with its classification head cleanly named self.fc) and a ResNet-style ResidualConvBlock combining two Conv2d + BatchNorm2d stages with an identity skip path F.relu(out + x):

class MedicalPatchCNN(nn.Module):
    """Compact 2D CNN for single-channel medical patch classification."""

    def __init__(self, num_classes=1):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 8, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),
            nn.Conv2d(8, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
        )
        self.fc = nn.Linear(16, num_classes)

    def forward(self, x):
        return self.fc(self.features(x))

class ResidualConvBlock(nn.Module):
    """Two-layer Conv+BN residual block with identity skip connection."""

    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(channels)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(channels)

    def forward(self, x):
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return F.relu(out + x)

demo_cnn = MedicalPatchCNN(num_classes=1)
res_blk = ResidualConvBlock(channels=8)
total_p = sum(p.numel() for p in demo_cnn.parameters())
print(f"MedicalPatchCNN total params: {total_p:,}")
s16 = tuple(demo_cnn(torch.zeros(4, 1, 16, 16)).shape)

print(f"Output on 16x16: {s16} | on 24x24: {s24}")
res_in = torch.randn(3, 8, 16, 16)

)

30.3.5 Synthetic Medical Lesion Patches & Training MedicalPatchCNN

To keep every experiment 100% offline, deterministic, and fast on CPU, we synthesize \(16 \times 16\) single-channel medical imaging patches mimicking chest X-ray or fluorescence microscopy nodules:

  • Class 0 (Healthy tissue): Random exposure baseline (0.15..0.30) plus Gaussian tissue noise (\(\sigma = 0.12\)).
  • Class 1 (Focal lesion): Healthy tissue background plus a bright localized circular 2D Gaussian nodule placed at a randomized interior coordinate (cy, cx)—rewarding true CNN translation equivariance!
def generate_synthetic_lesion_dataset(n_samples=160, img_size=16, seed=42):
    rng = np.random.default_rng(seed)
    n_neg = n_samples // 2
    n_pos = n_samples - n_neg
    labels = np.array([0] * n_neg + [1] * n_pos, dtype=np.float32)
    rng.shuffle(labels)
    yy, xx = np.meshgrid(
        np.arange(img_size), np.arange(img_size), indexing="ij"
    )
    images = np.zeros((n_samples, 1, img_size, img_size), dtype=np.float32)
    for i, lbl in enumerate(labels):
        base = rng.uniform(0.15, 0.30)
        patch = rng.normal(base, 0.12, size=(img_size, img_size))
        if lbl == 1.0:
            cy = rng.integers(3, img_size - 3)
            cx = rng.integers(3, img_size - 3)
            amp = rng.uniform(0.95, 1.25)
            dist_sq = (yy - cy) ** 2 + (xx - cx) ** 2
            patch = patch + amp * np.exp(-dist_sq / (2.0 * 1.5 ** 2))
        images[i, 0] = np.clip(patch, 0.0, 2.0)
    return torch.from_numpy(images), torch.from_numpy(labels)

X_all, y_all = generate_synthetic_lesion_dataset(200, img_size=16, seed=42)
idx = np.arange(len(y_all))
tr_i, va_i = train_test_split(
    idx, test_size=0.25, stratify=y_all.numpy(), random_state=42
)
X_tr, y_tr = X_all[tr_i], y_all[tr_i]
X_va, y_va = X_all[va_i], y_all[va_i]

torch.manual_seed(42)
cnn = MedicalPatchCNN(num_classes=1)
opt = torch.optim.Adam(cnn.parameters(), lr=0.01)
loss_fn = nn.BCEWithLogitsLoss()

for epoch in range(1, 16):
    cnn.train()
    perm = torch.randperm(len(X_tr))
    ep_loss = 0.0
    for start in range(0, len(X_tr), 32):
        b = perm[start : start + 32]
        opt.zero_grad()
        loss = loss_fn(cnn(X_tr[b]).squeeze(-1), y_tr[b])
        loss.backward()
        opt.step()
        ep_loss += loss.item() * len(b)
    ep_loss /= len(X_tr)
    if epoch in (1, 5, 10, 15):
        print(f"Epoch {epoch:2d} | Train BCE Loss: {ep_loss:.5f}")

cnn.eval()
with torch.no_grad():
    va_probs = torch.sigmoid(cnn(X_va).squeeze(-1)).numpy()
va_pred = (va_probs >= 0.5).astype(np.float32)
va_acc = float((va_pred == y_va.numpy()).mean())
va_auc = float(roc_auc_score(y_va.numpy(), va_probs))
print(f"Val Accuracy: {va_acc:.4f} | Val ROC-AUC: {va_auc:.4f}")

Expected Output:

Epoch  1 | Train BCE Loss: 0.71271
Epoch  5 | Train BCE Loss: 0.60868
Epoch 10 | Train BCE Loss: 0.26909

30.3.6 Transfer Learning: Freezing the Convolutional Backbone

When adapting a pretrained vision backbone (such as ImageNet-pretrained ResNet or a hospital-pretrained chest X-ray encoder) to a small specialty cohort, we freeze the convolutional backbone (requires_grad = False) and optimize only the task-specific linear head (self.fc):

def freeze_backbone(model, head_name="fc"):
    prefix = f"{head_name}."
    trainable, frozen = 0, 0
    for name, p in model.named_parameters():
        p.requires_grad = name.startswith(prefix)
        if p.requires_grad:
            trainable += p.numel()
        else:
            frozen += p.numel()
    return {"trainable_params": trainable, "frozen_params": frozen}

transfer_net = MedicalPatchCNN(num_classes=1)
transfer_net.load_state_dict(cnn.state_dict())
counts = freeze_backbone(transfer_net, head_name="fc")
w_conv0 = transfer_net.features[0].weight.detach().clone()
w_fc0 = transfer_net.fc.weight.detach().clone()

head_opt = torch.optim.Adam(
    [p for p in transfer_net.parameters() if p.requires_grad], lr=0.05
)
head_opt.zero_grad()

30.3.8 Break It On Purpose! (CNN Error Anatomy)

ImportantBreak It On Purpose #1 — RuntimeError (Channel Count Mismatch: RGB 3 Channels into Grayscale Conv2d)

rgb_batch = torch.zeros(2, 3, 16, 16)
gray_conv(rgb_batch)

Python’s Traceback:

RuntimeError: Given groups=1, weight of size [8, 1, 3, 3], expected
input[2, 3, 16, 16] to have 1 channels, but got 3 channels instead

Diagnosis: PyTorch stores Conv2d weights as [out_channels, in_channels, kH, kW]. Here weight expects in_channels = 1 (single-channel grayscale scan), but rgb_batch supplied 3 channels (common when PNG X-rays are accidentally loaded in RGB mode via PIL/OpenCV, or when an NHWC (B, H, W, C) array is not permuted to NCHW!).
Fix: Convert grayscale images to 1 channel (x.mean(dim=1, keepdim=True)), permute channel-last tensors via x.permute(0, 3, 1, 2), or construct Conv2d(3, ...) when true RGB color is needed.

ImportantBreak It On Purpose #2 — RuntimeError (Missing Batch & Channel Dimensions: 2D Input to Conv2d) 
gray_conv = nn.Conv2d(1, 8, kernel_size=3, padding=1)
flat_2d = torch.zeros(16, 16)
gray_conv(flat_2d)

Python’s Traceback:

RuntimeError: Expected 3D (unbatched) or 4D (batched) input to conv2d,
but got input of size: [16, 16]

Diagnosis: Passing a raw 2D NumPy/PyTorch image (H, W) into nn.Conv2d omits both the batch axis N and channel axis C. Similarly, passing channel-last (B, 16, 16, 1) triggers a channel mismatch because PyTorch reads dimension 1 (16) as in_channels!
Fix: Add batch and channel dimensions cleanly via flat_2d.unsqueeze(0).unsqueeze(0) (yielding (1, 1, 16, 16)), and always verify x.ndim == 4 with (N, C, H, W) layout before calling a CNN.

ImportantBreak It On Purpose #3 — RuntimeError (Calling backward() When All Parameters Are Frozen)

for p in frozen_net.parameters():
    p.requires_grad = False

Python’s Traceback:

have a grad_fn

Diagnosis: During transfer learning, if you misspell head_name (e.g., passing "classifier" when the head attribute is "fc"), zero parameters match name.startswith(prefix), so every weight gets requires_grad = False. PyTorch builds no autograd graph for out, and .backward() crashes immediately!

def run_lesion_cnn_audit(n_samples=200, epochs=15, seed=42):
    """Audit shapes, train MedicalPatchCNN & locate lesion via saliency."""
    X, y = generate_synthetic_lesion_dataset(n_samples, 16, seed)
    idx = np.arange(len(y))
    tr, va = train_test_split(
        idx, test_size=0.25, stratify=y.numpy(), random_state=seed
    )
    torch.manual_seed(seed)
    model = MedicalPatchCNN(num_classes=1)
    shapes, handles = [], []

    def _make_hook(layer_name):
        def _hook(_mod, _inp, out):
            shapes.append((layer_name, tuple(out.shape)))
        return _hook

    for name, mod in model.named_modules():
        if isinstance(mod, (nn.Conv2d, nn.Linear)):
            handles.append(mod.register_forward_hook(_make_hook(name)))
    try:
        model.eval()
        with torch.no_grad():
            model(torch.zeros(4, 1, 16, 16))
    finally:
        for h in handles:
            h.remove()

    opt = torch.optim.Adam(model.parameters(), lr=0.01)
    loss_fn = nn.BCEWithLogitsLoss()
    for _ in range(epochs):
        model.train()
        perm = torch.randperm(len(tr))
        for s in range(0, len(tr), 32):
            b = tr[perm[s : s + 32].numpy()]
            opt.zero_grad()
            loss = loss_fn(model(X[b]).squeeze(-1), y[b])
            loss.backward()
            opt.step()

    model.eval()
    with torch.no_grad():
        probs = torch.sigmoid(model(X[va]).squeeze(-1)).numpy()
    val_auc = round(float(roc_auc_score(y[va].numpy(), probs)), 4)
    pos_i = int(np.where(y[va].numpy() == 1.0)[0][0])
    x_one = X[va][pos_i : pos_i + 1].clone().detach().requires_grad_(True)
    model.zero_grad()
    logit = model(x_one).squeeze()
    logit.backward()
    sal = x_one.grad.detach().abs().squeeze().cpu().numpy()
    peak_rc = np.unravel_index(int(np.argmax(sal)), sal.shape)
    peak = (int(peak_rc[0]), int(peak_rc[1]))
    return {"shapes": shapes, "val_auc": val_auc, "peak_coord": peak}

30.8 Stage 8 — Complete Annotated Solutions & Debugging Post-Mortem

30.8.1 A. Concept & Execution Trace Test Key

  1. Each of the 16 output filters has 3 * 5 * 5 = 75 weights plus 1 bias \(= 76\) parameters, so \(16 \times 76 = \mathbf{1{,}216}\) parameters total.
  2. \(H_{\text{out}} = W_{\text{out}} = \lfloor (224 + 2 \times 3 - 7) / 2 \rfloor + 1 = \lfloor 223 / 2 \rfloor + 1 = 111 + 1 = 112\), giving (4, 64, 112, 112).
  3. padding = 2 (\(5 // 2 = 2\)), because \((H + 2(2) - 5) // 1 + 1 = H\).
  4. You flipped the kernel \(180^\circ\) (kernel[::-1, ::-1]). Symmetric kernels look identical when flipped, but PyTorch’s F.conv2d performs cross-correlation without flipping.
  5. AdaptiveAvgPool2d(1) always reduces spatial dimensions to (1, 1) regardless of input resolution, so Flatten() feeds (8, 16) into self.fc.
  6. For \(+3.0\): \(\text{ReLU}(0 + 3.0) = \mathbf{3.0}\) (identity highway!). For \(-3.0\): \(\text{ReLU}(0 - 3.0) = \mathbf{0.0}\) (post-addition ReLU zeroes negative values).
  7. PyTorch interprets dimension 1 (64) as in_channels, raising RuntimeError: expected input[10, 64, 64, 1] to have 1 channels, but got 64 channels instead. Fix with x.permute(0, 3, 1, 2) to convert NHWC \(\rightarrow\) NCHW.
  8. No parameter name starts with "classifier.", so freeze_backbone_for_transfer set requires_grad = False on every parameter in MedicalPatchCNN—leaving no trainable leaf tensors in the autograd graph.
  9. Unremoved hooks stay attached to module instances forever, firing on every subsequent training batch, silently growing Python lists, and leaking GPU/CPU memory—even if an exception occurs mid-forward.
  10. Near pred_prob = 0.999, the sigmoid derivative \(\sigma(z)(1 - \sigma(z)) \approx 0.001\) scales all pixel gradients down by 1000x (saturation!). Backpropagating from the raw pre-sigmoid logit preserves full gradient contrast.

import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F

# To-Do 30.1
def conv2d_output_shape(h_in, w_in, kernel_size, stride=1, padding=0):
    """Compute Conv2d output (h_out, w_out) with ValueError guards."""
    if stride <= 0:
        raise ValueError("stride must be positive")
    h_out = (h_in + 2 * padding - kernel_size) // stride + 1
    w_out = (w_in + 2 * padding - kernel_size) // stride + 1
    if h_out <= 0 or w_out <= 0:
        raise ValueError("output spatial dimensions must be positive")
    return (int(h_out), int(w_out))

# To-Do 30.2
def conv2d_single_channel_numpy(image_2d, kernel_2d, stride=1, padding=0):
    """Pure-NumPy 2D cross-correlation matching PyTorch F.conv2d."""
    img = np.asarray(image_2d, dtype=np.float32)
    ker = np.asarray(kernel_2d, dtype=np.float32)
    if padding > 0:
        img = np.pad(
            img, ((padding, padding), (padding, padding)), mode="constant"
        )
    kh, kw = ker.shape
    h_out = (img.shape[0] - kh) // stride + 1
    w_out = (img.shape[1] - kw) // stride + 1
    out = np.zeros((h_out, w_out), dtype=np.float32)
    for i in range(h_out):
        for j in range(w_out):
            patch = img[
                i * stride : i * stride + kh,
                j * stride : j * stride + kw,
            ]
            out[i, j] = np.sum(patch * ker)
    return out

# To-Do 30.3
class MedicalPatchCNN(nn.Module):
    """Compact 2D CNN for single-channel medical patch classification."""

    def __init__(self, num_classes=1):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 8, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),
            nn.Conv2d(8, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
        )
        self.fc = nn.Linear(16, num_classes)

    def forward(self, x):
        return self.fc(self.features(x))

# To-Do 30.4
class ResidualConvBlock(nn.Module):
    """Two-conv residual block with BatchNorm2d and identity skip."""

    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(channels)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(channels)

    def forward(self, x):
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return F.relu(out + x)

# To-Do 30.5
def freeze_backbone_for_transfer(model, head_name="fc"):
    """Freeze all parameters outside `head_name.` and tally p.numel()."""
    prefix = f"{head_name}."
    trainable = 0
    frozen = 0
    for name, param in model.named_parameters():
        param.requires_grad = name.startswith(prefix)
        if param.requires_grad:
            trainable += param.numel()
        else:
            frozen += param.numel()
    return {
        "trainable_params": int(trainable),
        "frozen_params": int(frozen),
    }

# To-Do 30.6
def generate_synthetic_lesion_dataset(n_samples=160, img_size=16, seed=42):
    """Generate deterministic (X[N,1,H,W], y[N]) lesion patch tensors."""
    rng = np.random.default_rng(seed)
    n_neg = n_samples // 2
    n_pos = n_samples - n_neg
    labels = np.array([0] * n_neg + [1] * n_pos, dtype=np.float32)
    rng.shuffle(labels)
    yy, xx = np.meshgrid(
        np.arange(img_size), np.arange(img_size), indexing="ij"
    )
    images = np.zeros((n_samples, 1, img_size, img_size), dtype=np.float32)
    for i, lbl in enumerate(labels):
        base = rng.uniform(0.15, 0.30)
        patch = rng.normal(base, 0.12, size=(img_size, img_size))
        if lbl == 1.0:
            cy = rng.integers(3, img_size - 3)
            cx = rng.integers(3, img_size - 3)
            amp = rng.uniform(0.95, 1.25)
            dist_sq = (yy - cy) ** 2 + (xx - cx) ** 2
            patch = patch + amp * np.exp(-dist_sq / (2.0 * 1.5 ** 2))
        images[i, 0] = np.clip(patch, 0.0, 2.0)
    return torch.from_numpy(images), torch.from_numpy(labels)

        "final_train_loss": round(float(final_loss), 5),
    }

# Exam Task 30.3 (35 pts)
def compute_saliency_attribution_map(model, x_single):
    """Compute |d(logit)/dx| saliency map, peak (row, col), and prob."""
    model.eval()
    model.zero_grad()
    x = x_single.clone().detach().requires_grad_(True)
    logit = model(x).squeeze()
    logit.backward()
    saliency = x.grad.detach().abs().squeeze().cpu().numpy()
    peak_rc = np.unravel_index(int(np.argmax(saliency)), saliency.shape)
    peak_coord = (int(peak_rc[0]), int(peak_rc[1]))
    pred_prob = round(float(torch.sigmoid(logit.detach()).item()), 4)
    return {
        "saliency_map": saliency,
        "peak_coord": peak_coord,
        "pred_prob": pred_prob,
    }

30.8.4 D. Debugging Post-Mortem: Top 3 Chapter 30 Failure Modes

  1. Channel & Dimension Mismatches (NCHW vs. 2D or NHWC): Passing (H, W) without batch/channel axes, feeding 3-channel RGB PNGs into a 1-channel medical Conv2d(1, ...), or forgetting .permute(0, 3, 1, 2) on OpenCV arrays triggers immediate RuntimeError. Audit tensor shapes early with audit_cnn_feature_map_shapes.
  2. Silent Transfer-Learning Freeze & Hook Leaks: Misspelling head_name freezes 100% of parameters and crashes loss.backward() with does not require grad; forgetting handle.remove() in finally: permanently leaks forward hooks into subsequent training epochs.
  3. Saturated Saliency & Mutated Inputs: Calling x_single.requires_grad_(True) directly mutates caller validation tensors, and calling torch.sigmoid(logit).backward() attenuates gradients on confident predictions. Always .clone().detach().requires_grad_(True) and backpropagate the raw logit.
